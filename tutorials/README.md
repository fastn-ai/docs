# Tutorials

Each tutorial is a hands-on walkthrough with one clear outcome. By the end, you have something working.

**Prerequisites:** Read [Core concepts](../getting-started/concepts.md) first. These tutorials assume you have a Fastn account and basic familiarity with the dashboard.

### Tutorials for your team

For your team: the people who set up and run Fastn for your product.

[**Set up your organization**](saas-admin/setting-up-your-organization.md) - Configure organization settings, invite your team, review plan limits and the audit log, and find API keys, secrets, environments, and connector auth.

[**Create a workflow with the Fastn agent**](saas-admin/creating-a-workflow-via-ai.md) - Use the Fastn agent to create workflows by describing what you need in plain language. Needs a paid plan (Scale or Enterprise).

[**Build your widget**](saas-admin/building-your-widget.md) - See how the widget builder works and what your customers see.

[**Manage customers**](saas-admin/managing-customers.md) - Create customers, scope API calls, customize quota limits, and monitor activity.

[**Set up roles and permissions**](saas-admin/roles-and-permissions-setup.md) - Assign built-in roles (Owner, Admin, Developer, Operator, Viewer, End User), create custom roles, and manage access.

### Tutorials for developers

See [Developer tutorials](developer/README.md): embedding the widget, embed tokens, API keys, customer identifiers, deployment, and troubleshooting.

### Tutorials for the people at your customers


For the people at your customers who use integrations through the embedded widget in your product.

[**Connect apps**](end-user/connecting-apps-via-widget.md) - Find available integrations, authorize your accounts, and activate connections.

[**Customize an integration**](end-user/customizing-your-integrations.md) - Configure sync preferences, field mappings, and scheduling.

[**View sync status and history**](end-user/viewing-sync-status-and-history.md) - Check what's syncing, view history, and troubleshoot failures.
