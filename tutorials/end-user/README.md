# End User

These tutorials are for the people who use integrations through the widget embedded in a SaaS product. You don't need a Fastn account or dashboard access — everything happens inside the product you already use.

{% hint style="info" %}
**Note for SaaS Admins:** Share this section with your customers when they ask how to use the integrations you've embedded. These tutorials describe the end user experience through the widget, not the Fastn dashboard.
{% endhint %}

### Tutorials in this section

[**Connecting Apps via Widget**](connecting-apps-via-widget.md) — Find available integrations, authorize your accounts, and activate connections through the embedded widget.

[**Customizing Your Integrations**](customizing-your-integrations.md) — Configure sync preferences, field mappings, scheduling, and other settings for your active integrations.

[**Extending a Pre-Built Integration**](extending-a-prebuilt-integration.md) — Change what fields, filters and direction a shipped integration uses, and know where the agent's authority ends.

[**Getting Alerted**](getting-alerted.md) — Set up your own alerts so a broken or stalled integration tells you, instead of a colleague telling you.

[**Connecting Claude and Other AI Clients**](connecting-claude.md) — Copy the MCP URL from a share link and drive your integrations from Claude, with no fastn account.

[**Viewing Sync Status & History** ](viewing-sync-status-and-history.md)— Check what's syncing, view execution history, and troubleshoot when something fails.
