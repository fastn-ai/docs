# Botdog

<img src="../../.gitbook/assets/connectors/botdog.png" alt="Botdog logo" width="64">

Botdog is a LinkedIn outreach and automation platform. This connector covers campaigns and their sequences, statistics and activity controls, leads, audience lists and blacklists, connected LinkedIn sender accounts and their daily sending limits, message snippets, analytics, team users, messaging, and webhook subscriptions.

## Use it

Add Botdog from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.botdog.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).

## Actions

| Action | Slug | What it does |
| --- | --- | --- |
| Add Leads To Campaign | `addLeadsToCampaign` | Enrol LinkedIn profiles as leads in an existing Botdog campaign, up to 100 per call. WARNING: every profile added here becomes a real outreach target — once the campaign is running, Botdog will visit, invite and message these people from the connected LinkedIn account. The calling API key's owner must hold a LinkedIn seat, otherwise the API returns 403. |
| Add Leads To List | `addLeadsToList` | Add LinkedIn profiles to a Botdog list as leads, up to 100 per call. Duplicates already present in the list are skipped. Adding a profile to a list only stores it as an audience member; it does not start any outreach. |
| Add Profiles To Blacklist | `addProfilesToBlacklist` | Add LinkedIn profiles to a Botdog blacklist so that campaigns never contact them, up to 100 per call. Duplicates already present are skipped. |
| Archive Campaign | `archiveCampaign` | Archive a Botdog campaign. Archiving stops the campaign and moves it out of the active list while keeping its leads and history; the work is completed asynchronously, so the call returns 202 Accepted. |
| Create Blacklist | `createBlacklist` | Create a new Botdog blacklist, a suppression list of LinkedIn profiles that campaigns must never contact. Note that the Botdog API offers no endpoint for deleting a blacklist once it has been created. |
| Create Campaign | `createCampaign` | Create a new Botdog outreach campaign with a name and optional start and end dates. The campaign is created in the CREATED state; its message sequence must be built and the campaign launched from the Botdog web app, neither of which is settable through the API. |
| Create List | `createList` | Create a new Botdog lead or audience list. Set isBlacklist to true to create a suppression list instead. Note that the Botdog API offers no endpoint for deleting a list once it has been created. |
| Create Snippet | `createSnippet` | Create a Botdog message snippet. A TEXT snippet stores a static template in content; an LLM snippet stores a generation prompt in prompt. An optional shortcut gives quick access and must be unique. |
| Create Webhook | `createWebhook` | Create a Botdog webhook subscription that POSTs the selected event types to your endpoint, optionally restricted to specific campaigns. The signing secret is generated by Botdog and is never returned. Note that the Botdog API offers no endpoint for deleting a webhook once it has been created. |
| Delete Campaign | `deleteCampaign` | Delete a Botdog campaign. The campaign is hidden immediately and its leads and running activity are cancelled and removed in the background, so the call returns 202 Accepted rather than 200. |

## Events

| Event | Id | When it fires |
| --- | --- | --- |
| Campaign Completed | `CAMPAIGN_COMPLETED` | A campaign finished. Botdog's subscription API accepts this event type but its public documentation does not list it among the delivered events, so delivery is unconfirmed. No payload schema is published; subscribe and inspect a first delivery before relying on it. |
| Campaign Started | `CAMPAIGN_STARTED` | A campaign started running. Botdog's subscription API accepts this event type but its public documentation does not list it among the delivered events, so delivery is unconfirmed. No payload schema is published; subscribe and inspect a first delivery before relying on it. |
| Daily Sending Limit Reached | `DAILY_LIMIT_REACHED` | A sender account hit its daily cap. Botdog accepts this subscription but its documentation states the event is NOT YET DELIVERED and reserved for a future release, so subscribing to it produces no calls today; this connector's unsubscribe code parks retired subscriptions on this event type for that reason. |
| Inbox Message Received Outside Campaigns | `NON_CAMPAIGN_LEAD_INBOX_MESSAGE_RECEIVED` | Someone outside any campaign sent an inbound LinkedIn message. This event carries only the five identity fields plus the shared base fields; the enriched contact fields are absent entirely. It never overlaps with Lead Replied. Payload schema modelled from Botdog's documented sample. |
| Invitation Accepted | `LEAD_INVITATION_ACCEPTED` | A lead accepted a connection invitation from your account. Payload schema modelled from Botdog's documented sample; no live delivery could be captured in this sandbox. |
| Invitation Sent | `LEAD_INVITATION_SENT` | A connection invitation was sent to a lead. On this event leadInvitedAt is an empty string because the event fires as the invitation leaves; use sentAt. Payload schema modelled from Botdog's documented sample. |
| Invitation Withdrawn | `LEAD_INVITATION_WITHDRAWN` | A pending connection invitation was withdrawn. Botdog accepts this subscription but its documentation states the event is NOT YET DELIVERED and reserved for a future release, so subscribing to it produces no calls today. |
| Lead Replied | `LEAD_MESSAGE_REPLIED` | A lead replied to one of your messages. Payload schema modelled from Botdog's documented sample at docs.botdog.co/webhooks/events; no live delivery could be captured because this sandbox has no connected LinkedIn sender account. |
| Lead Skipped | `LEAD_SKIPPED` | A lead was skipped by a campaign. Botdog accepts this subscription but its documentation states the event is NOT YET DELIVERED and reserved for a future release, so subscribing to it produces no calls today. |
| LinkedIn Account Disconnected | `ACCOUNT_DISCONNECTED` | A connected LinkedIn sender account lost its session. Botdog accepts this subscription but its documentation states the event is NOT YET DELIVERED and reserved for a future release, so subscribing to it produces no calls today. |
