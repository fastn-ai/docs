# Coresignal

<img src="../../.gitbook/assets/connectors/lg/coresignal.png" alt="Coresignal logo">

Coresignal B2B public web data API (CDAPI v2): search, collect and enrich company, employee, job and post records across Base, Clean and Multi-source datasets, plus Bulk Collect data requests, Agentic Search and employee-change webhook subscriptions. Metered by credits.

| | |
| --- | --- |
| **Category** | [CRM and sales](README.md) |
| **Website** | [coresignal.com](https://coresignal.com) |
| **Authentication** | API key |
| **Slug** | `coresignal` |

## Use it

Add Coresignal from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.coresignal.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).
