# ContactOut

<img src="../../.gitbook/assets/connectors/lg/contactout.png" alt="ContactOut logo">

This connector covers the full ContactOut public API: LinkedIn and email profile enrichment, people and company search, decision-maker discovery, bulk contact-info jobs, contact availability checks, hashed-email identifiers, single and bulk email verification, outreach campaign management and API usage statistics.

| | |
| --- | --- |
| **Category** | [CRM and sales](README.md) |
| **Website** | [contactout.com](https://contactout.com) |
| **Authentication** | API key |
| **Slug** | `contactout` |

## Use it

Add ContactOut from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.contactout.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).

## Events

Start a workflow when one of these happens, with an [app event trigger](../../build/triggers/README.md).

<table><thead><tr><th width="240">Event</th><th width="260">Id</th><th>When it fires</th></tr></thead><tbody><tr><td>Bulk Contact Info Job Completed</td><td><code>bulk_contact_info_job_completed</code></td><td>Fires when an asynchronous bulk contact-info job finishes and ContactOut posts its results. ContactOut has no webhook registration API: you register this trigger per job. Setup: copy this trigger's URL, then run the Create Bulk Contact Info Job action (POST /v2/people/linkedin/batch) with that URL in its Callback URL input. ContactOut posts the finished results to it once the job completes. Because the callback URL is supplied per job, each trigger receives only the jobs it was passed to. ContactOut sends no event-type field and no signature on this delivery. Payload schema modelled from ContactOut's documented webhook payload, not from a captured delivery.</td></tr><tr><td>Bulk Email Verification Job Completed</td><td><code>bulk_email_verification_job_completed</code></td><td>Fires when an asynchronous bulk email verification job finishes and ContactOut posts its results. ContactOut has no webhook registration API: you register this trigger per job. Setup: copy this trigger's URL, then run the Create Bulk Email Verification Job action (POST /v1/email/verify/batch) with that URL in its Callback URL input. Because the callback URL is supplied per job, each trigger receives only the jobs it was passed to. ContactOut sends no event-type field and no signature on this delivery. ContactOut does not publish the callback body for this job type; the schema below is modelled from the body its Get Bulk Email Verification Job endpoint returns and should be treated as indicative rather than a vendor contract.</td></tr></tbody></table>
