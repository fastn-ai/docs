| **Authentication** | API key or token |
| **Slug** | `awsSns` |

## Setup

Your customers enter their API key or token for AWS Simple Notification Service when they connect. Nothing else needs setting up.

## Use it

Add AWS Simple Notification Service from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.awsSns.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).

## Events

AWS Simple Notification Service has no events, so it can't start a workflow by itself. Use its actions in a workflow that another [trigger](../../build/triggers/README.md) starts, such as a schedule or a webhook.
