# Tidio

<img src="../../.gitbook/assets/connectors/lg/tidio.png" alt="Tidio logo">

Tidio is a customer service platform combining live chat, ticketing and the Lyro AI agent. This connector covers the Tidio OpenAPI (api.tidio.com) and the read-only Analytics API (taa.data.tidio.com, PostgREST; same credentials; Plus/Premium only, returns 401 Unauthorized otherwise). IMPORTANT: the Tidio OpenAPI is a paid feature - Product (Lyro product recommendation) endpoints require a paid Lyro plan, and every other endpoint family (contacts, conversations, tickets, operators, departments, Lyro data sources, project) requires the Plus or Premium plan and returns 403 api_access_disabled otherwise. Credentials are the OpenAPI Client Id/Client Secret pair generated in Tidio Panel under Developer &gt; OpenAPI.

## Use it

Add Tidio from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.tidio.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).

| Add website as Lyro data source (scraping) | `scrapeLyroWebsiteDataSource` | Add website as Lyro data source (scraping). This API endpoint allows you to submit a website URL to be scraped and used as a knowledge data source for the Lyro AI Agent. Each URL must be unique per project. If the URL already exists, a `409 Conflict` response will be returned. |
| Ask Lyro to answer ticket | `askLyroToAnswerTicket` | Ask Lyro to answer ticket. This API endpoint asks Lyro to answer a ticket based on the data provided. Responding can take up to 40 seconds. Currently, it only works for the first message in the ticket, which is why the request is limited to a single message. |
| Create contact | `createContact` | Create contact. Contacts are site visitors who have interacted with the Tidio widget and have been identified by their name, email address, or phone number. Each contact can have custom properties that can be given by the contact, added by chat operators, or updated by chatbots. Contacts may also have conversations, which include messages from the contact as well as messages to the contact from chat operators or chatbots. You can use OpenAPI to create a new contact. When creating a contact, you need to provide at least one of the following: `email`, `first_name`, `last_name`, or `phone`. Please note that using this method will always add new contacts. No data will be overwritten, even if it includes the `email` or a `distinct_id`. |
| Create Lyro QA data source | `createLyroQaDataSource` | Create Lyro QA data source. This API endpoint allows you to create a QA data source for the Lyro AI Agent. Data sources provide knowledge that Lyro uses to answer customer questions. The content should be provided as text and will be processed by the AI Agent. |
| Create multiple contacts | `createContactsBatch` | Create multiple contacts. The same as `[POST] /contacts`, but for multiple contacts. Contacts are saved with `all or nothing` strategy, so all contacts must be valid. The maximum amount of contacts to create in a single request is 100. |
| Create ticket (as Contact) | `createTicketAsContact` | Create ticket (as Contact). This API endpoint creates a ticket as Contact based on the data provided. |
| Delete contact | `deleteContact` | Delete contact. This API endpoint allows you to delete a specific contact identified by ID. Please be aware that once the contact is deleted, there's no way to recover it, so use this feature with care. |
| Delete Product | `deleteProduct` | Permanently removes a single product from the Lyro AI agent's product recommendations. Deletion is irreversible and processed asynchronously. Individual product deletions do not count against the 24-hour product source ingestion limit. |
| Delete ticket | `deleteTicket` | Delete ticket. This API endpoint allows you to delete a specific ticket identified by ID. This feature can be used to delete requests that are no longer needed or have been resolved. Be careful when using this endpoint. Deleted data is usually irreversible. |
| Get agent_details | `listAgentDetails` | Get agent_details. Raw data for human agents. Analytics API (read-only, PostgREST at taa.data.tidio.com). Filter any column with column=operator.value (eq, neq, gt, gte, lt, lte, like, ilike, in, is, not.), e.g. created_at=gte.2026-08-01T00:00:00Z. Paging: limit + offset (with an order).
