# Cisco Webex

Cisco Webex video conferencing, messaging, and collaboration platform. Wraps the Webex REST API (webexapis.com/v1) for meetings, messages, rooms/spaces, people, memberships, teams, and webhooks.

| | |
| --- | --- |
| **Category** | [Communication](README.md) |
| **Website** | [webexapis.com](https://webexapis.com) |
| **Authentication** | OAuth 2.0 |
| **Slug** | `webex` |

## Use it

Add Cisco Webex from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.webex.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).
