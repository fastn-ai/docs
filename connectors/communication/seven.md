# seven

<img src="../../.gitbook/assets/connectors/seven.png" alt="seven logo" width="64">

seven (seven.io) is a European SMS, RCS, WhatsApp Business and voice messaging gateway. Send SMS, RCS and WhatsApp messages, place text-to-speech voice calls, manage contacts and groups, look up and validate phone numbers (format, HLR, MNP, CNAM, RCS capabilities), book and manage virtual numbers, query logbooks, delivery status reports, pricing, analytics and account balance, administer subaccounts, and register webhooks for inbound messages and delivery events.

## Use it

Add seven from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.seven.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).

## Actions

| Action | Slug | What it does |
| --- | --- | --- |
| Configure Subaccount Auto Top-Up | `configureSubaccountAutoTopup` | Set up automatic credit transfer for a subaccount: whenever its balance falls below the threshold, the given amount is moved from the main account. Set amount to 0 to switch automatic top-up off. |
| Create Contact | `createContact` | Add a new contact to your seven address book. Only the fields you supply are stored. Phone numbers may be given in almost any format; seven normalises them. Returns the created contact including its numeric id. Note: seven expects group membership as repeated groups[] form fields, so this action can assign the contact to one group per call; add further memberships with additional Update Contact calls. |
| Create Group | `createGroup` | Create a new contact group in seven. Groups let you address many contacts at once: the group name can be passed as the recipient when sending an SMS, RCS or voice message. Returns the created group including its numeric id. |
| Create Subaccount | `createSubaccount` | Create a subaccount under your seven main account. Subaccounts have their own balance, sender IDs and settings, which makes them useful for separating customers or departments. The new subaccount starts with a zero balance; use Transfer Credits To Subaccount or Configure Subaccount Auto Top-Up to fund it. |
| Create Webhook | `createWebhook` | Register a webhook so seven calls your URL in real time when an event occurs, instead of you polling. Deliveries are signed with X-Signature, X-Timestamp and X-Nonce headers and originate from 195.201.160.143. Failed deliveries are retried up to 14 times over roughly 3.5 days. Returns the new webhook's id. |
| Delete Active Number | `deleteActiveNumber` | Release a virtual phone number booked on your seven account. By default the number is released at the end of the current billing period; set delete_immediately to true to release it at once. A released number can be reactivated within 14 days with Reactivate Number. |
| Delete Contact | `deleteContact` | Permanently remove a contact from your seven address book by its numeric id. The contact is also removed from every group it belonged to. This cannot be undone. |
| Delete Group | `deleteGroup` | Delete a contact group from your seven account. By default the contacts in the group are kept and only lose their membership; set delete_contacts to true to delete the member contacts as well. This cannot be undone. |
| Delete Scheduled SMS | `deleteScheduledSms` | Cancel one or more SMS that were scheduled with a delay and have not yet been dispatched, so they are never sent. Pass the message ids returned by Send SMS. Returns the ids that were actually deleted. |
| Delete Subaccount | `deleteSubaccount` | Permanently delete a subaccount of your seven main account by its id. This cannot be undone. |

## Events

Start a workflow when one of these happens, with an [app event trigger](../../build/triggers/README.md).

| Event | Id | When it fires |
| --- | --- | --- |
| All Events | `all` | Subscribes to every event type seven emits on one hook: sms_mo, dlr, rcs, wa_mo, voice_call, voice_status, voice_dtmf and tracking. Read the webhook_event field of each delivery to tell them apart, since the data object differs per type. Leave event_filter empty. Use this only when you want one endpoint for everything; otherwise subscribe to the specific event. |
| DTMF Keypress Received | `voice_dtmf` | Fires when the recipient of a voice call presses a key on their telephone keypad, so you can build IVR menus and confirmation flows. Carries the digit pressed along with the call's duration and price. Leave event_filter empty. Payload schema modelled from seven's documented sample. |
| Inbound SMS Received | `sms_mo` | Fires when an SMS is received on one of your seven virtual numbers. Optionally restrict it to a single inbound number by setting the event_filter input to that number in international format without a plus (e.g. 4915112345678); leave it empty to receive inbound SMS for every number. Payload schema modelled from seven's documented sample. |
| Inbound Voice Call Received | `voice_call` | Fires when someone calls one of your seven voice-enabled numbers. Leave event_filter empty. Payload schema modelled from seven's documented sample. |
| Inbound WhatsApp Message Received | `wa_mo` | Fires when a WhatsApp user sends a message to your registered WhatsApp Business sender number. Requires a registered WABA sender on the account. Leave event_filter empty. Payload shape modelled on seven's other inbound-message events; seven does not publish a wa_mo sample, so confirm the exact field names against a real delivery before relying on them. |
| Link Click Or View Tracked | `tracking` | Fires when a recipient clicks or views a shortened URL in a message you sent with performance_tracking enabled. Requires a custom domain configured under Settings &gt; Conversion Tracking. Leave event_filter empty. Payload schema modelled from seven's documented sample. |
| RCS Event | `rcs` | Fires for every RCS event on your agents: delivery and read receipts for messages you sent, inbound RCS messages, typing indicators from the user, and selection of a suggested reply. Inspect data.status and data.content_type to tell them apart. Leave event_filter empty. Payload schema modelled from seven's documented samples. |
| SMS Delivery Status Changed | `dlr` | Fires when a network operator reports a new delivery status for an SMS you sent: DELIVERED, NOTDELIVERED, BUFFERED, TRANSMITTED, ACCEPTED, EXPIRED, REJECTED or FAILED. Internal states (Created, Queued, Processed) are not delivered. Leave event_filter empty. Payload schema modelled from seven's documented sample. |
| Voice Call Status Changed | `voice_status` | Fires when a voice call you placed changes status, for example when it completes. Carries the duration and the per-minute price so you can reconcile spend. Leave event_filter empty. Payload schema modelled from seven's documented sample. |
