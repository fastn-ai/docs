# Novu

Novu is an open-source notification infrastructure platform that lets teams orchestrate Email, SMS, Push, In-App, and Chat notifications through code-defined workflows, manage subscribers and their channel preferences, group subscribers into topics, and trigger or broadcast workflow events from any backend.

## Use it

Add Novu from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.novu.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).

## Actions

| Action | Slug | What it does |
| --- | --- | --- |
| Add Subscribers To Topic | `addTopicSubscribers` | Subscribes one or more existing subscribers to a topic, so future notifications sent to that topic reach them. |
| Broadcast Event To All Subscribers | `broadcastEvent` | Triggers a workflow event for every subscriber in the current environment, useful for announcements or platform-wide notices. |
| Bulk Create Subscribers | `bulkCreateSubscribers` | Creates or updates up to 500 subscribers in a single request, useful for initial data import or periodic sync from an external system. |
| Bulk Trigger Workflow Events | `bulkTriggerEvent` | Triggers up to 100 workflow events in a single request, each with its own workflow, recipients, and payload. |
| Bulk Update Subscriber Preferences | `bulkUpdateSubscriberPreferences` | Updates a subscriber's notification channel preferences for multiple workflows in a single request, up to 100 workflow preferences per call. |
| Cancel Triggered Event | `cancelTriggeredEvent` | Cancels a previously triggered event by its transaction ID, halting any pending delayed or digested steps that have not yet executed. |
| Check Topic Subscriber | `checkTopicSubscriber` | Checks whether a subscriber, identified by their external subscriber ID, is subscribed to a given topic. |
| Create Environment | `createEnvironment` | Creates a new environment (e.g. a Staging environment) under the current organization. |
| Create Integration | `createIntegration` | Connects a new provider integration (e.g. an email, SMS, push, or chat provider) to the current environment, storing its credentials for use by workflow steps on that channel. |
| Create Subscriber | `createSubscriber` | Creates a new subscriber in the current Novu environment, identified by a unique subscriber ID, with optional profile fields such as name, email, phone, locale, timezone, and custom data. |
| Create Topic | `createTopic` | Creates a new topic, a named group used to send notifications to many subscribers at once by adding them as topic subscriptions. |
| Create Workflow | `createWorkflow` | Creates a new notification workflow made of one or more steps (e.g. in-app, email, SMS, push, chat, delay, digest), which can later be triggered to deliver notifications to subscribers. |
| Delete Environment | `deleteEnvironment` | Permanently deletes a custom (non-default) environment. The built-in Development and Production environments cannot be deleted. |
| Delete Integration | `deleteIntegration` | Removes a provider integration from the current environment. |
| Delete Message | `deleteMessage` | Deletes a single channel message by its message ID, removing it from the subscriber's activity and in-app inbox. |
| Delete Messages By Transaction ID | `deleteMessagesByTransaction` | Deletes every channel message generated by a specific triggered event, identified by its transaction ID. |
| Delete Subscriber | `deleteSubscriber` | Permanently deletes a subscriber and their associated data from the current environment. |
| Delete Subscriber Channel Credentials | `deleteSubscriberCredentials` | Removes a subscriber's stored credentials for a specific provider, such as a push token or chat webhook, identified by provider ID. |
| Delete Topic | `deleteTopic` | Permanently deletes a topic and all of its subscriptions. |
| Delete Workflow | `deleteWorkflow` | Permanently deletes a workflow and its step configuration from the current environment. |
| Get Environment API Keys | `getEnvironmentApiKeys` | Retrieves the API keys for the environment that the calling secret key belongs to. |
| Get Notification | `getNotification` | Retrieves a single notification activity record by its ID, including the full per-channel job execution details and delivery status. |
| Get Subscriber | `getSubscriber` | Retrieves a single subscriber by its subscriber ID. |
| Get Subscriber Preferences | `getSubscriberPreferences` | Retrieves a subscriber's notification channel preferences, either globally or per workflow, including whether each channel (email, SMS, in-app, push, chat) is enabled. |
| Get Topic | `getTopic` | Retrieves a single topic by its key. |
| Get Topic Subscription | `getTopicSubscription` | Retrieves a single topic subscription by its identifier, in the form tk_{topicKey}:si_{subscriberId}. |
| Get Workflow | `getWorkflow` | Retrieves a single workflow by its workflow ID, including its full step configuration. |
| List Active Integrations | `listActiveIntegrations` | Lists only the currently active provider integrations for the current organization. |
| List Environments | `listEnvironments` | Lists every environment (e.g. Development, Production) belonging to the current organization. |
| List Integrations | `listIntegrations` | Lists every provider integration (email, SMS, push, chat, in-app) configured for the current organization, including their active state and priority. |
| List Messages | `listMessages` | Lists individual channel messages (email, SMS, push, chat, in-app) that were generated by triggered workflows, including their delivery status. Supports filtering by channel, subscriber, and transaction ID. |
| List Notification Activity | `listNotifications` | Lists notification activity logs for the current environment, showing which workflows were triggered, for which subscribers, and their processing status. Supports filtering by channel, workflow, subscriber, and transaction ID. |
| List Subscribers | `listSubscribers` | Searches and lists subscribers in the current Novu environment with cursor-based pagination, optional filters, and sorting. |
| List Topic Subscriptions | `listTopicSubscriptions` | Lists the subscriber subscriptions for a topic, with pagination. |
| List Topics | `listTopics` | Lists topics in the current environment with cursor-based pagination and optional key filtering. |
| List Workflows | `listWorkflows` | Searches and lists notification workflows in the current environment, with optional text search and pagination. |
| Patch Workflow | `patchWorkflow` | Partially updates a workflow, such as toggling its active state or changing its name, description, or tags, without needing to resend the full step configuration. |
| Remove Subscribers From Topic | `removeTopicSubscribers` | Unsubscribes one or more subscribers from a topic, so they no longer receive notifications sent to that topic. |
| Set Integration As Primary | `setIntegrationPrimary` | Marks an active integration as the primary provider for its channel, so it is preferred over other integrations on the same channel. |
| Set Subscriber Channel Credentials | `setSubscriberCredentials` | Fully replaces a subscriber's credentials for a specific push or chat provider, such as a device push token or a chat webhook URL, used to deliver notifications on that channel. |
| Sync Workflow To Environment | `syncWorkflow` | Promotes and synchronizes a workflow's current configuration from this environment into a target environment (e.g. from Development to Production), creating or updating the workflow there. |
| Trigger Workflow Event | `triggerEvent` | Triggers a workflow by its workflow ID for one or more subscribers, sending the notification payload data through the workflow's configured steps and channels. This is the primary way to send a notification. |
| Update Environment | `updateEnvironment` | Updates an environment's name or color. |
| Update Integration | `updateIntegration` | Updates an existing provider integration's name, active state, credentials, or step conditions. |
| Update Subscriber | `updateSubscriber` | Partially updates an existing subscriber's profile fields such as name, email, phone, locale, timezone, and custom data. |
| Update Subscriber Preferences | `updateSubscriberPreferences` | Updates a subscriber's notification channel preferences globally or for a specific workflow, enabling or disabling channels such as email, SMS, in-app, push, and chat. |
| Update Topic | `updateTopic` | Updates a topic's display name. |
| Update Topic Subscription | `updateTopicSubscription` | Updates a topic subscription's per-workflow notification preferences for the subscribed subscriber. |
| Update Workflow | `updateWorkflow` | Fully replaces an existing workflow's name, description, tags, active state, and steps. |
| Upsert Subscriber Channel Credentials | `upsertSubscriberCredentials` | Creates or partially updates a subscriber's credentials for a specific push or chat provider, merging with any existing credentials for that provider instead of replacing them entirely. |
