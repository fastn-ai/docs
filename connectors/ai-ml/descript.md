# Descript

<img src="../../.gitbook/assets/connectors/lg/descript.png" alt="Descript logo">

Descript is an AI audio and video editing platform. This connector covers the complete Descript Public API v1 at https://descriptapi.com/v1: drive status, project listing, project detail, drive-wide search, job listing, job status and job cancellation, media import into new or existing projects (which triggers transcription), Underlord agent edits driven by a natural-language prompt, the list of available agent models, publishing a composition to a shareable rendered link, transcript export in txt, markdown, html, rtf, docx and srt, published-project metadata lookup, and Edit in Descript import URL creation. Authentication is a personal API token created in Descript under Settings &gt; API tokens, sent as Authorization: Bearer. Import, agent and publish jobs are asynchronous and metered (media minutes and AI credits) and accept an optional callback_url that Descript POSTs the finished job payload to.

## Use it

Add Descript from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.descript.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).

## Events

Start a workflow when one of these happens, with an [app event trigger](../../build/triggers/README.md).

<table><thead><tr><th width="240">Event</th><th width="260">Id</th><th>When it fires</th></tr></thead><tbody><tr><td>Agent edit job finished</td><td><code>agent</code></td><td>Fires once when a POST /jobs/agent Underlord edit stops. To receive it, pass the webhook URL as the callback_url input of the Run Agent Edit action; Descript has no webhook registration API. Carries result.agent_response, result.project_changed, result.resolved_model, result.conversation_id and the metered ai_credits_used. A cancelled job delivers job_state cancelled with result.error_message Agent edit was cancelled and ai_credits_used 0.</td></tr><tr><td>Media import job finished</td><td><code>import/project_media</code></td><td>Fires once when a POST /jobs/import/project_media job stops. To receive it, pass the webhook URL as the callback_url input of the Import Project Media action; Descript has no webhook registration API. job_state is stopped or cancelled and result.status is success or failure. Carries result.media_status per imported file, result.media_seconds_used (the metered transcription minutes) and result.created_compositions.</td></tr><tr><td>Publish job finished</td><td><code>publish</code></td><td>Fires once when a POST /jobs/publish render stops. To receive it, pass the webhook URL as the callback_url input of the Publish Project action; Descript has no webhook registration API. Carries result.share_url, result.composition_id, result.media_type and a time-limited result.download_url with result.download_url_expires_at.</td></tr></tbody></table>
