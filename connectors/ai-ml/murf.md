# Murf

<img src="../../.gitbook/assets/connectors/lg/murf.png" alt="Murf logo">

Murf AI — text-to-speech, voice changer, translation, instant voice cloning and Murf Dub automation. Wraps the Murf REST API at https://api.murf.ai (OpenAPI 3.1). Authenticates with the account api-key header.

## Use it

Add Murf from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.murf.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).

## Events

Start a workflow when one of these happens, with an [app event trigger](../../build/triggers/README.md).

<table><thead><tr><th width="240">Event</th><th width="260">Id</th><th>When it fires</th></tr></thead><tbody><tr><td>Dub Job Finished</td><td><code>DUB_JOB</code></td><td>Murf's only webhook. Fires when a Murf Dub job completes, fails or partially completes. THERE IS NO SUBSCRIBE OR UNSUBSCRIBE API: registration is per job. To receive it, pass this trigger's URL as webhook_url (and a shared secret as webhook_secret) on the Create Dub Job or Create Dub Job In Project action; that job is then the only source of deliveries, and you stop them by not passing webhook_url on the next job. Murf signs each delivery with X-Signature-Timestamp and X-HMAC-Signature = HMAC-SHA256(webhook_secret, compact-JSON payload + timestamp); verify it and reject stale timestamps. Requires a Murf Dub API key. payloadSchema is MODELLED from Murf's published webhook documentation and its Get Dub Job Status response shape - no live delivery was capturable because the account's TTS key is refused by the dubbing product.</td></tr></tbody></table>
