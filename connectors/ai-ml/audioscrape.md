# Audioscrape

<img src="../../.gitbook/assets/connectors/lg/audioscrape.png" alt="Audioscrape logo">

Audioscrape is an audio intelligence platform: a searchable, speaker-attributed record of 18M+ public podcast episodes plus your own uploaded calls, meetings and recordings. This connector covers the complete Audioscrape REST API (hybrid, text and semantic search; podcasts, episodes and transcripts; audio items and uploads; persons and speakers; knowledge-graph entities and trending; podcast charts and ranking history; libraries, datasets and workspaces; workspace data export; API keys; account, plan and usage) and every tool of the Audioscrape remote MCP server (mcp.audioscrape.com) called over JSON-RPC, including transcription jobs, upload URLs, entity relationship graphs, episode overviews and share links.

## Use it

Add Audioscrape from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.audioscrape.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).

## Actions

| Action | Slug | What it does |
| --- | --- | --- |
| Create Agent Checkout | `createAgentCheckout` | Agent-initiated purchase: returns a Stripe-hosted checkout URL for the given email and plan so a person can complete payment themselves. Nothing is charged by this call and no email is sent. The account is created when the person signs in after paying. No API key is required by the vendor for this endpoint. |
| Create API Key | `createApiKey` | Generates a new workspace-scoped API key. The full key_value is returned only in this response (Audioscrape stores a hash), so save it immediately. Optionally set an expiry and pin the key to one workspace you belong to. The number of keys is limited by the plan (max_api_keys on Get Current User). |
| Create Workspace Export | `createWorkspaceExport` | Starts an asynchronous job that packages a workspace's audio files, transcripts, items and metadata into one downloadable archive. Only workspace owners or admins may call it, and at most one job per workspace can be queued or running at a time (further requests return 429). Poll Get Workspace Export with the returned job_id. |
| Delete API Key | `deleteApiKey` | Revokes an API key immediately; any request using the revoked key fails with 401 from then on. Returns no body on success (204). |
| Get API Key Usage | `getApiKeyUsage` | Returns how many requests authenticated with an API key over the trailing 30 days. Pair it with last_used from List API Keys to audit a credential before revoking or rotating it. |
| Get Current Usage | `getCurrentUsage` | Returns this calendar month's usage counters (searches, semantic searches, data calls, keyword alerts) alongside the plan's configured limits. Use it to check remaining quota before a heavy burst of searches. |
| Get Current User | `getCurrentUser` | Returns the authenticated user, their current workspace, plan name and per-resource plan limits, the API key that authenticated the request and the effective dated API version. Use it as the first call in an integration to verify credentials and discover which features the plan includes. |
| Get Dataset | `getDataset` | Returns a dataset together with a reference to its parent library in a single response. Data endpoint: requires a plan with data-API calls; the free plan returns DATA_CALLS_NOT_IN_PLAN. |
| Get Entity | `getEntity` | Returns a knowledge-graph entity (person, organisation, place, topic or product) plus the episodes where it is most mentioned. Optionally count and list only episodes from one dataset. Data endpoint: requires a plan with data-API calls; the free plan returns DATA_CALLS_NOT_IN_PLAN. |
| Get Episode | `getEpisode` | Returns a podcast episode's metadata, its parent podcast and extracted entities. Heavy fields are opt-in through the include parameter (transcript, entities). Data endpoint: requires a plan with data-API calls; the free plan returns DATA_CALLS_NOT_IN_PLAN. |
| Get Episode Transcript | `getEpisodeTranscript` | Returns a podcast episode's transcript on its own: speaker-attributed segments with start and end times plus the speaker list. A 206 response carries a partial object while transcription is still in progress. Data endpoint: requires a plan with data-API calls; the free plan returns DATA_CALLS_NOT_IN_PLAN. |
| Get Item | `getItem` | Returns one audio item of any source type (podcast episode, upload or other) with its parent podcast when present. Heavy fields are opt-in through the include parameter (transcript, entities). Data endpoint: requires a plan with data-API calls; the free plan returns DATA_CALLS_NOT_IN_PLAN. |
| Get Item Transcript | `getItemTranscript` | Returns the transcript of any audio item regardless of source type: speaker-attributed segments with timestamps plus the speaker list. A 206 response carries a partial object while transcription is still in progress. Data endpoint: requires a plan with data-API calls; the free plan returns DATA_CALLS_NOT_IN_PLAN. |
| Get Library | `getLibrary` | Returns one library plus the datasets the calling user can see: public datasets always, workspace-scoped datasets only for members. Data endpoint: requires a plan with data-API calls; the free plan returns DATA_CALLS_NOT_IN_PLAN. |
| Get Person | `getPerson` | Returns a person (speaker) plus up to 20 recent episode appearances where they are attributed as a speaker. Data endpoint: requires a plan with data-API calls; the free plan returns DATA_CALLS_NOT_IN_PLAN. |
| Get Podcast | `getPodcast` | Returns podcast metadata plus up to 20 most recent episodes. The identifier accepts either a numeric podcast id or a URL slug. Data endpoint: requires a plan with data-API calls; the free plan returns DATA_CALLS_NOT_IN_PLAN. |
| Get Podcast Ranking History | `getPodcastRankingHistory` | Returns a podcast's historical chart positions across countries and platforms, most recent first. The identifier accepts either a numeric podcast id or a URL slug. Data endpoint: requires a plan with data-API calls; the free plan returns DATA_CALLS_NOT_IN_PLAN. |
| Get Service Health | `getServiceHealth` | Liveness probe for the Audioscrape API. Returns status "healthy" with a timestamp whenever the API is responding; it does not check downstream dependencies. |
| Get Trending | `getTrending` | Returns what is trending across Audioscrape in the last 7 days: the most-searched queries and the most-mentioned entities. Data endpoint: requires a plan with data-API calls; the free plan returns DATA_CALLS_NOT_IN_PLAN (the MCP Get Trending action is available on every plan). |
| Get Workspace | `getWorkspace` | Returns one of your workspaces plus all of its datasets regardless of visibility, including private datasets that never appear under libraries. Members only; a workspace you do not belong to returns 404. Data endpoint: requires a plan with data-API calls; the free plan returns DATA_CALLS_NOT_IN_PLAN. |
| Get Workspace Export | `getWorkspaceExport` | Returns the lifecycle state of a workspace export job. When status is completed, download_url holds a signed URL valid until download_expires_at. Any workspace member may call it. |
| List API Keys | `listApiKeys` | Returns all API keys belonging to the calling user. key_value is always null here; only the display key_prefix is recoverable after creation. Use Rotate API Key to obtain a fresh secret. |
| List Chart Podcasts | `listChartPodcasts` | Returns the latest Apple Podcasts or Spotify podcast chart for a country (charts are ingested daily). When platform is omitted, results from both platforms are interleaved. Data endpoint: requires a plan with data-API calls; the free plan returns DATA_CALLS_NOT_IN_PLAN. |
| List Items | `listItems` | Lists audio items of every content type (podcast episodes, uploads and other sources), newest first. Filter by source type, dataset id or library slug. Data endpoint: requires a plan with data-API calls; the free plan returns DATA_CALLS_NOT_IN_PLAN. |
| List Libraries | `listLibraries` | Returns every public library on Audioscrape ordered by subscriber count; is_subscribed tells you whether the calling user is a member. Data endpoint: requires a plan with data-API calls; the free plan returns DATA_CALLS_NOT_IN_PLAN. |
| List Podcast Episodes | `listPodcastEpisodes` | Returns the episodes of a single podcast, newest first, with pagination. The identifier accepts either a numeric podcast id or a URL slug. Data endpoint: requires a plan with data-API calls; the free plan returns DATA_CALLS_NOT_IN_PLAN. |
| List Recent Episodes | `listRecentEpisodes` | Returns the most recently published podcast episodes across all podcasts, newest first, with transcript availability. Data endpoint: requires a plan that includes data-API calls (Starter or higher); the free plan returns an explicit DATA_CALLS_NOT_IN_PLAN error. |
| List Workspace Datasets | `listWorkspaceDatasets` | Returns every dataset in one of your workspaces (public, workspace and private alike). Members only. Data endpoint: requires a plan with data-API calls; the free plan returns DATA_CALLS_NOT_IN_PLAN. |
| List Workspaces | `listWorkspaces` | Returns every workspace the calling user is a member of with their role in each; is_current marks the workspace the API key is scoped to. Data endpoint: requires a plan with data-API calls; the free plan returns DATA_CALLS_NOT_IN_PLAN. |
| MCP Create Share Link | `mcpCreateShareLink` | Calls the create_share_link tool of the Audioscrape MCP server: creates a shareable URL for a specific audio moment that unfurls with a social-media preview card. Optionally embed a quote and a timestamp; omit the timestamp to share the whole item. The tool result is returned in result.structuredContent and as a JSON string in result.content[0].text. |
| MCP Fetch | `mcpFetch` | Calls the fetch compatibility tool of the Audioscrape MCP server: returns the full transcript of a search result (an id such as ep_12345 from MCP Search) as one plain-text document. Prefer MCP Get Transcript for typed, timestamped segments. The tool result is returned in result.structuredContent and as a JSON string in result.content[0].text. |
| MCP Get Charts | `mcpGetCharts` | Calls the get_charts tool of the Audioscrape MCP server: returns current Apple Podcasts and Spotify chart rankings for a country. Omit platform to get both (each item carries a platform field). The tool result is returned in result.structuredContent and as a JSON string in result.content[0].text. |
| MCP Get Entity Graph | `mcpGetEntityGraph` | Calls the get_entity_graph tool of the Audioscrape MCP server: given an entity, returns its typed relationships (employed_by, founded, supports, opposes, competes_with, invested_in and more) with quote evidence from the source audio. With a second entity it returns how the two are connected. Relationships are machine-extracted claims, not verified facts. The tool result is returned in result.structuredContent and as a JSON string in result.content[0].text. |
| MCP Get Episode Overview | `mcpGetEpisodeOverview` | Calls the get_episode_overview tool of the Audioscrape MCP server: one small response with an episode's titled, timestamped chapters, speakers, most-mentioned entities and metadata. Far cheaper than reading the full transcript; drill into a chapter with MCP Get Transcript using the chapter's start_time. The tool result is returned in result.structuredContent and as a JSON string in result.content[0].text. |
| MCP Get Speaker | `mcpGetSpeaker` | Calls the get_speaker tool of the Audioscrape MCP server: returns a speaker's bio and audio appearances across podcasts and uploads. Use MCP Search Speakers first to find the person slug. The tool result is returned in result.structuredContent and as a JSON string in result.content[0].text. |
| MCP Get Transcript | `mcpGetTranscript` | Calls the get_transcript tool of the Audioscrape MCP server: returns speaker-identified transcript segments with timestamps plus metadata for one audio item (podcast episode or upload). Long episodes are paged: when the coverage object reports truncated=true, call again with start_time set to coverage.next_start_time. The tool result is returned in result.structuredContent and as a JSON string in result.content[0].text. |
| MCP Get Transcription Status | `mcpGetTranscriptionStatus` | Calls the get_transcription_status tool of the Audioscrape MCP server: returns the status of a transcription job (pending, running, waiting, completed, failed), its pipeline stage, progress for long recordings and, when complete, the episode_id to use with MCP Search Audio or MCP Get Transcript. The tool result is returned in result.structuredContent and as a JSON string in result.content[0].text. |
| MCP Get Trending | `mcpGetTrending` | Calls the get_trending tool of the Audioscrape MCP server: returns the people, topics and organizations currently trending across recently transcribed audio. The tool result is returned as a JSON string in result.content[0].text (fields trending_entities and trending_searches). |
| MCP List My Datasets | `mcpListMyDatasets` | Calls the list_my_datasets tool of the Audioscrape MCP server: lists the libraries the user is subscribed to and the datasets inside each, with curator, role and counts of podcasts, episodes and duration. Takes no arguments. The tool result is returned in result.structuredContent and as a JSON string in result.content[0].text. |
| MCP List My Uploads | `mcpListMyUploads` | Calls the list_my_uploads tool of the Audioscrape MCP server: lists audio you have uploaded and transcribed into your private workspace (excludes the public podcast corpus). The tool result is returned in result.structuredContent and as a JSON string in result.content[0].text. |
| MCP List Podcast Episodes | `mcpListPodcastEpisodes` | Calls the list_podcast_episodes tool of the Audioscrape MCP server: lists the transcribed episodes of one podcast, newest first, under a coverage header that says whether transcripts are current for the show. Use MCP Search Podcasts first to find the podcast id. The tool result is returned in result.structuredContent and as a JSON string in result.content[0].text. |
| MCP List Recent Transcripts | `mcpListRecentTranscripts` | Calls the list_recent_transcripts tool of the Audioscrape MCP server: lists recently transcribed audio (podcast episodes plus your uploads) ordered by date, optionally scoped to specific podcast ids. The tool result is a JSON-encoded array of episodes (id, title, description, publish_date, url) in result.content[0].text. |
| MCP List Tools | `mcpListTools` | Calls the tools/list method of the Audioscrape MCP server (mcp.audioscrape.com) and returns every available tool with its name, description, annotations and JSON input schema. Use it to discover tools before calling them with the MCP actions. |
| MCP Request Upload URL | `mcpRequestUploadUrl` | Calls the request_upload_url tool of the Audioscrape MCP server: returns a one-time URL to which raw audio or video bytes can be PUT within 15 minutes for transcription. The PUT response contains a job_id to poll with MCP Get Transcription Status. Prefer MCP Transcribe Audio when the file is reachable by link. The tool result is returned in result.structuredContent and as a JSON string in result.content[0].text. |
| MCP Search | `mcpSearch` | Calls the search compatibility tool of the Audioscrape MCP server: returns episode-level citable documents (id, title, url) for a query. Prefer MCP Search Audio for segment-level results with timestamps and speakers. Counts against the plan's search quota. The tool result is returned in result.structuredContent and as a JSON string in result.content[0].text. |
| MCP Search Audio | `mcpSearchAudio` | Calls the search_audio tool of the Audioscrape MCP server: searches all transcribed audio (public podcasts plus your uploads) for a topic, phrase or speaker and returns matching segments with timestamps, speakers and snippets. Text mode needs the words spoken close together; use semantic for conceptual questions. Searches count against the plan's monthly search quota. The tool result is returned as JSON in result.structuredContent and as a JSON string in result.content[0].text. |
| MCP Search Entities | `mcpSearchEntities` | Calls the search_entities tool of the Audioscrape MCP server: searches the knowledge graph for people, companies, locations, topics and products mentioned in transcribed audio, optionally filtered by entity type or dataset. The tool result is returned in result.structuredContent and as a JSON string in result.content[0].text. |
| MCP Search Podcasts | `mcpSearchPodcasts` | Calls the search_podcasts tool of the Audioscrape MCP server: searches the podcast catalog by title. Each hit carries searchable (has any transcript) and coverage (transcribed_episodes, last_transcribed, newest_feed_episode, current) so you can tell how much of a show is searchable. The tool result is returned in result.structuredContent and as a JSON string in result.content[0].text. |
| MCP Search Speakers | `mcpSearchSpeakers` | Calls the search_speakers tool of the Audioscrape MCP server: searches speakers and hosts by name across all transcribed audio and returns matching people with their slug for MCP Get Speaker. The tool result is returned in result.structuredContent and as a JSON string in result.content[0].text. |
| MCP Transcribe Audio | `mcpTranscribeAudio` | Calls the transcribe_audio tool of the Audioscrape MCP server: transcribes an audio or video file with speaker diarization and indexes it into your private workspace. Pass audio_url as a direct media link or a Google Drive, Dropbox or OneDrive share link ("anyone with the link"). Returns a job_id to poll with MCP Get Transcription Status. Transcription minutes count against the plan quota. The tool result is returned in result.structuredContent and as a JSON string in result.content[0].text. |
| Rotate API Key | `rotateApiKey` | Atomically replaces an API key's secret while keeping its id, name, workspace pin and expiry. The old secret stops working the moment this call returns and the new secret is returned once in key_value. Rotating the key used by this connection invalidates the connection until it is re-saved with the new key. |
| Search Audio | `searchAudio` | Searches the transcribed audio corpus (public podcasts plus your own uploads) and returns segment-level results with timestamps, highlights and the parent episode and podcast. Search type auto-detects: boolean or quoted queries use text search, others hybrid. Semantic and hybrid searches count against the plan's semantic search quota (0 on the free plan, which returns an explicit plan-gate error). Filter by content type, podcast ids, speakers, publish-date range or tenancy scope. |
| Search Entities | `searchEntities` | Searches the knowledge-graph index for entities (people, organisations, places, topics, products) extracted from audio content, sorted by total mention count. Optionally filter by entity type or restrict to entities mentioned in one dataset. Data endpoint: requires a plan with data-API calls; the free plan returns DATA_CALLS_NOT_IN_PLAN. |
| Search Persons | `searchPersons` | Searches the persons index by name. Persons are speakers identified across transcripts: every speaker attributed to at least one segment. Data endpoint: requires a plan with data-API calls; the free plan returns DATA_CALLS_NOT_IN_PLAN. |
| Search Podcasts | `searchPodcasts` | Lists podcasts, optionally filtered by title substring or ISO 639-1 language, ordered by episode count then alphabetically. Data endpoint: requires a plan with data-API calls; the free plan returns DATA_CALLS_NOT_IN_PLAN. |
| Send Agent Payment Link | `sendAgentPaymentLink` | Agent-initiated purchase: emails a Stripe checkout link for the given plan to the person's email address instead of returning it. Rate limited to 3 emails per address per day; sent is false when the cap was reached. This delivers a real email, so only use it with a person who asked for it. No API key is required by the vendor for this endpoint. |
| Upload Audio To Dataset | `uploadAudioToDataset` | Uploads audio hosted at a public HTTPS URL into one of your datasets and queues it for transcription with speaker separation. Audioscrape downloads and stores a copy; transcription minutes count against the plan's monthly quota. The caller must be a member of the dataset's parent library. URLs resolving to private or internal IP ranges are rejected with 422. Multipart file uploads are not supported by this action; host the file and pass its URL. Poll Get Item for processing_status after upload. |

## Events

Start a workflow when one of these happens, with an [app event trigger](../../build/triggers/README.md).

| Event | Id | When it fires |
| --- | --- | --- |
| Keyword Alert Match | `alert.match` | Fires when newly transcribed audio matches a standing keyword alert in your workspace. Registration is manual in the Audioscrape web app: open your workspace, go to the Integrations tab, add a webhook feed, paste the fastn trigger URL, then create alerts with 'Alert me on new results' on any search, person or entity page and choose webhook delivery. Webhook delivery requires a plan with webhooks enabled (webhooks_enabled on Get Current User; not available on the free plan). Audioscrape does not publish the payload outside the Integrations tab, so the payload schema below is modelled from the documented alert digest fields (episode or meeting title and source, speaker, transcript snippet, deep link) and is NOT a captured delivery; confirm the real shape and the event-type field from the Integrations tab delivery log before relying on field paths. |
