# Copyleaks

<img src="../../.gitbook/assets/connectors/lg/copyleaks.png" alt="Copyleaks logo">

Copyleaks is an AI-powered content authenticity platform: plagiarism detection, AI-generated text, image and video detection, grammar checking, text moderation, object detection and image plagiarism search. This connector covers the Copyleaks REST API (https://api.copyleaks.com): account login, credit balance and usage history, submitting files, URLs and OCR images for authenticity scans, starting, deleting and re-notifying scans, exporting reports, the synchronous AI text, AI image, image plagiarism, object detection, grammar and text moderation checks, the asynchronous AI image and video detectors, supported languages and file types, and Private Cloud Hub repository information.

## Use it

Add Copyleaks from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.copyleaks.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).

## Events

Start a workflow when one of these happens, with an [app event trigger](../../build/triggers/README.md).

<table><thead><tr><th width="240">Event</th><th width="260">Id</th><th>When it fires</th></tr></thead><tbody><tr><td>Credits Checked</td><td><code>2</code></td><td>Fired when a scan submitted with properties.action 1 (check credits) has been priced. Pass this trigger's URL as properties.webhooks.status when submitting. The payload carries status 2 and the number of credits the full scan will cost; call Start Scans within 48 hours to run it.</td></tr><tr><td>Document Indexed</td><td><code>3</code></td><td>Fired when a document submitted with properties.action 2 (index only) has been indexed in the Shared Data Hub or a repository. Pass this trigger's URL as properties.webhooks.status when submitting. The payload carries status 3.</td></tr><tr><td>Scan Completed</td><td><code>0</code></td><td>Fired when an authenticity scan finishes successfully. Copyleaks has no webhook registration API: when you submit a scan (Submit URL Scan, Submit File Scan or Submit OCR Scan) pass this trigger's URL as properties.webhooks.status, e.g. https://&lt;fastn-trigger-url&gt;?event={STATUS}. The status webhook payload carries status 0 for completed scans; the scanned document, results and score are in the body.</td></tr><tr><td>Scan Error</td><td><code>1</code></td><td>Fired when a scan ends with an error. Pass this trigger's URL as properties.webhooks.status when submitting the scan. The payload carries status 1 and an error object with type, id, code and message.</td></tr></tbody></table>
