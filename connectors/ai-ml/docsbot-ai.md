# DocsBot AI

<img src="../../.gitbook/assets/connectors/docsbot-ai.png" alt="DocsBot AI logo" width="64">

DocsBot AI is a documentation-chatbot and AI agent platform. This connector covers the full DocsBot Admin API (teams, team members and invites, bots, sources, source tags, questions, conversations, leads, statistics, reports, deep-research jobs, skills, workspace agent and webhooks) on https://docsbot.ai/api, and the full DocsBot Chat API (chat agent, legacy chat and ask, semantic search, document fetch, answer rating, support escalation, lead capture, conversation summaries and tickets, deep research and voice sessions) on https://api.docsbot.ai.

## Use it

Add DocsBot AI from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.docsbotAi.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).

## Actions

| Action | Slug | What it does |
| --- | --- | --- |
| Ask Bot Question (Legacy) | `askBotQuestionLegacy` | Asks a DocsBot bot a single question through the legacy question-and-answer endpoint and returns one answer with its sources, without conversation state. Kept for backwards compatibility; use Ask Chat Agent for new integrations. Consumes AI credits. |
| Ask Chat Agent | `askChatAgent` | Asks a DocsBot bot a question through the Chat Agent API, the current conversational endpoint. Pass a conversation id you generate to keep a thread going, and enable the agent tools you want for the turn. Returns the answer with its cited sources. Each answered question consumes AI credits from the team's monthly allowance, and web search costs 10 additional credits per search. |
| Call Documentation MCP Server | `callDocumentationMcpServer` | Sends a JSON-RPC request to a DocsBot bot's Documentation MCP server, which exposes search tools over the bot's indexed content to MCP clients. Use method tools/list to discover the tools and tools/call to run one. Responses arrive as a server-sent event stream. MCP access requires the Standard plan and above. |
| Call Question History MCP Server | `callQuestionsMcpServer` | Sends a JSON-RPC request to a DocsBot bot's Question History MCP server, which exposes tools for searching the bot's logged questions and answers. Use method tools/list to discover the tools and tools/call to run one. Responses arrive as a server-sent event stream. MCP access requires the Standard plan and above. |
| Cancel Deep Research Job | `cancelDeepResearchJob` | Cancels a running or clarifying DocsBot deep research job so it stops consuming AI credits. The job record is kept with a cancellation timestamp. |
| Capture Conversation Lead | `captureConversationLead` | Saves lead details such as name, email, company or phone against a DocsBot Chat Agent conversation and merges them into the conversation metadata. The lead is always saved even when the conversation does not yet exist, and capturing one fires the lead.created webhook. |
| Chat With Bot (Legacy) | `chatWithBotLegacy` | Asks a DocsBot bot a question through the legacy stateless Chat API, optionally passing prior turns as history and receiving the updated history to send with the next request. DocsBot marks this API deprecated and recommends Ask Chat Agent for new integrations. Consumes AI credits. |
| Continue Deep Research Job | `continueDeepResearchJob` | Answers the clarifying questions of a DocsBot deep research job and queues the job to run. Returns the updated job record. The research itself completes asynchronously; poll Get Deep Research Job Status or subscribe to the deep_research.done webhook. |
| Create Bot | `createBot` | Creates a new DocsBot chatbot in a team. The number of bots is capped by the team plan, so this returns HTTP 402 with an upgrade message once the bot limit is reached. Pass copyFrom to clone an existing bot together with its sources. Returns the created bot object including its id and signature key. |
| Create Bot Image Upload URL | `createBotImageUploadUrl` | Creates a short-lived signed URL for uploading a bot widget image such as a chat bubble icon, chat avatar or header logo. Upload the raw bytes to the returned uploadUrl with a PUT and the exact returned content type, then save the returned public CDN URL on the bot with Update Bot. Only raster formats (png, jpg, jpeg, gif, webp) are accepted; SVG is rejected. |

## Events

Start a workflow when one of these happens, with an [app event trigger](../../build/triggers/README.md).

| Event | Id | When it fires |
| --- | --- | --- |
| Conversation Answer Rated | `conversation.rated` | Fires when a visitor rates one of the bot's answers through the Rate Answer endpoint or the widget thumbs control. Set the teamId and botId inputs when subscribing. Payload schema modelled from the vendor's documented sample in the Webhooks API docs, not captured from a live delivery. |
| Conversation Escalated | `conversation.escalated` | Fires when a conversation escalation is confirmed through the Escalate Conversation endpoint, which sets the conversation to escalated handled. Payload schema modelled from the vendor's documented sample in the Webhooks API docs, not captured from a live delivery. |
| Deep Research Completed | `deep_research.done` | Fires when a deep research job on the bot finishes, carrying the final markdown answer. Set the teamId and botId inputs when subscribing. Payload schema modelled from the vendor's documented sample in the Webhooks API docs, not captured from a live delivery. |
| Lead Created | `lead.created` | Fires when DocsBot captures lead data on a bot conversation, for example when the Capture Conversation Lead endpoint or the widget lead form saves a visitor's details. Set the teamId and botId inputs when subscribing. Payload schema modelled from the vendor's documented sample in the Webhooks API docs, not captured from a live delivery. |
