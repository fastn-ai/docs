# Eden AI

<img src="../../.gitbook/assets/connectors/lg/eden-ai.png" alt="Eden AI logo">

Eden AI is a unified AI gateway giving access to 500+ models from 50+ providers through one API. This connector covers the full Eden AI v3 API: OpenAI-compatible chat completions, responses, embeddings, moderation, Anthropic messages, image generation and editing, audio transcription and speech, video generation, the Universal AI expert-model endpoint (text analysis, web scraping and search, OCR and document parsing, image analysis, translation, text-to-speech) with typed actions per feature, asynchronous jobs, collections, file uploads, model and feature catalogs, and the organization Management API (API keys, management keys, members, groups and usage).

## Use it

Add Eden AI from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.edenAi.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).

## Events

Start a workflow when one of these happens, with an [app event trigger](../../build/triggers/README.md).

<table><thead><tr><th width="240">Event</th><th width="260">Id</th><th>When it fires</th></tr></thead><tbody><tr><td>Async Job Completed</td><td><code>async_job_completed</code></td><td>Sent by Eden AI when an asynchronous Universal AI job (speech-to-text, multipage OCR, table extraction, web crawl/batch scrape/structured extraction/deep research, video generation, video deepfake detection) finishes with status success or fail. Eden AI has no webhook registration API: pass this trigger's webhook URL as webhook_receiver (and optionally user_webhook_parameters for correlation) in Create Async Job or any typed async action such as Transcribe Audio, Extract Text From Document or Crawl Website. Each delivery is a JSON POST with headers X-Edenai-Webhook: true, X-Edenai-Signature (RSA PKCS1 v1.5 / SHA-256 hex signature of the canonical JSON body, verified with the public key obtained from Eden AI support) and X-Edenai-Hash-Algorithm: SHA256. RSA signature verification is not expressible in fastn's HMAC verification, so it is left unset here; verify downstream if required. Payload shape modelled from the official webhook documentation (https://www.edenai.co/docs/v3/expert-models/webhooks) because job creation is credit-gated on the test account.</td></tr></tbody></table>
