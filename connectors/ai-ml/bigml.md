# BigML

<img src="../../.gitbook/assets/connectors/lg/bigml.png" alt="BigML logo">

This connector covers the full BigML.io REST API (andromeda version, https://bigml.io/andromeda): list / get / create / update / delete for every resource type — projects, external connectors, sources, composites, datasets, samples, correlations, statistical tests, configurations, models, ensembles, linear and logistic regressions, deepnets, fusions, OptiMLs, time series, PCAs, clusters, anomaly detectors, associations, topic models, predictions, batch predictions, centroids, batch centroids, anomaly scores, batch anomaly scores, association sets, topic distributions, batch topic distributions, projections, batch projections, forecasts, evaluations, and WhizzML scripts, libraries and executions. Resource creation is asynchronous (poll status.code == 5). Authenticates with username + API key as query parameters.

## Use it

Add BigML from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.bigml.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).
