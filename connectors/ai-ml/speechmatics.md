# Speechmatics

<img src="../../.gitbook/assets/connectors/lg/speechmatics.png" alt="Speechmatics logo">

Submit pre-recorded audio to the Batch Transcription (ASR) API, poll job status, retrieve transcripts in JSON, plain text or SRT, download the original media, read usage statistics, and administer workspace projects and API keys through the Management API.

| | |
| --- | --- |
| **Category** | [AI and ML](README.md) |
| **Website** | [speechmatics.com](https://speechmatics.com) |
| **Authentication** | Credentials you enter |
| **Slug** | `speechmatics` |

## Use it

Add Speechmatics from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.speechmatics.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).
