# HappyScribe

<img src="../../.gitbook/assets/connectors/lg/happyscribe.png" alt="HappyScribe logo">

HappyScribe transcription, subtitling and translation platform. Submit media for automatic or human transcription, manage transcriptions, folders, glossaries and style guides, export transcripts to 20+ formats, order translations, dispatch an AI notetaker to Zoom/Google Meet/Microsoft Teams calls, and manage workspace members. Wraps the HappyScribe REST API v1 at https://www.happyscribe.com/api/v1.

| | |
| --- | --- |
| **Category** | [AI and ML](README.md) |
| **Website** | [happyscribe.com](https://happyscribe.com) |

## Use it

Add HappyScribe from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.happyscribe.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).

## Actions

| Action | Slug | What it does |
| --- | --- | --- |
| Add Organization Membership | `addOrganizationMembership` | Add a user to the connected HappyScribe workspace by e-mail. If the address already belongs to a HappyScribe user the membership is created instantly and returned as 201 with the member object; otherwise HappyScribe e-mails an invitation and returns 202 with the invite. Only the admin and member roles can be assigned here. The caller must be an owner or admin, and the workspace plan must allow the requested role and have a free seat. |
| Confirm Order | `confirmOrder` | Submit a HappyScribe order that was created with confirm=false, moving it out of state "incomplete" and starting processing. THIS SPENDS MONEY: it charges the workspace the amount quoted in the order's details.total_cents (AI transcription is $0.20/minute with a $0.50 minimum charge after the free allowance). Call Get Order first and check details.total_cents and canBeSubmitted. Returns 400 when the order cannot be submitted as it stands and 409 with a Retry-After header while its media is still being ingested. |
| Create Export | `createExport` | Export one or more finished HappyScribe transcriptions to a downloadable file in any of 21 formats - txt, docx, pdf, srt, vtt, stl, json, csv, xlsx, html, premiere, fcp, edl, avid variants, maxqda, facebook_srt - or fetch the source media as mp3/mp4. Exporting an existing transcription is free. Each file takes about 10 seconds; poll Get Export until state is ready, then download from download_link. mp3 and mp4 return state ready and a short-lived download_link immediately and accept exactly one transcription id. |
| Create Meeting | `createMeeting` | Dispatch the HappyScribe AI notetaker to a Zoom, Google Meet or Microsoft Teams call. HappyScribe records it, transcribes it and generates a summary. Returns 201 with the meeting id once the bot is dispatched; the bot usually joins in seconds but can take up to three minutes. Use join_at to schedule a future join instead of joining immediately. Only one active meeting is dispatched per normalised meeting_url and join_at in a workspace - a duplicate request returns the existing meeting unchanged. Creating a meeting does not schedule the underlying call, and there is no API to cancel or delete one. |
| Create Order | `createOrder` | Create a HappyScribe transcription or subtitling order from a publicly reachable media URL. This is the current, recommended replacement for Create Transcription. BILLABLE when confirm is true - the order is submitted and charged immediately. Leave confirm false (the default) to get a priced quote back in state "incomplete" at no cost, review details.total_cents, then call Confirm Order. Automatic (auto) results arrive in seconds to minutes; human (pro) results take hours to days. |
| Create Transcription (Deprecated) | `createTranscription` | DEPRECATED by HappyScribe - use Create Order instead. Submit a publicly reachable media URL for automatic or human transcription/subtitling. BILLABLE: this endpoint charges immediately and has no confirmation step (AI transcription is $0.20/min after the free allowance). Poll Get Transcription until state is automatic_done, then use Create Export to download the text. |
| Create Translation Order | `createTranslationOrder` | Create a HappyScribe translation order from an existing transcription into one or more target languages, producing a new transcription per language. Replaces the deprecated Create Translation Task. BILLABLE when confirm is true; leave confirm false (the default) to get a free priced quote in state "incomplete" and submit it later with Confirm Order. Translating a transcription that is itself a translation automatically uses the original source. |
| Create Translation Task (Deprecated) | `createTranslationTask` | DEPRECATED by HappyScribe - use Create Translation Order instead, which supports several target languages and a confirmation step. Starts a machine translation of an existing transcription into one target language and creates a new transcription holding the result. BILLABLE: there is no confirm step, so this charges as soon as it is called. Poll Get Translation Task until state is done, then read translatedTranscriptionId. |
| Delete Transcription | `deleteTranscription` | Delete a HappyScribe transcription. By default it is moved to the Trash and can be restored; pass permanent=true to delete it irreversibly. Deleting a transcription that is still processing cancels it and refunds the credits it consumed. Late pipeline stages (aligning, retrying, unlocked, automatic_transcribing_second_part, pro_transcribing, human_translating) cannot be cancelled and return 409 Conflict naming the state. |
| Get Company | `getCompany` | HappyScribe Intelligence API: retrieve a single company discovered from your workspace's transcripts, by its integer id. REQUIRES ENROLMENT - the Intelligence API is in private beta and a workspace that is not enrolled gets 404, as does a company id belonging to another workspace. |
| Get Export | `getExport` | Retrieve a HappyScribe export by id to check whether it has finished and to obtain its download_link. Poll this after Create Export until state is ready; expired means the file is no longer available and a new export must be created. |
| Get Meeting | `getMeeting` | Retrieve a HappyScribe notetaker meeting by id, including its lifecycle status, the effective recording settings, and - once ready - the linked transcription id, the full transcript, the plain-text summary, and any associated People and Companies. Poll this when not using meeting webhooks. |
| Get Order | `getOrder` | Retrieve a HappyScribe order by id: its state, the operations it performs, the full pricing breakdown, per-file ingestion progress, and - once fulfilled - outputsIds holding the resulting transcription ids. Use it to price an unconfirmed order before submitting it and to track a submitted one to completion. |
| Get Person | `getPerson` | HappyScribe Intelligence API: retrieve a single person discovered from your workspace's transcripts, by integer id, with their e-mails and linked company. REQUIRES ENROLMENT - the Intelligence API is in private beta and a workspace that is not enrolled gets 404, as does a person id belonging to another workspace. |
| Get Transcription | `getTranscription` | Retrieve a single HappyScribe transcription by id, including its processing state, language, duration, cost, sharing settings, folder and - for notetaker recordings - the linked meeting details. Poll this after creating a transcription or order to see when state becomes automatic_done. |
| Get Transcription Summary | `getTranscriptionSummary` | Retrieve the AI-generated meeting summary for a HappyScribe notetaker recording, given its transcription id. Returns 404 when the transcription is not a notetaker recording or the summary job has not finished yet. |
| Get Translation Task | `getTranslationTask` | Retrieve the status of a HappyScribe translation task. Poll it until state is done, then use translatedTranscriptionId with Get Transcription or Create Export to read the translated content. A failed task carries failureReason. |
| Get Upload URL | `getUploadUrl` | Request a pre-signed AWS S3 URL for uploading a media file to HappyScribe storage. PUT the file to the returned signedUrl (see Upload File To Signed URL), then pass that same URL as the media URL when creating a transcription or an order. Not needed when the media is already reachable at a public URL. |
| List Companies | `listCompanies` | HappyScribe Intelligence API: list the companies discovered from your workspace's meeting transcripts, sorted by name, with enrichment data such as industry, employee count, funding and LinkedIn URL. Paginated. REQUIRES ENROLMENT - the Intelligence API is in private beta and requests from a workspace that is not enrolled return 404; contact HappyScribe support to enrol. |
| List Folders | `listFolders` | List the folders in the connected HappyScribe workspace. Use a folder id to filter List Transcriptions, to move a transcription with Update Transcription, or as the destination for a new order or notetaker recording. The implicit root folder ("All files") is not returned here - read its id from any transcription's folder.id. |
| List Glossaries | `listGlossaries` | List the glossaries available in the connected HappyScribe workspace. Glossaries hold domain terminology that improves transcription and translation accuracy; pass their ids as glossary_ids when creating an order or configuring a notetaker meeting. Glossaries are created in the HappyScribe web app, not through the API. |
| List Organization Memberships | `listOrganizationMemberships` | List the members of the connected HappyScribe workspace with their membership id, e-mail, name and role. Paginated at 25 per page. Filter by exact role, or by a case-insensitive partial match on e-mail or name. The membership id is what Update Membership Role and Remove Membership need. |
| List Organizations | `listOrganizations` | List every HappyScribe workspace (organization) the authenticated API key belongs to, with the caller's role, the owner e-mail, member count, currency and whether human transcription/translation are allowed. Use it to discover the organization id that almost every other HappyScribe endpoint requires. |
| List People | `listPeople` | HappyScribe Intelligence API: list the people (contacts) discovered from your workspace's meeting transcripts, sorted by name, each with their e-mails and their linked company. Job title, seniority, headline, LinkedIn URL, city and country are populated only when person enrichment has been opted into - otherwise they are null. REQUIRES ENROLMENT - the Intelligence API is in private beta and a workspace that is not enrolled gets 404. |
| List Style Guides | `listStyleGuides` | List the style guides available in the connected HappyScribe workspace, with their verbatim, grammar-fixing, SDH, speaker-identification and notation-tag settings. Pass an id as style_guide_id when creating an order to apply those formatting preferences; on pro orders the verbatim and SDH addons are then applied automatically. Style guides are created in the HappyScribe web app. |
| List Transcriptions | `listTranscriptions` | List the transcriptions in the connected HappyScribe workspace, most recent first. Returns metadata only (id, name, folder, state, language, duration, cost, tags, media URLs) - not the transcript text; use Create Export to fetch the actual content. Supports paging and filtering by folder. Note: HappyScribe documents a tags[] filter on this endpoint but it is not applied server-side (a non-matching tag still returns every transcription), so it is deliberately not exposed here. |
| Remove Organization Membership | `removeOrganizationMembership` | Remove a member from the connected HappyScribe workspace by membership id. Returns 204 No Content on success. The workspace owner cannot be removed; the caller must be an owner or admin, although staff members may remove themselves. |
| Update Organization Membership Role | `updateOrganizationMembershipRole` | Change a HappyScribe workspace member's role to admin or member. Get the membership id from List Organization Memberships. The workspace owner's role cannot be changed here, the caller must be an owner or admin, and the plan must allow the requested role. |
| Update Transcription | `updateTranscription` | Rename a HappyScribe transcription, move it to another folder in the same workspace, and/or toggle "anyone with the link" sharing. Any combination of the three can be changed in one call. When sharing is enabled the response carries the publicUrl to share; set it back to false to revoke public access. |
| Upload File To Signed URL | `uploadFileToSignedUrl` | Upload media bytes to the pre-signed AWS S3 URL returned by Get Upload URL. Split the signed URL into its path segments and query parameters and pass them here with the file content. KNOWN LIMITATION: the fastn engine injects the connection's Authorization header on every request and AWS rejects a pre-signed URL that also carries one ("Only one auth mechanism allowed"), so this action cannot currently complete - the same request succeeds with plain curl. Prefer the supported alternative: host the media at any publicly reachable URL and pass that URL straight to Create Order or Create Transcription; HappyScribe accepts YouTube and Vimeo links too. |

## Events

Start a workflow when one of these happens, with an [app event trigger](../../build/triggers/README.md).

| Event | Id | When it fires |
| --- | --- | --- |
| Meeting Cancelled | `meeting.cancelled` | The meeting was cancelled before completion. SETUP (manual, UI only): HappyScribe web app -&gt; Settings -&gt; Webhooks -&gt; add endpoint -&gt; paste the fastn trigger URL -&gt; tick meeting.cancelled -&gt; save, and copy the whsec_ signing secret shown once. HTTPS and a public address are required. |
| Meeting Failed | `meeting.failed` | The notetaker or transcription flow reached a terminal failure; data.object.reason is one of no_recording, invalid_meeting_url, bot_error or transcription_failed. SETUP (manual, UI only): HappyScribe web app -&gt; Settings -&gt; Webhooks -&gt; add endpoint -&gt; paste the fastn trigger URL -&gt; tick meeting.failed -&gt; save, and copy the whsec_ signing secret shown once. HTTPS and a public address are required. |
| Meeting Recording Completed | `meeting.recording_completed` | The provider recording is available for processing. SETUP (manual, UI only): HappyScribe web app -&gt; Settings -&gt; Webhooks -&gt; add endpoint -&gt; paste the fastn trigger URL -&gt; tick meeting.recording_completed -&gt; save, and copy the whsec_ signing secret shown once. HTTPS and a public address are required. |
| Meeting Recording Started | `meeting.recording_started` | The HappyScribe notetaker has entered the call and recording has started. SETUP (manual, UI only - HappyScribe has no webhook registration API): sign in to HappyScribe as an organization administrator, go to Settings -&gt; Webhooks, click to add an endpoint, give it a name, paste the fastn trigger URL, tick the meeting.recording_started event, and save. Copy the signing secret shown once (it begins with whsec_) if you intend to verify signatures. The endpoint must be HTTPS and resolve to a public address; redirects are not followed. |
| Meeting Summary Ready | `meeting.summary_ready` | The plain-text meeting summary has been generated and persisted, and is included at data.object.summary. SETUP (manual, UI only): HappyScribe web app -&gt; Settings -&gt; Webhooks -&gt; add endpoint -&gt; paste the fastn trigger URL -&gt; tick meeting.summary_ready -&gt; save, and copy the whsec_ signing secret shown once. HTTPS and a public address are required. |
| Meeting Transcript Ready | `meeting.transcript_ready` | The full JSON transcript is ready and is included at data.object.transcript. SETUP (manual, UI only): HappyScribe web app -&gt; Settings -&gt; Webhooks -&gt; add endpoint -&gt; paste the fastn trigger URL -&gt; tick meeting.transcript_ready -&gt; save, and copy the whsec_ signing secret shown once. HTTPS and a public address are required. |
