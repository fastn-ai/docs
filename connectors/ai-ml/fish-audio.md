## Setup

Your customers enter their access token for Fish Audio when they connect. Nothing else needs setting up.

## Use it

Add Fish Audio from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.fishAudio.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).

## Events

Start a workflow when one of these happens, with an [app event trigger](../../build/triggers/README.md).

<table><thead><tr><th width="240">Event</th><th width="260">Id</th><th>When it fires</th></tr></thead><tbody><tr><td>Call Analyzed</td><td><code>call.analyzed</code></td><td>Fires when post-call analysis settles (completed, skipped or error), after call.ended for the same session. Payload carries the session facts plus the full analysis entity (summary, data fields, criteria results). Registered per agent via the agent's webhooks.post_call list (Agent ID input required).</td></tr><tr><td>Call Ended</td><td><code>call.ended</code></td><td>Fires when a voice-agent session reaches a terminal state (every real call, whether or not analysis is configured). Payload carries the session facts plus ended_reason (hangup or error). Registered per agent: the subscription adds the fastn URL to the agent's webhooks.post_call list and publishes the agent, so the Agent ID input is required. Deliveries are signed with X-Fish-Webhook-Signature (t=&lt;unix&gt;,v1=&lt;hex HMAC-SHA256 of '{t}.{body}'&gt;) keyed with the per-endpoint secret.</td></tr><tr><td>Phone Call Dial Finished</td><td><code>phone_call.dial_finished</code></td><td>Fires for outbound phone calls as soon as the dial attempt resolves (answered, busy, no_answer or failed), before call.ended. Payload carries the session facts plus top-level dial_status and answered_by. Registered per agent via the agent's webhooks.post_call list (Agent ID input required).</td></tr></tbody></table>
