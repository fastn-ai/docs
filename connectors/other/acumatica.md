# Acumatica

<img src="../../.gitbook/assets/connectors/lg/acumatica.png" alt="Acumatica logo">

Access StockItem, NonStockItem, Customer, Vendor, SalesOrder, PurchaseOrder, Invoice, Bill, Payment, Shipment, InventoryReceipt, InventoryIssue, Account, JournalTransaction, Contact, Lead, Case, Project entities. Base URL: https://{instance}/entity/Default/{endpointVersion}. Auth via login session cookie (POST /entity/auth/login) or OAuth2.

| | |
| --- | --- |
| **Category** | [Other](README.md) |
| **Website** | [acumatica.com](https://acumatica.com) |
| **Authentication** | Credentials you enter, OAuth 2.0 |
| **Slug** | `acumatica` |

## Use it

Add Acumatica from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.acumatica.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).
