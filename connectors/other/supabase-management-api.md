# Supabase Management

Supabase Management API (api.supabase.com/v1): edge functions, SQL/DDL queries, migrations, PostgREST config, project & API key management. Authenticates with an account-level Personal Access Token (sbp_...); the target project is passed per-action via the projectRef input.

| **Authentication** | Credentials you enter, OAuth 2.0 |
| **Actions** | 164 |
| **Events** | 0 |
| **Slug** | `supabaseManagementApi` |

## Use it

Add Supabase Management from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.supabaseManagementApi.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).
