# Vlocity (Salesforce Industries)

<img src="../../.gitbook/assets/connectors/vlocity.ico" alt="Vlocity (Salesforce Industries) logo" width="64">

Vlocity, now sold as Salesforce Industries, is a set of managed packages installed inside a Salesforce org (namespaces vlocity_cmt for Communications/Media/Energy, vlocity_ins for Insurance/Health, vlocity_ps for Public Sector, or omnistudio). This connector covers ONLY the Vlocity-specific Apex REST surface under /services/apexrest/ that the generic Salesforce connector cannot reach: Industries CPQ Cart APIs v2, Digital Commerce v3 and its admin catalog APIs, Enterprise Product Catalog v2, and parameterised invocation of OmniStudio Integration Procedures. Generic vlocity_* sObject CRUD, SOQL, composite, bulk and tooling are deliberately NOT duplicated here - use the Salesforce connector with sobject=vlocity_cmt__PriceList__c and friends. Auth is standard Salesforce OAuth 2.0 against a Connected App in the customer org; the package namespace is a per-connection credential because it is part of every URL path.

## Use it

Add Vlocity (Salesforce Industries) from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.vlocity.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).

## Actions

| Action | Slug | What it does |
| --- | --- | --- |
| Add Items to Cart | `addCartItems` | Industries CPQ postCartsItems: add one or more products to an existing cart. Enforces product eligibility, quantity constraints and cart state validation, and can trigger pricing, validation and promotion logic. The operation is atomic. Each entry in items is an itemJSON structure carrying at minimum itemId. itemId IS A PricebookEntry Id (01u...), NOT a Product2 Id (01t...) - Vlocity says so verbatim when you get it wrong: "PricebookEntry not found for the given PriceBookEntry Ids." The product must also have a vlocity_cmt__ProductChildItem__c row (created automatically by the package's Product2 trigger, or by the Root Product Child Item batch job); without one the call returns 200 with "No PCIs found." Verified end to end on Vlocity CMT 900.442: returns code 150 severity INFO "Successfully added." with the priced line item. |
| Add To or Delete From Existing Basket | `updateBasketContents` | Digital Commerce v3 Basket Operations: add an offer to an existing basket, or delete one from it with deleteBundleNumber. A JSON body is ALWAYS sent (at minimum {}): both required inputs are URL-consumed, so without a bodyTemplate fastn would send no body and Salesforce answers 500 JSONException - same defect class as Run Pricing on Cart. That transport defect is fixed. BLOCKED beyond that on org configuration, same root cause as Create Basket: the shipped VlocityAPIMetadata row for basketOperations carries a NULL APIHandler (only DefaultBasketOperationsRHandler), so Vlocity's router has no handler class and every basket call returns INVOKEMETHOD-405 "Method not found: null". A CME implementation supplies that handler; the managed package does not. |
| Apply Price Adjustment to Cart Item | `applyCartItemAdjustment` | Industries CPQ (Winter '26 Apply Adjustment): apply a manual price adjustment to one cart line item. Verified live on CMT 900.442 that the /v2/cpq/carts/{cartId}/items/{itemId}/pricing path routes. itemId is the CART LINE ITEM Id. A JSON body is ALWAYS sent (at minimum {}): both required inputs are consumed by the URL, so without a bodyTemplate fastn would send no body at all and Salesforce answers 500 System.JSONException "no content to map to Object due to end of input" - the same defect class as Run Pricing on Cart. |
| Apply Promotions to Cart | `addCartPromotionItems` | Industries CPQ postCartsPromoItems: apply one or more promotions to a cart, adding the promotion's items as cart line items. Each entry in items carries the promotion Id (itemId) plus any configuration the promotion requires. |
| Checkout Cart | `checkoutCart` | Industries CPQ: submit the cart for checkout - converts an Opportunity to a Quote, a Quote to an Order, or an Order to Assets. NOT REVERSIBLE when submitOrder is true. A JSON body is ALWAYS sent (at minimum {}): cartId is URL-consumed, so without a bodyTemplate fastn would send no body and Salesforce answers 500 JSONException - same defect class as Run Pricing on Cart. That transport defect is fixed and the body now goes out correctly. BLOCKED beyond that on org configuration: on Vlocity CMT 900.442 with submitOrder false and checkOrderStatus false, against a priced cart holding a real line item, this returns HTTP 200 with INVOKE-500 severity ERROR "Attempt to de-reference a null object". Checkout needs the CME object and field mappings (CustomObjectMap/CustomFieldMap) that a CME implementation supplies; the managed package alone does not. Same unconditional NPE family as Create Cart and Get Eligible Products. |
| Create Basket | `createBasket` | Digital Commerce v3: create a basket by adding an offer to a new virtual basket. Returns a cartContextKey that identifies the basket on later calls. BLOCKED on org configuration. Measured on Vlocity CMT 900.442: returns INVOKEMETHOD-405 "Method not found: null" both before and after the Digital Commerce API metadata was loaded. Root cause found in the package's own VlocityAPIMetadata static resource - the shipped row for basketOperations carries a NULL APIHandler, only an APIResponseHandler (DefaultBasketOperationsRHandler), so the router has no handler class to dispatch to and reports the null handler name back verbatim. A CME implementation supplies that handler; the managed package does not. Passing methodName explicitly does not change the result. Route, auth and namespace substitution are verified correct. |
| Create Cart | `createCart` | Industries CPQ: create a cart. The cart header is an Opportunity, Order or Quote chosen by objectType, and the created record's Id becomes the cartId for every other cart action. Also serves the assetToOrder flow when assetIds are supplied. Body fields are JSON-serialised from the inputs supplied - no bodyTemplate, because the accepted field set varies by header object and org config. BLOCKED on org configuration on Vlocity CMT 900.442: HTTP 500 APEX_ERROR System.NullPointerException (System Code) for every body shape tried, with and without priceListId, effectiveDate, status and stageName, and after a full price list, pricing element, price list entry, ProductChildItem and catalog fixture existed. Same unconditional NPE as Get Eligible Products, Checkout Cart and Delete Cart Discount. WORKAROUND: create the header via the Salesforce connector (Opportunity with Pricebook2Id and vlocity_cmt__PriceListId__c) and pass its Id as cartId - the rest of the cart API then works. |
| Create EPC Picklists | `createEpcPicklists` | Enterprise Product Catalog: create picklists, which supply the allowed values for EPC product attributes. Pass the picklist definitions in picklists; picklist versions and picklist items are managed through the same EPC resource family. |
| Create EPC Products | `createEpcProducts` | Enterprise Product Catalog: create products in the Vlocity Product Console. Pass the product definitions in products. This is the EPC-aware create - it goes through the catalog's abstraction layer rather than writing Product2 directly, so product versions, child items and attribute assignments are handled consistently. For plain Product2 field writes the generic Salesforce connector is the simpler route. |
| Create EPC Promotions | `createEpcPromotions` | Enterprise Product Catalog: create promotions and their promotion items. These are the promotions the CPQ cart and Digital Commerce offers surface later, so creating them here is the catalog-side counterpart to Apply Promotions to Cart. |
