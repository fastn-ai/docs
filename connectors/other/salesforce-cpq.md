# Salesforce CPQ

Salesforce CPQ (formerly Steelbrick) — the configure-price-quote managed package that runs inside a Salesforce org. Covers the CPQ-specific surface only: the SBQQ__ custom objects (quotes, quote lines and line groups, quote terms, quote templates and documents, product options and features, configuration attributes, product and configuration rules, price rules and their conditions and actions, discount schedules and tiers, block prices, contracted prices, costs, subscriptions and consumption schedules) plus the CPQ Apex REST API at /services/apexrest/SBQQ/ServiceRouter for reading, saving and calculating a quote and for searching and adding products. Standard Salesforce sObject CRUD, SOQL, composite, Bulk, Tooling, Chatter and Analytics are NOT duplicated here — use the Salesforce connector alongside this one against the same org. Requires the Salesforce CPQ managed package to be installed and licensed; a plain Developer Edition org does not have it.

## Use it

Add Salesforce CPQ from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.salesforceCpq.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).

## Actions

| Add Products To Quote (CPQ API) | `addProductsToQuote` | CPQ Quote API: add one or more ProductModels to a QuoteModel and get the model back with the new quote lines (each carrying its key, productQuantityEditable, productHasDimensions and descriptionLocked). Does NOT save — pipe the result into calculateQuote and then saveQuote. ignoreCalculate must be hardcoded true per Salesforce. groupKey is 0-indexed and only meaningful on grouped quotes. Salesforce CPQ Summer '16 and later. |
| Amend Contract (CPQ API) | `amendContract` | CPQ Contract Manipulation API: generate an amendment quote from an existing contract, the API equivalent of the Amend button. Returns the new amendment QuoteModel. The Salesforce guide says this loader takes no request body, but the Apex REST ServiceRouter still requires an entity body - calling it with none returns 400 JSON_PARSER_ERROR 'The HTTP entity body is required' - so a context JSON string is sent like every other loader. Pass {} unless Salesforce documents context fields later. The connected user needs unusually broad access for this to work: create, read, insert, update and delete on both Quote and Opportunity, plus read on Product2 - without full Opportunity access the amendment fails. Salesforce CPQ Summer '16 and later. |
| Approve Approval Request (Advanced Approvals API) | `approveApprovalRequest` | Advanced Approvals API: approve an sbaa__Approval__c record with an optional comment. Advanced Approvals Spring '21 and later. Approval API labels are English only. |
| Calculate Quote (CPQ API) | `calculateQuote` | CPQ Quote API: run CPQ's pricing engine over a QuoteModel and get the recalculated model back (net totals, customer totals, per-line SBQQ__NetTotal__c and every price rule applied). Does NOT save — pipe the result into saveQuote. The context wraps the model under a quote key: {"quote": {...QuoteModel...}}. Salesforce documents this as performing like an asynchronous calculation and advises against it where instant results are needed; it also requires an Apex CalculateCallback class when the quote has quote-scoped product rules, which cannot be supplied over REST. Salesforce CPQ Summer '16 and later. |
| Contract Opportunity (CPQ) | `contractOpportunity` | Trigger CPQ's contracting process on an opportunity by setting SBQQ__Contracted__c. This is a CPQ-specific field on the standard Opportunity object: flipping it to true makes CPQ generate the Contract, the SBQQ__Subscription__c records for subscription products and Assets for the rest. It is asynchronous — the contract and subscriptions appear shortly afterwards, so poll listSubscriptionsForAccount rather than expecting them in this response. The opportunity needs a primary quote that has been ordered. Returns 204 No Content. |
| Contract Order (CPQ) | `contractOrder` | Trigger CPQ's order-based contracting by setting SBQQ__Contracted__c on an Order. This is the order-level equivalent of contractOpportunity and is the right one to use in orgs configured to contract from orders rather than opportunities. The order must be Activated. Asynchronous — poll listSubscriptionsForContract afterwards. Returns 204 No Content. |
| Create Apex Class (webhook infrastructure) | `createApexClass` | Webhook infrastructure, not part of the CPQ product surface. Pass the full class source as Body; Salesforce extracts the class name from the declaration. Must be stage:live for the subscription resolver to see it. |
| Create Apex Trigger (webhook infrastructure) | `createApexTrigger` | Webhook infrastructure, not part of the CPQ product surface. Must be stage:live for the subscription resolver to see it. |
| Create CPQ Block Price | `createBlockPrice` | Create a block price (SBQQ__BlockPrice__c) — one quantity band that is charged a flat price rather than a per-unit one. The product's pricing method must be Block for CPQ to use these. Bounds are lower-inclusive and upper-exclusive. SBQQ__ExpirationDate__c does not exist on this object in CPQ 262.1 (only SBQQ__EffectiveDate__c does), and CurrencyIsoCode exists only in a multi-currency org. Returns {id, success, errors}. |
| Create CPQ Configuration Attribute | `createConfigurationAttribute` | Create a configuration attribute (SBQQ__ConfigurationAttribute__c) on a bundle — the configurator control that pushes one value onto every option at once. SBQQ__TargetField__c is the API name of the field it writes on the quote lines. Scope it to one feature with SBQQ__Feature__c, or leave that empty for the whole bundle. SBQQ__ShownValues__c and SBQQ__HiddenValues__c narrow a picklist's choices. Returns {id, success, errors}. |
| Create CPQ Configuration Rule | `createConfigurationRule` | Scope a product rule to one bundle by creating a configuration rule (SBQQ__ConfigurationRule__c). Without one, a Product-scoped rule applies wherever its conditions match; with one, it only runs inside the named bundle. Returns {id, success, errors}. |
| Create CPQ Contracted Price | `createContractedPrice` | Create a contracted price (SBQQ__ContractedPrice__c) — a negotiated price or discount for one product on one account, which CPQ applies ahead of list pricing. Set either SBQQ__Price__c (a fixed price) or SBQQ__Discount__c (a percentage off list), not both. Multi-currency orgs need one record per currency; CPQ does not convert. Overlapping effective-date ranges for the same account, product and currency are rejected. Returns {id, success, errors}. |
| Create CPQ Cost | `createCost` | Create a cost record (SBQQ__Cost__c) — the per-unit cost CPQ uses for margin and cost-plus pricing. Returns {id, success, errors}. SBQQ__Cost__c in CPQ 262.1 carries neither effective/expiration dates nor CurrencyIsoCode; CurrencyIsoCode only exists in a multi-currency org. |
| Create CPQ Discount Schedule | `createDiscountSchedule` | Create a discount schedule (SBQQ__DiscountSchedule__c), the container for a volume or term discount curve. Add the actual bands with createDiscountTier afterwards — a schedule with no tiers discounts nothing. Range applies the matching tier's discount to the whole quantity; Slab blends across every tier the quantity spans. SBQQ__AggregationScope__c decides whether quantity is totalled across the quote or only within a line group, and SBQQ__CrossProducts__c (plural — SBQQ__CrossProduct__c does not exist in CPQ 262.1) totals across every product sharing the schedule. Returns {id, success, errors}. |
| Create CPQ Discount Tier | `createDiscountTier` | Add a tier (SBQQ__DiscountTier__c) to a discount schedule. Bounds are lower-inclusive and upper-exclusive, so consecutive tiers share a boundary value: 1-10, 10-50, 50-blank. Leave the upper bound empty on the last tier to make it open-ended. Set SBQQ__Discount__c for a percentage or SBQQ__DiscountAmount__c for a currency amount, matching the schedule's SBQQ__DiscountUnit__c. Returns {id, success, errors}. |
| Create CPQ Error Condition | `createErrorCondition` | Add an error condition (SBQQ__ErrorCondition__c) to a product rule — one test of a field on the quote, quote line, product option or feature. Several conditions on a rule combine according to the rule's SBQQ__ConditionsMet__c. SBQQ__TestedObject__c and SBQQ__TestedField__c name what is inspected, SBQQ__Operator__c and SBQQ__FilterValue__c the comparison. Returns {id, success, errors}. |
| Create CPQ Option Constraint | `createOptionConstraint` | Create an option constraint (SBQQ__OptionConstraint__c) between two options of the same bundle. The real lookups are SBQQ__ConstrainedOption__c and SBQQ__ConstrainingOption__c — SBQQ__ConstrainedProductOption__c, SBQQ__ConstrainingProductOption__c and SBQQ__Group__c do not exist in CPQ 262.1. Both lookups are filtered by SBQQ__ConfiguredSKU__c, so supply the bundle product id as well. Option constraints override product rules where both apply. Returns {id, success, errors}. |
| Create CPQ Price Action | `createPriceAction` | Create a price action (SBQQ__PriceAction__c) — the write half of a price rule, setting one pricing field on the target record when the rule's conditions are met. SBQQ__TargetField__c and SBQQ__SourceField__c do not exist on this object in CPQ 262.1: the target field is the SBQQ__Field__c picklist, and a source is given by SBQQ__SourceVariable__c, SBQQ__SourceLookupField__c or SBQQ__ValueField__c. Supply exactly one of Value, Formula, SourceVariable or ValueField. The parent rule's SBQQ__TargetObject__c must be Calculator for a quote/quote-line pricing write to fire. Returns {id, success, errors}. |
| Create CPQ Price Condition | `createPriceCondition` | Add a price condition (SBQQ__PriceCondition__c) to a price rule — one test against the quote, a quote line, a product option or a summary variable. Conditions on a rule combine according to the rule's SBQQ__ConditionsMet__c. Returns {id, success, errors}. |
| Create CPQ Price Rule | `createPriceRule` | Create a price rule (SBQQ__PriceRule__c) — the container for price conditions and price actions that write pricing fields during calculation or configuration. SBQQ__EvaluationScope__c and SBQQ__Description__c do not exist on this object in CPQ 262.1: the scope field is SBQQ__TargetObject__c (Calculator or Configurator), and every price action on the rule depends on it being set correctly. Add conditions with createPriceCondition and actions with createPriceAction. Returns {id, success, errors}. |
| Create CPQ Product Action | `createProductAction` | Create a product action (SBQQ__ProductAction__c) — what a Selection- or Filter-type product rule does when it fires: add, remove, show, hide, enable or disable a product or option. Target one product with SBQQ__Product__c, or a set with SBQQ__FilterField__c plus SBQQ__FilterValue__c. SBQQ__Quantity__c, SBQQ__Order__c and SBQQ__FilterOperator__c do not exist on this object in CPQ 262.1. Returns {id, success, errors}. |
| Create CPQ Product Feature | `createProductFeature` | Create a feature (SBQQ__ProductFeature__c) on a CPQ bundle — the grouping that product options are filed under in the configurator. Min and max option counts turn the feature into a "pick between N and M of these" control. SBQQ__OptionSelectionMethod__c decides how the options are presented: Click for checkboxes, Add for a search-and-add list, Dynamic for options sourced by a filter. Returns {id, success, errors}. |
| Create CPQ Product Option | `createProductOption` | Create a product option (SBQQ__ProductOption__c) — one child product offered inside a CPQ bundle. | Read Quote (CPQ API) | `readQuote` | CPQ Quote API: read a full QuoteModel through SBQQ.ServiceRouter.read. Returns the quote record plus every quote line and line group as CPQ's own JSON model (record, nextKey, netTotal, netNonSegmentTotal, customerTotal, lineItems[], lineItemGroups[]) — this is the model you feed back into calculateQuote, addProductsToQuote, validateQuote and saveQuote. The only GET in the CPQ API. Salesforce CPQ Summer '16 and later. |
| Read Quote Terms (CPQ API) | `readQuoteTerms` | CPQ Quote Term API: read the terms and conditions that apply to a quote, optionally resolved against a quote template and a language. Without templateId the terms associated with the template contents are not returned. The raw upstream response is a bare array of QuoteTermModels; fastn surfaces it under items. Salesforce CPQ Summer '19 and later. |
| Reject Approval Request (Advanced Approvals API) | `rejectApprovalRequest` | Advanced Approvals API: reject an sbaa__Approval__c record with an optional comment. Note this endpoint lives under the SEPARATE Advanced Approvals managed package (namespace sbaa) at /services/apexrest/sbaa/ServiceRouter, not the CPQ SBQQ router — it returns 404 in an org that has CPQ but not Advanced Approvals. Advanced Approvals Spring '21 and later. |
| Renew Contracts (CPQ API) | `renewContracts` | CPQ Contract Manipulation API: generate renewal quotes for one or more contracts, the API equivalent of the Renew button. Pass masterContractId to co-term several contracts onto one master. The raw upstream response is a bare array of QuoteModels (or, with returnOnlyQuoteId true, the bare quote id object); fastn surfaces it under items. Salesforce CPQ Summer '16 and later; returnOnlyQuoteId is Winter '21 and later. |
| Run Configuration Load Rules (CPQ API) | `runConfigurationLoadRules` | CPQ Configuration API: invoke every load-event product rule for a configurable product and get the resulting ProductModel back. This is what applies auto-selection, hiding and default-setting rules when a bundle is opened. uid is the Product2 Id. lineItemKey identifies upgrade options in amendment flows; dynamicOptionSkus supplies dynamically sourced option SKUs. Salesforce CPQ Spring '17 and later. |
| Save Quote (CPQ API) | `saveQuote` | CPQ Quote API: persist a whole QuoteModel through SBQQ.ServiceRouter.save — the quote header, every quote line and every line group in one call, running CPQ's own save logic rather than raw sObject DML. The provider name travels in the body, not the query string, which is why this call has no query parameters. Pass the model as a JSON string (the model CPQ returned from readQuote or calculateQuote, re-serialized); fastn escapes it into the body for you. Returns the saved QuoteModel. Salesforce CPQ Summer '16 and later. |
| Set Contract Renewal Fields (CPQ) | `setContractRenewalFields` | Set CPQ's renewal fields on a standard Contract. SBQQ__RenewalForecast__c true makes CPQ create the renewal opportunity with forecast amounts; SBQQ__RenewalQuoted__c true marks that a renewal quote now exists — until it is set, the renewal opportunity has no renewal quote attached. Both are CPQ-added fields on the standard Contract object. Contract generation itself is asynchronous, so allow time after contracting before setting these. Returns 204 No Content. |
| Update CPQ Contracted Price | `updateContractedPrice` | Update a contracted price (SBQQ__ContractedPrice__c) by Id. Only id is required; omitted fields are untouched. Quotes already calculated keep their old prices until recalculated. Returns 204 No Content. |
| Update CPQ Price Rule | `updatePriceRule` | Update a price rule (SBQQ__PriceRule__c) by Id. Only id is required; omitted fields are untouched. Setting SBQQ__Active__c false retires the rule without losing its conditions and actions. Quotes already calculated keep their prices until recalculated. Returns 204 No Content. |
| Update CPQ Product Option | `updateProductOption` | Update a product option (SBQQ__ProductOption__c) by Id. Only id is required; omitted fields are untouched. Changes affect future configurations only — quote lines already generated from this option are not retrofitted. Returns 204 No Content. |
| Update CPQ Product Rule | `updateProductRule` | Update a product rule (SBQQ__ProductRule__c) by Id. Only id is required; omitted fields are untouched. Setting SBQQ__Active__c false is the safe way to retire a rule without deleting its conditions and actions. Returns 204 No Content. |
| Update CPQ Quote | `updateQuote` | Update a CPQ quote (SBQQ__Quote__c) by Id. Only id is required; every other field you supply is sent and omitted fields are untouched. Send at least one field, an empty body is rejected with JSON_PARSER_ERROR. Editing pricing-relevant fields here does NOT recalculate the quote — run calculateQuote and saveQuote for that. Rollup fields such as SBQQ__NetAmount__c are read-only. Returns 204 No Content. |
| Update CPQ Quote Line | `updateQuoteLine` | Update a CPQ quote line (SBQQ__QuoteLine__c) by Id. Only id is required; omitted fields are untouched. Send at least one field. This does NOT reprice the quote — run calculateQuote then saveQuote afterwards, or CPQ's totals will disagree with the line. SBQQ__NetPrice__c and SBQQ__NetTotal__c are calculated, not writable. Returns 204 No Content. |
| Update CPQ Quote Line Group | `updateQuoteLineGroup` | Update a quote line group (SBQQ__QuoteLineGroup__c) by Id. Only id is required; omitted fields are untouched. Send at least one field. List and net totals on the group are rollups and are not writable. Returns 204 No Content. |
| Update CPQ Quote Term | `updateQuoteTerm` | Update a quote term (SBQQ__QuoteTerm__c) by Id. Only id is required; omitted fields are untouched. Name is an auto-number on this object and is not writable — sending it returns INVALID_FIELD_FOR_INSERT_UPDATE. Returns 204 No Content. |
| Update CPQ Subscription | `updateSubscription` | Update a subscription (SBQQ__Subscription__c) by Id — the renewal-forecasting fields CPQ reads when it builds a renewal quote. SBQQ__RenewalTerm__c and SBQQ__RenewalPricingMethod__c do not exist on this object in CPQ 262.1; renewal term and pricing method live on the parent Contract (see setContractRenewalFields). Returns 204 No Content. |
| Validate Product Configuration (CPQ API) | `validateProductConfiguration` | CPQ Configuration API: run validation product rules against a product configuration and get the ConfigurationModel back with validationMessages populated. uid is the Product2 Id. The event property is required and selects which rule set runs: Load, Save, Edit or Always. Salesforce CPQ Spring '17 and later. |
| Validate Quote (CPQ API) | `validateQuote` | CPQ Quote API: run CPQ's validation product rules against a QuoteModel and get the error messages back. Returns a bare JSON array of strings, empty when the quote is valid; fastn surfaces it under items. Unlike calculateQuote the context here is the QuoteModel itself, NOT wrapped in a quote key. Salesforce CPQ Winter '19 and later. Note: the Salesforce curl sample spells the provider QuoteAPI.QuoteValidator without the SBQQ prefix while the Apex sample on the same page uses the fully qualified SBQQ.QuoteAPI.QuoteValidator, which is what this action sends. |

## Events

Start a workflow when one of these happens, with an [app event trigger](../../build/triggers/README.md).

| Event | Id | When it fires |
| --- | --- | --- |
| CPQ Contracted Price Created | `sbqq__contractedprice__c.created` | Fires after a new SBQQ__ContractedPrice__c record is inserted. |
| CPQ Contracted Price Deleted | `sbqq__contractedprice__c.deleted` | Fires after an SBQQ__ContractedPrice__c record is deleted. |
| CPQ Contracted Price Updated | `sbqq__contractedprice__c.updated` | Fires after an SBQQ__ContractedPrice__c record is updated. |
| CPQ Quote Created | `sbqq__quote__c.created` | Fires after a new SBQQ__Quote__c record is inserted. |
| CPQ Quote Deleted | `sbqq__quote__c.deleted` | Fires after an SBQQ__Quote__c record is deleted. |
| CPQ Quote Document Generated | `sbqq__quotedocument__c.created` | Fires after a new SBQQ__QuoteDocument__c record is inserted, which is the completion signal for the asynchronous generateQuoteDocument call. |
| CPQ Quote Line Created | `sbqq__quoteline__c.created` | Fires after a new SBQQ__QuoteLine__c record is inserted. Note a bundle produces one event per line, parent and children. |
| CPQ Quote Line Deleted | `sbqq__quoteline__c.deleted` | Fires after an SBQQ__QuoteLine__c record is deleted. |
| CPQ Quote Line Group Created | `sbqq__quotelinegroup__c.created` | Fires after a new SBQQ__QuoteLineGroup__c record is inserted. |
| CPQ Quote Line Group Deleted | `sbqq__quotelinegroup__c.deleted` | Fires after an SBQQ__QuoteLineGroup__c record is deleted. |
| CPQ Quote Line Group Updated | `sbqq__quotelinegroup__c.updated` | Fires after an SBQQ__QuoteLineGroup__c record is updated. |
| CPQ Quote Line Updated | `sbqq__quoteline__c.updated` | Fires after an SBQQ__QuoteLine__c record is updated. Recalculating a quote updates every line, so expect a burst. |
| CPQ Quote Updated | `sbqq__quote__c.updated` | Fires after an SBQQ__Quote__c record is updated. This is the one to bind for status changes such as Draft to Approved. |
| CPQ Subscription Created | `sbqq__subscription__c.created` | Fires after a new SBQQ__Subscription__c record is inserted, which is how CPQ signals that a quote has been contracted and a recurring entitlement now exists. |
| CPQ Subscription Deleted | `sbqq__subscription__c.deleted` | Fires after an SBQQ__Subscription__c record is deleted. |
| CPQ Subscription Updated | `sbqq__subscription__c.updated` | Fires after an SBQQ__Subscription__c record is updated, including renewal-forecast changes. |
