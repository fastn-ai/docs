# OneSimpleAPI

<img src="../../.gitbook/assets/connectors/lg/one-simple-api.png" alt="OneSimpleAPI logo">

OneSimpleAPI is a developer utility API toolkit: website screenshots, HTML/URL to PDF, QR code generation, email validation, currency exchange rates, URL shortening and expansion, web page metadata and status checks, image info and transformation, readability and sentiment analysis, colour conversion, purchasing-power-parity discount calculation and an HTTP response cache.

| **Website** | [onesimpleapi.com](https://onesimpleapi.com) |
| **Authentication** | API key |
| **Slug** | `oneSimpleApi` |

## Use it

Add OneSimpleAPI from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.oneSimpleApi.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).
