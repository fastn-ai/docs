# Crowdin

<img src="../../.gitbook/assets/connectors/lg/crowdin.png" alt="Crowdin logo">

Crowdin localization management platform (crowdin.com REST API v2). Manage projects, source files and directories, branches, source strings, translations and approvals, target languages, glossaries and terms, storages, and project webhooks.

| | |
| --- | --- |
| **Category** | [Developer tools](README.md) |
| **Website** | [crowdin.com](https://crowdin.com) |
| **Authentication** | API key |
| **Slug** | `crowdin` |

## Use it

Add Crowdin from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.crowdin.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).
