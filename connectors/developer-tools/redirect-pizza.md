# redirect.pizza

<img src="../../.gitbook/assets/connectors/lg/redirect-pizza.png" alt="redirect.pizza logo">

redirect.pizza is a DNS-based hosted redirect service: point a domain's DNS at redirect.pizza and it serves 301/302/307/308 redirects with automatically provisioned Let's Encrypt HTTPS, no server required. This connector wraps the complete redirect.pizza REST API v1 (https://redirect.pizza/api/v1): redirect CRUD, pause/resume of whole redirects and of individual source URLs, bulk CSV/JSON import and import status, email forwards and their delivery logs, redirect analytics (total hits, time series, dimension breakdowns and raw hits), domain listing, per-domain security/edge settings, DNS propagation checks and automatic DNS configuration, team quota and default settings, team member management, plus the unauthenticated redirect tester and QR code generator.

## Use it

Add redirect.pizza from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.redirectPizza.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).

## Actions

| Action | Slug | What it does |
| --- | --- | --- |
| Apply Automatic DNS Configuration | `applyAutomaticDns` | Ask redirect.pizza to write the required DNS records for a domain directly at its DNS provider, for the registrars and DNS hosts it can drive automatically. Check dns.automatic_dns.available on the domain first: when it is false the call returns 403 'Automatic DNS configuration is not available for this domain.' Returns 200 with successful true and an output message; 409 if a run is already in progress, 503 if the configuration attempt failed. |
| Check Domain DNS Propagation | `checkDomainDns` | Force redirect.pizza to re-check the DNS records of a domain immediately rather than waiting for its own schedule, and return the refreshed domain with its dns.verified flag, the records still required and the SSL certificate status. Use this right after publishing the A, AAAA or CNAME records that Retrieve Domain reports. |
| Create Email Forward | `createEmailForward` | Create an email forward that delivers mail sent to alias@domain on to another address. The domain must be one you own and can manage DNS for; the response includes the MX and TXT records you must publish before mail flows. Use '*' as the alias to create a catch-all. Email forwarding is a paid feature: teams below the Pro plan receive HTTP 402 with the message 'Email forwarding is available from the Pro plan and up.' |
| Create Redirect | `createRedirect` | Create a new redirect. Sources are the incoming hostnames or URLs that should be redirected; destination is the target the visitor is sent to. Each source hostname counts against your plan's hostname quota, and you must own the domain and be able to change its DNS. Returns 201 with the created redirect, including the generated source ids and the domain objects with the DNS records you must add. Use merge to fold the new source into an existing redirect with the same settings, or upsert to update an existing redirect whose sources overlap instead of creating a new one. |
| Delete Domain | `deleteDomain` | Permanently delete a domain together with every source URL that belongs to it. Any redirect left with no sources afterwards is deleted too, so traffic on that domain stops being redirected immediately. Requires both the domains:manage and redirects:write scopes. Returns 204 with an empty body on success. This cannot be undone. |
| Delete Email Forward | `deleteEmailForward` | Permanently delete an email forward. Mail sent to that alias stops being forwarded immediately. Returns 204 with an empty body on success. Email forwarding is a paid feature: teams below the Pro plan receive HTTP 402 with the message 'Email forwarding is available from the Pro plan and up.' |
| Delete Redirect | `deleteRedirect` | Permanently delete a redirect and all of its source URLs. Traffic to those hostnames stops being redirected immediately and the hostnames are released from your plan quota. Returns 204 with an empty body on success, or 404 when the redirect does not exist. This cannot be undone. |
| Generate QR Code | `generateQrCode` | Generate a QR code image that points at a given URL, for printing on signage or handing out alongside a vanity redirect. Use format 'json' (the default): the response is JSON metadata containing a base64 data URI of the PNG plus a suggested filename. The 'png', 'svg' and 'eps' formats return raw image data rather than JSON - verified live, 'svg' comes back as parsed XML rather than usable markup, so prefer 'json' and decode the data URI yourself. This endpoint does not require authentication. |
| Get Analytics Dimension Breakdown | `getAnalyticsDimension` | Return aggregated redirect analytics broken down by one dimension - for example countries, sources, destinations, referrers or device types - within a date range, as a paginated list of key/count pairs. Optionally narrow with a filter query such as 'redirect:1234567890', 'tag:marketing' or 'traffic_type:human'. The Analytics API is in beta. Analytics is a paid feature: teams below the Basic plan receive HTTP 402 with the message 'Analytics is available from the Basic plan and up.' |
| Get Hits Time Series | `getHitsTimeSeries` | Return redirect hits as a time series over the given date range, as an array of key/count points suitable for plotting a traffic graph. Optionally narrow with a filter query such as 'redirect:1234567890'. The Analytics API is in beta. Analytics is a paid feature: teams below the Basic plan receive HTTP 402 with the message 'Analytics is available from the Basic plan and up.' |
| Get Team Details | `getTeam` | Retrieve the team that the API token belongs to, including its name, current and maximum hostname count, current, projected and maximum monthly hit count, current and maximum number of users, the redirect.pizza nameservers to delegate to, summary email preferences and the team-wide default security settings. Use this to check quota before creating redirects. |
| Get Total Hits | `getTotalHits` | Return the total number of redirect hits recorded in a given period, optionally narrowed with a filter query such as 'redirect:1234567890'. Returns a data object with a count plus the filters that were applied. The Analytics API is in beta. Analytics is a paid feature: teams below the Basic plan receive HTTP 402 with the message 'Analytics is available from the Basic plan and up.' |
| Import Redirects | `importRedirects` | Bulk-import redirects from either an array of row objects or a CSV string, using the same columns as the dashboard importer: source, destination, redirect_type, uri_forwarding, keep_query_string, tracking, tags and notes. Existing sources are updated to the row destination. A maximum of 5000 rows can be imported per API call. Returns 202 with an import object whose id you can poll with Retrieve Redirect Import to watch success, error and pending row counts. |
| Invite Team Member | `inviteTeamMember` | Invite someone to your redirect.pizza team by email. CAUTION: this sends a real invitation email to the address given; the member is created with status 'invited' and becomes 'active' once they accept. Tag access works as in the dashboard - 'all' grants access to every redirect, 'allowed' limits access to redirects carrying the listed tags, and 'restricted' blocks the listed tags. Additional seats are a paid feature: teams at their seat limit receive HTTP 402 with the message 'Inviting additional team members is available from the Pro plan and up.' |
| List Domains | `listDomains` | Return a paginated list of the domains configured through your redirects, each with its DNS verification state, the DNS records that must be published, whether automatic DNS configuration is available, SSL certificate status and per-domain security settings. 20 domains are returned per page by default. Use the query parameter to search by FQDN or filter with tokens such as status:verified, status:unverified or tag:marketing. |
| List Email Forward Logs | `listEmailForwardLogs` | Return a cursor-paginated list of email forward delivery log entries for your team, showing when each message was received, its sender, recipient alias, forwarding destination, subject and delivery status. Rows may be updated as delivery resolves. Filter by date range or with a query such as 'forward:sales@example.com domain:example.com'. Email forwarding is a paid feature: teams below the Pro plan receive HTTP 402 with the message 'Email forwarding is available from the Pro plan and up.' |
| List Email Forwards | `listEmailForwards` | Return a paginated list of the email forwards configured for your redirect.pizza team, each with its alias, domain, destination address and the MX and TXT DNS records required for delivery. 20 email forwards are returned per page by default. Email forwarding is a paid feature: teams below the Pro plan receive HTTP 402 with the message 'Email forwarding is available from the Pro plan and up.' |
| List Raw Hits | `listRawHits` | Return individual redirect hits, cursor-paginated, so traffic can be investigated request by request. Each hit carries the timestamp, redirect id, full source URL and destination URL, anonymised IP, scheme, method, crawler and WAF flags, geolocation, user agent, browser, OS, device type and referrer. Raw analytics is a paid feature: teams below the Business plan receive HTTP 402 with the message 'Raw analytics view is available from the Business plan and up.' |
| List Redirects | `listRedirects` | Return a paginated list of the redirects in your redirect.pizza team. 20 redirects are returned per page by default. Use the query parameter for free-text search across sources and destinations, or filter with key:value tokens such as status:active, status:paused, tag:marketing, type:temporary, created_before:2026-01-01, source:old.example.com or destination:https://example.org. Returns a data array of redirect objects plus links and meta pagination blocks. |
| List Team Members | `listTeamMembers` | Return a paginated list of the people on your redirect.pizza team, including pending invitations. Each entry carries the member id, email address, role, a status of 'active' or 'invited', their tag access mode and the tags it applies to. 20 users are returned per page by default. |
| Pause Redirect | `pauseRedirect` | Pause every source URL of a redirect. Paused sources stop forwarding traffic but the redirect and its DNS configuration are kept, so it can be re-enabled with Resume Redirect. Returns 204 with an empty body on success. |
| Pause Source URL | `pauseSourceUrl` | Pause one specific source URL of a redirect, leaving the redirect's other sources active. The paused source stops forwarding traffic until Resume Source URL is called. Source ids are returned in the sources array of Retrieve Redirect. Returns 204 with an empty body on success. |
| Remove Team Member | `removeTeamMember` | Remove a person from your redirect.pizza team, or cancel a pending invitation. The user's redirect.pizza account itself is not deleted unless the invite was never claimed. CAUTION: passing the id of the account your own API token belongs to removes your own access to this team; the API refuses only the very last owner, answering 422 'Cannot remove the last owner from the team.' Returns 204 with an empty body on success. |
| Resume Redirect | `resumeRedirect` | Resume every source URL of a previously paused redirect so it forwards traffic again. Returns 204 with an empty body on success. |
| Resume Source URL | `resumeSourceUrl` | Resume one specific paused source URL of a redirect so that it forwards traffic again, leaving the redirect's other sources unchanged. Returns 204 with an empty body on success. |
| Retrieve Domain | `getDomain` | Retrieve a single domain by its id, including its DNS verification state, the exact DNS records that must be published for redirects to work, whether automatic DNS configuration is available, SSL certificate status and its effective security settings. |
| Retrieve Email Forward | `getEmailForward` | Retrieve a single email forward by its id, including its alias, domain with required DNS records, and destination address. Email forwarding is a paid feature: teams below the Pro plan receive HTTP 402 with the message 'Email forwarding is available from the Pro plan and up.' |
| Retrieve Redirect | `getRedirect` | Retrieve a single redirect by its id, including all of its source URLs with their individual ids and paused state, the domain objects with required DNS records, verification and SSL status, and the redirect's destination, type, forwarding options, tags and notes. |
| Retrieve Redirect Import | `getRedirectImport` | Get the status of a bulk redirect import started with Import Redirects, including its processing status, total, success, error and pending row counts, and up to 100 recent row errors. Poll this until status is no longer 'processing'. |
| Test Redirect URL | `testRedirectUrl` | Probe any public HTTP or HTTPS URL from a redirect.pizza edge location and report exactly one hop: the status code returned, the Location it redirects to, whether the hop was served by redirect.pizza, whether HSTS and foreign-embedding protection are set, the raw response headers, the probe location used and a plain-English explanation. To follow a whole redirect chain, call again with the next_test_url from the response. Works on any site, not just your own redirects. |
| Update Domain Settings | `updateDomain` | Update the security and edge settings of a single domain: web application firewall, HSTS, prevent foreign embedding, short-lived ACME certificates, referrer policy and robots.txt. Each setting takes a status of 'inherit' to follow the team default, or 'enabled'/'disabled' to override it for this domain. Only the settings you send are changed. Returns 200 with the updated domain. |
| Update Email Forward | `updateEmailForward` | Change the destination address of an existing email forward. The alias and domain cannot be changed; delete and recreate the forward to move it. Email forwarding is a paid feature: teams below the Pro plan receive HTTP 402 with the message 'Email forwarding is available from the Pro plan and up.' |
| Update Redirect | `updateRedirect` | Replace an existing redirect's configuration. This is a full update: sources, destination and redirect_type are all required, and any source not listed is removed from the redirect. Returns 200 with the updated redirect. Use Create Redirect with upsert instead if you want to add sources without tracking redirect ids. |
| Update Team Member | `updateTeamMember` | Change the role and tag access of an active team member or a pending invitation. CAUTION: this can change your own access - demoting the account your API token belongs to may lock you out of the API, and the last owner of a team cannot be demoted (the API answers 422 'Cannot demote the last owner of the team.'). Returns 200 with the updated member. |
| Update Team Settings | `updateTeam` | Update the team name, the summary email schedule and recipients, and the team-wide default security settings that individual domains inherit: broken destination monitoring, CNAME flattening, web application firewall, HSTS, prevent foreign embedding, short-lived ACME certificates, referrer policy and robots.txt. Only the fields you send are changed. Returns 200 with the updated team. |
