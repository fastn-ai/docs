# Dropbox

<img src="../../.gitbook/assets/connectors/lg/dropbox.png" alt="Dropbox logo">

Dropbox API v2 connector — files & folders (list, metadata, create, delete, move, copy, search, revisions, temporary links, upload/download), sharing (shared links, file/folder members), users (account, space usage), and file requests. RPC-style JSON over POST; content endpoints on content.dropboxapi.com. OAuth 2.0 with offline refresh.

| **Authentication** | OAuth 2.0 |
| **Slug** | `dropbox` |

## Use it

Add Dropbox from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.dropbox.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).
