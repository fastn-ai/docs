# Microsoft OneDrive

<img src="../../.gitbook/assets/connectors/lg/onedrive.png" alt="Microsoft OneDrive logo">

Microsoft OneDrive via Microsoft Graph v1.0 — drives, driveItems (upload, download, list children, move, copy, delete, search), file versions, thumbnails, sharing links and permissions, shared-with-me, special folders, delta sync, and change-notification subscriptions (webhooks).

| | |
| --- | --- |
| **Category** | [Productivity](README.md) |
| **Website** | [onedrive.com](https://onedrive.com) |
| **Authentication** | OAuth 2.0 |
| **Slug** | `onedrive` |

## Use it

Add Microsoft OneDrive from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.onedrive.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).
