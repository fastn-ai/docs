# SimplyBook.me

<img src="../../.gitbook/assets/connectors/lg/simplybook-me.png" alt="SimplyBook.me logo">

SimplyBook.me is an online appointment scheduling platform for service businesses. This connector covers the SimplyBook.me Admin REST API v2 and the JSON-RPC Company Administration Service: bookings and cancellations, clients and client fields, services and service categories, providers (performers) and locations, the schedule, timeline and available booking slots, calendar notes, memberships, packages, products, promotions, coupons and gift cards, invoices and payments, booking statuses, tickets, reports and statistics, company settings and working hours, and webhook subscriptions.

## Use it

Add SimplyBook.me from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.simplybookMe.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).

## Events

The delivered payload carries notification_type = "cancel" (verified on a live delivery). Fetch the record with Get Booking using booking_id.</td></tr><tr><td>Booking Changed</td><td><code>change_booking</code></td><td>An existing booking was rescheduled, reassigned or otherwise edited. The delivered payload carries notification_type = "change" (verified on a live delivery). Fetch the current state with Get Booking using booking_id.</td></tr><tr><td>Booking Created</td><td><code>new_booking</code></td><td>A new booking was made - from the booking page, the admin calendar or the API. The delivered payload carries notification_type = "create" (verified on a live delivery). Fetch the full record with Get Booking using booking_id.</td></tr><tr><td>Client Changed</td><td><code>change_client</code></td><td>An existing client record was edited. Fetch the current state with Get Client using client_id. SimplyBook.me sends NO event-type field on client payloads - only client_id - so this event cannot be told apart from the other client events by payload content. Bind it to its own trigger so routing is by URL rather than by event key.</td></tr><tr><td>Client Created</td><td><code>new_client</code></td><td>A new client record was created. Fetch the full record with Get Client using client_id. SimplyBook.me sends NO event-type field on client payloads - only client_id - so this event cannot be told apart from the other client events by payload content. Bind it to its own trigger so routing is by URL rather than by event key.</td></tr><tr><td>Client Deleted</td><td><code>delete_client</code></td><td>A client record was deleted; the record is no longer retrievable, only the identifier is delivered. SimplyBook.me sends NO event-type field on client payloads - only client_id - so this event cannot be told apart from the other client events by payload content. Bind it to its own trigger so routing is by URL rather than by event key.</td></tr><tr><td>Invoice Created</td><td><code>new_invoice</code></td><td>A new invoice or order was created, which happens when a booking is taken with payments enabled. Fetch it with Get Invoice using invoice_id. Requires the Accept Payments Custom Feature; not observed on a live delivery because that feature is disabled on the certification account.</td></tr></tbody></table>
