## Use it

Add Google Calendar from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.googleCalendar.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).

## Events

Start a workflow when one of these happens, with an [app event trigger](../../build/triggers/README.md).

<table><thead><tr><th width="240">Event</th><th width="260">Id</th><th>When it fires</th></tr></thead><tbody><tr><td>Calendar Event Created or Updated</td><td><code>exists</code></td><td>A resource on the watched calendar was created or changed. X-Goog-Resource-State: exists. Google sends no event body - call listEvents with a syncToken or updatedMin to fetch what changed.</td></tr><tr><td>Calendar Event Deleted</td><td><code>not_exists</code></td><td>A resource on the watched calendar no longer exists (deleted). X-Goog-Resource-State: not_exists.</td></tr><tr><td>Channel Sync</td><td><code>sync</code></td><td>Sent once immediately after a watch channel is created, confirming the subscription is live. X-Goog-Resource-State: sync. Carries no calendar data.</td></tr></tbody></table>
