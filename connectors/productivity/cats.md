# CATS

<img src="../../.gitbook/assets/connectors/lg/cats.png" alt="CATS logo">

CATS (CATSOne) applicant tracking system. Manage candidates, jobs, companies, contacts, pipelines, activities, tasks, tags, lists, custom fields, attachments and webhooks through the CATS v3 REST API.

| | |
| --- | --- |
| **Category** | [Productivity](README.md) |
| **Website** | [catsone.com](https://catsone.com) |
| **Authentication** | API key |
| **Slug** | `cats` |

## Use it

Add CATS from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.cats.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).
