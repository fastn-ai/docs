# Ascora

<img src="../../.gitbook/assets/connectors/lg/ascora.png" alt="Ascora logo">

Manage enquiries, customers and contacts, inventory supplies, kits and categories, quotations and quote line items, jobs, job labour and timesheets, suppliers and supplier invoices, notes, attachments, accounting integration (invoices and payments to send), users, and webhook subscriptions.

| | |
| --- | --- |
| **Category** | [Productivity](README.md) |
| **Website** | [ascora.com.au](https://ascora.com.au) |
| **Authentication** | API key |
| **Slug** | `ascora` |

## Use it

Add Ascora from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.ascora.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).
