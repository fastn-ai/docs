# TalentHR

<img src="../../.gitbook/assets/connectors/lg/talenthr.png" alt="TalentHR logo">

TalentHR public API (v1) — all-in-one HR platform: employee directory and records, onboarding, time off, time tracking, attendance, documents, assets, benefits, applicant tracking, surveys, performance goals and HR reports.

| **Authentication** | Basic auth |
| **Slug** | `talenthr` |

## Use it

Add TalentHR from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.talenthr.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).
