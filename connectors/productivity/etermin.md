# eTermin

<img src="../../.gitbook/assets/connectors/lg/etermin.png" alt="eTermin logo">

eTermin is an online appointment scheduling and booking platform. This connector covers the eTermin REST API (https://www.etermin.net/api): appointments and appointment sync, calendars, calendar services, calendar return times and non-working times, anchor times by weekday and by date, working times by weekday and by date, services and service groups, contacts with frequency and service links, vouchers, ratings, time slots, survey results, booking page logs, message logs and user mappings, plus the account, user, company, settings, custom field, location, payment, invoice, tag, file, survey, statistics, log and webhook configuration resources.

## Use it

Add eTermin from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.etermin.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).

## Actions

| Action | Slug | What it does |
| --- | --- | --- |
| Add Calendar To Group | `addCalendarToGroup` | Adds a calendar to a calendar group. Undocumented route; all three parameters are required and numeric - omitting them walks through 400 'calgrplinked is missing!' then 400 'calendargroupid is missing!'. calgrplinked is a 0/1 flag (true/false is rejected as a non-Int32). Adding the same calendar to the same group twice returns 404 "Violation of PRIMARY KEY constraint 'PK_AppCalendarsGroupings'". Returns 'Created successfully!'; confirm with List Calendar Group Members. All parameters travel in the URL; eTermin rejects any non-empty request body. |
| Assign Service To Calendar | `assignServiceToCalendar` | Links an existing service to a calendar so the service becomes bookable on it. Returns 'Calendar/Service created successfully!'. The service must already belong to a service group - linking a service whose ServiceGroupID is null fails with 404 'Cannot insert the value NULL into column ServiceGroupID'. Confirm with List Calendar Services for the calendar. |
| Create Account | `createAccount` | UNSAFE TO DRIVE - creates a real eTermin ACCOUNT from an email address and triggers an onboarding mail to it. Never execute with a real address. Undocumented route; proven to exist and proven correct to the last safe step: with no parameters it answers 200 'E-Mail address is missing!', which is the route's own required-field error, so 'email' is the required key. The remaining fields are not documented by eTermin. |
| Create Anchor Time | `createAnchortime` | Create a weekly anchor time (fixed start time) for a calendar. All parameters are sent as query parameters; eTermin rejects any non-empty request body. |
| Create Anchor Time By Date | `createAnchortimedate` | Create a date-specific anchor time for a calendar. |
| Create Appointment | `createAppointment` | Book an appointment. WARNING: with sendemail/sms/notificationmsg set to true eTermin sends a real confirmation to the contact - keep them false unless a real booking confirmation is intended. All boolean flags are required because eTermin rejects an empty boolean query value. |
| Create Calendar | `createCalendar` | Creates a new eTermin calendar. The route takes no effective parameters - the calendar is created with account defaults and named 'Neuer Kalender' (a calendarname passed on the query string is ignored, proven live). Returns the new CalendarID in the id element; rename and configure it with Update Calendar. Subject to the account's calendar quota (Trial = 1 included + AdditionalCalendars). |
| Create Calendar Non-Working Time | `createCalendarsnonworkingtime` | Create a non-working (blocked) time range for a calendar. Note: the calendar id parameter is named appcalendarid on this route, and nwtype is a SMALLINT (0/1) even though eTermin's OpenAPI types it boolean. |
| Create Calendar Return Time | `createCalendarreturntime` | Create a return time (buffer window) for a calendar. |
| Create Contact | `createContact` | Create a contact (customer record). 'newsletter' must be supplied because eTermin rejects an empty boolean query value. Setting loginid/password creates portal login credentials for the contact. |
| Create Location | `createLocation` | Creates an alternative appointment location on a calendar. Undocumented route. calendarid is an Int32 and rejects an empty value, so it is required; every address field tolerates empty. The route answers 200 with an empty statusmsg and no id, so confirm creation with List Locations for that calendar and take the id from there. All parameters travel in the URL; eTermin rejects any non-empty request body. |
| Create Service | `createService` | Creates a bookable service inside a service group and returns its new id. eTermin takes every field as a query parameter and rejects an empty value for most numeric and true/false fields, so those are marked required here; free-text fields may be left blank. Note that maxminslots and tagscancel are numeric 0/1 flags despite being typed as booleans/strings in eTermin's own specification. |
| Create Service Group | `createServiceGroup` | Creates a service group, the block on the booking page that holds a set of selectable services. Returns the new service group id together with the status. Services are then attached to it with Create Service. |
| Create Survey | `createSurvey` | Creates a feedback survey. Undocumented route; name and header are both required (omitting either returns 400 'Parameter name is missing!' / 'Parameter header is missing!'), while infotext and lang tolerate empty. Returns the new numeric id and 'Created successfully!'. All parameters travel in the URL; eTermin rejects any non-empty request body. |
| Create Synced Appointment | `createSyncedAppointment` | Pushes an appointment from an external calendar (Outlook/Google/CalDAV) into eTermin. appointmentid is YOUR external id and must be unique - re-posting the same id returns 400 'Appointment with the ID X already exists! Use PUT verb'. All parameters travel in the URL: eTermin rejects any non-empty request body. sequence is an integer and sendemail a boolean, so both are required (an empty value 400s). Set sendemail=false to avoid mailing the attendee. |
| Create Tag | `createTag` | Creates an appointment tag. Undocumented route; 'name' is the only parameter and is required (without it the route answers 400 'Parameter name is missing!'). Returns 'Created successfully!' with a GUID in the id element - the numeric id used by Update/Delete Tag comes from List Tags. All parameters travel in the URL; eTermin rejects any non-empty request body. |
| Create User Mapping | `createUsermapping` | Create a user mapping (maps an external value or value range to a calendar / service group). |
| Create Voucher | `createVoucher` | Create a voucher. The voucher code is supplied as 'id'. Returns the code and the numeric internal id (iid) needed to update it. |
| Create Web Push Subscription | `createWebPushSubscription` | Registers a browser push subscription for a backend user. userid is the user GUID from List Users and is the only required parameter - it is the key the route reads: every other parameter name answers 404 'Conversion failed when converting from a character string to uniqueidentifier', while userid answers 200. Returns 200 with an empty statusmsg, so confirm with List Web Push Subscriptions and take the new ID from there. All parameters travel in the URL; eTermin rejects any non-empty request body. |
| Create Working Time | `createWorkingtime` | Create a weekly working-time slot for a calendar. Integer parameters must carry a value (empty is rejected); use -1 for 'not set' on validwithserviceid, locationid and calendarintervalid. |
| Create Working Time Date | `createWorkingtimesdate` | Creates a date-specific working slot (an exception to the weekly working times) on a calendar. Returns the new slot id and 'Working slot created successfully!'. All parameters travel in the URL; eTermin rejects any non-empty request body. Required set determined empirically: every numeric and boolean parameter rejects an empty value, while reason, serviceids and oneoffcode tolerate empty and stay optional. |
| Delete Anchor Time | `deleteAnchortime` | Delete a weekly anchor time by id. |
| Delete Anchor Time By Date | `deleteAnchortimedate` | Delete a date-specific anchor time by id. |
| Delete Appointment | `deleteAppointment` | Cancel/delete an appointment by its INTERNAL numeric id (appid, the IID returned by Create Appointment). Proven: appid deletes ('1 record(s) deleted'); passing the external id instead returns '0 record(s) deleted', and passing an empty appid alongside an external id returns 400 'Index was outside the bounds of the array' - so the two keys are exposed as separate actions. WARNING: sendemail=true sends a real cancellation message to the contact. |
| Delete Backend User | `deleteUser` | Delete a backend user by id. Undocumented route; with no parameters it answers 400 'ID parameter is missing!'. NOT DRIVEN on the sandbox: the only backend user is the account owner, and deleting it would lock the account out. |
| Delete Calendar | `deleteCalendar` | Permanently deletes a calendar and everything attached to it (working times, appointments, calendar/service links). With no id the route answers 200 'Calendar ID is missing!'. Always confirm removal with List Calendars afterwards. |
| Delete Calendar Non-Working Time | `deleteCalendarsnonworkingtime` | Delete a non-working time range by id. |
| Delete Calendar Return Time | `deleteCalendarreturntime` | Delete a calendar return time by id. |
| Delete Contact | `deleteContact` | Delete a contact by cid (contact id) or email. The external-id key cannot be exposed here for the same reason as Update Contact: an EMPTY id is parsed as a GUID and returns 404 'Conversion failed when converting from a character string to uniqueidentifier'. |
| Delete Email Notification | `deleteEmailNotification` | UNSAFE TO DRIVE - /api/email is eTermin's notification sender and its contract is unpublished. Built for coverage and proven to the last safe step only: with no parameters DELETE /api/email answers 200 with an empty statusmsg (a no-op), matching the other verbs on the route. The 'id' key is inferred, not confirmed by eTermin. Do not run this against a live account until the contract is published. |
| Delete File | `deleteFile` | Deletes an attached file by its id (from List Files). Without id the route answers 400 'ID parameter is missing!'. Confirm removal by re-running List Files for the same appointment or contact. |
| Delete Invoice | `deleteInvoice` | Deletes a subscription invoice by its id. Undocumented route; with no id it answers 400 'id is missing!'. UNSAFE TO DRIVE on a live account: eTermin's billing invoices cannot be recreated through the API, so this action must only be run against an invoice the caller genuinely wants removed. Confirm the outcome with List Invoices. |
| Delete Location | `deleteLocation` | Deletes an appointment location by its id. Undocumented route. It answers 200 with an empty statusmsg whether or not anything matched, so ALWAYS confirm removal with List Locations for the calendar afterwards. |
| Delete Service | `deleteService` | Deletes a bookable service by id. The service is removed from its service group and from the booking page. Returns the number of records deleted. |
| Delete Service Group | `deleteServiceGroup` | Deletes a service group by id. The services belonging to the group are removed from the booking page along with it. Returns the status of the operation. |
| Delete Survey | `deleteSurvey` | Deletes a feedback survey by its id. Without id the route answers 400 'Parameter id is missing!'. Confirm removal with List Surveys - a 200 carrying '0 record(s) deleted' means nothing matched. |
| Delete Synced Appointment | `deleteSyncedAppointment` | Deletes an appointment previously pushed via Appointment Sync, matched on your external appointmentid plus its start/end. Returns '1 record(s) deleted'. IMPORTANT: a 200 carrying '0 record(s) deleted' means nothing matched - always assert the count. With no parameters the route answers 200 'Start date or appointment ID is missing!'. |
| Delete Tag | `deleteTag` | Deletes an appointment tag by its numeric id (from List Tags). Without id the route answers 400 'Parameter id is missing!'. Confirm removal with List Tags - a 200 carrying '0 record(s) deleted' means nothing matched. |
| Delete User Mapping | `deleteUsermapping` | Delete a user mapping by id. |
| Delete Voucher | `deleteVoucher` | Delete a voucher by its voucher code (id). |
| Delete Web Push Subscription | `deleteWebPushSubscription` | Removes a browser push subscription by its numeric ID from List Web Push Subscriptions. With no id the route answers 400 'ID parameter is missing!'. Confirm removal by re-listing. |
| Delete Working Time | `deleteWorkingtime` | Delete working-time slots of a calendar, optionally a single one by id. |
| Delete Working Time Date | `deleteWorkingtimesdate` | Deletes a date-specific working slot. Pass calendarid plus the slot id. IMPORTANT: a 200 carrying '0 record(s) deleted' means nothing matched - assert the count and confirm with List Working Time Dates. |
| Get Account | `getAccount` | Returns the eTermin account record: package/plan name and id, creation and purchase dates, SMS allowance and usage, and the other subscription limits of the account. |
| Get Company | `getCompany` | Returns the company profile shown on the booking page: company name, additional information, street, ZIP, town, country and contact details. |
| Get Contact Frequency | `getContactFrequency` | Returns the booking frequency limit configured for a contact, i.e. how many appointments the contact may book within the given frequency type (for example per week or per month). |
| Get Contact Service Permissions | `getContactServicePermissions` | Returns which services and service groups a contact is permitted to book, as pairs of service group id and service id. |
| Get Customer Plan | `getCustomerPlan` | Returns the eTermin customer/tenant record for the authenticated account: assignedemp (number of employee seats), packageid, packagename (e.g. 'Trial') and supporttype. Undocumented route, no parameters. Use this to check plan entitlements before calling features that are plan-gated. |
| Get Settings | `getSettings` | Returns the account-wide booking settings: booking deadline and booking horizon in days, notification options, the notification and sender email addresses and the other configuration flags of the booking page. |
| Get Statistics | `getStatistics` | Returns booking statistics for a date range. Undocumented route; start and end are yyyy-MM-dd dates. Returns [] when the range contains no bookings. |
| Grant Contact Service Permission | `grantContactServicePermission` | Permits a contact to book the services in a given service group. cid is the internal contact id from List Contacts, sgid the ServiceGroupID. Read it back with Get Contact Service Permissions. All parameters travel in the URL; eTermin rejects any non-empty request body. Answers 200 with an empty statusmsg, so verify with the matching GET. |
| Invite Backend User | `createUser` | UNSAFE TO DRIVE - invites a backend user BY EMAIL, which sends a real invitation message. Never execute with a real address. Undocumented route; proven to exist and proven correct to the last safe step: with no parameters it answers 400 'Email parameter is missing!', so 'email' is the required key. |
| List Anchor Times | `listAnchortimes` | List the weekly anchor times of a calendar. Returns id, calendarid, starttime, weekday, ignoreonceappbooked. |
| List Anchor Times By Date | `listAnchortimedates` | List the date-specific anchor times of a calendar. |
| List Appointment Sync Changes | `listAppointmentSyncChanges` | Incremental calendar-sync feed. Returns every appointment created/modified/deleted since the given sync token, each row carrying SyncStatus (N=new, M=modified, D=deleted), ID, ExternalID, start/end local and UTC, and the current sync token to pass next time. Pass synctoken=0 for a full initial sync. |
| List Appointments | `listAppointments` | List appointments in a date range with optional filters. appid and cid are integer filters that reject an empty value - pass 0 for 'no filter'. All boolean flags must be supplied because eTermin rejects an empty boolean query value. |
| List Audit Log | `listAuditLog` | Returns the account's audit log for a date range - one row per change with datetime, userid, verb (GET/POST/PUT/DELETE), action (e.g. 'Delete working time') and appointmentid. Undocumented route. This is also where webhook deliveries are recorded (eTermin keeps them for 14 days, shown in the backend under API &gt; Logs). |
| List Available Time Slots | `listTimeSlots` | Returns the bookable time slots for a date, with availability, capacity and waiting-list information per calendar. This is the endpoint to call before creating an appointment. Narrow the search by service, calendar, duration, capacity or cluster, and use Range Search with an end date to scan several days. |
| List Booking Fields | `listBookingFields` | Lists the booking-form fields configured on the account: AppFieldsID, CustomerID, DisplayIndex, Name, DataFieldName (the payload key such as Salutation), Type (DropDownList, TextBox, ...), DisplayType and IsOptional. Undocumented route, no parameters. |
| List Booking Page Requests | `listBookingPageRequests` | Returns the access log of the public booking page from a given date onwards: timestamp, visitor IP, page identifier and browser. Set Summary Only to get aggregated counts instead of individual requests. |
| List Calendar Group Members | `listCalendarGroupMembers` | Lists the calendars belonging to a calendar group. Undocumented route; calendargroupid is required - without it the route answers 400 "The given key 'calendargroupid' was not present in the dictionary.". |
| List Calendar Non-Working Times | `listCalendarsnonworkingtimes` | List the non-working (blocked) time ranges of a calendar. |
| List Calendar Return Times | `listCalendarreturntimes` | List the return times of a calendar. |
| List Calendar Services | `listCalendarServices` | Returns the service-to-calendar assignments, i.e. which services can be booked on which calendar. Optionally restrict the result to one calendar. |
| List Calendars | `listCalendars` | Returns the calendars (resources/staff members) configured in the eTermin account, including name, multilingual descriptions, capacity, time-slot length and booking settings. Optionally filter to a single calendar by its CalendarID. |
| List Calendars For Service | `listCalendarsForService` | Returns the ids of the calendars on which a given service can be booked. Use it to find the bookable resources for a service before requesting time slots. |
| List Contacts | `listContacts` | List or look up contacts by email, external id or contact id (cid). All filters are optional strings - leave them empty to list every contact. |
| List Customer Ratings | `listRatings` | Returns the ratings and written feedback customers left after their appointments, including the score, the calendar and service rated, whether the rating is published and any reply. |
| List Deleted Appointments | `listDeletedAppointments` | Returns appointments that were deleted from the eTermin account, including who deleted them and the original booking details. Filter by a start/end date range or fetch a single deleted appointment by id. |
| List Email Templates | `listEmails` | UNSAFE TO DRIVE - /api/email is eTermin's notification sender. Undocumented route with no published contract; proven to exist and proven correct to the last safe step: with no parameters GET answers 200 with the body \"String '' was not recognized as a valid Boolean.\", which shows it takes a required boolean selector whose name eTermin does not publish. Establish the selector with eTermin support before driving this; do not execute it speculatively. |
| List Files | `listFiles` | Lists the files attached to an appointment or a contact. Undocumented route. Both appid (internal appointment id) and cid (internal contact id) are Int32 and reject an empty value, so both are required - pass 0 for the one you are not filtering on. |
| List Invoices | `listInvoices` | Lists the eTermin subscription invoices issued to this account. Undocumented route, no parameters; returns [] on an account that has never been billed (e.g. Trial). Passing an unknown id instead returns 200 with the plain-text body 'Invalid reference number or you don't have permission to view this data!'. |
| List Locations | `listLocations` | Lists the alternative appointment locations defined on a calendar, each with id, calendarid, name, street, zip, town, country, telephone, mobilephone, emaillocation and web. Undocumented route. calendarid is required: without it the route returns 200 with an EMPTY body rather than a JSON array. |
| List Message Logs | `listMessageLogs` | Returns the log of notification messages eTermin sent (email and SMS), including receiver, subject, delivery status and send date. Filter by log id, by the appointment the message belongs to, or restrict to SMS only. |
| List Payments | `listPayments` | Lists online payments recorded against appointments. Undocumented route, no parameters. On an account with no payment provider configured (e.g. Trial) it answers 200 with an EMPTY body rather than a JSON array - that is the vendor's empty response, not an error. |
| List Service Groups | `listServiceGroups` | Returns the service groups (the question/category blocks shown on the booking page) with their display text, selection behaviour, layout and visibility settings. Optionally fetch one group by id or request a specific language. |
| List Services | `listServices` | Returns the bookable services with their group, duration, price, capacity, colours, booking rules and display texts. Call it with no input to list every service, or pass a Service ID to fetch one. eTermin rejects an empty languageid or ServiceGroupID, so those two filters are offered by the dedicated List Services By Group and List Services In Language actions rather than as optional fields here. |
| List Services By Group | `listServicesByGroup` | Returns the bookable services belonging to one service group. Service Group ID is required because eTermin rejects an empty value for this filter; use List Services to fetch every service instead. |
| List Services In Language | `listServicesInLanguage` | Returns the bookable services with their texts in one specific language. Language is required because eTermin answers "Invalid languageid" to an empty value; use List Services for the account's default language. |
| List Survey Results | `listSurveyResults` | Returns the answers customers gave to appointment surveys, with the question, the answer, the timestamp and the calendar the appointment belonged to. Filter by date or by appointment. |
| List Surveys | `listSurveys` | Lists the post-appointment feedback surveys defined on the account (id, customerid, name, header, infotext, lang). Undocumented route. VENDOR BEHAVIOUR proven live: the only working filter is 'lang' - with no parameter the route returns only the de surveys, and passing an id returns []. Call it once per language you use. Survey answers are read with List Survey Results. |
| List Tags | `listTags` | Lists the appointment tags defined on the account, each with its numeric id, name and creationdate. Undocumented route, no parameters. Tag names are what the 'tags' and 'tagscancel' parameters on a service refer to. |

| List Users | `listUsers` | Returns the backend users of the eTermin account with their id, email address and permission flags (admin, calendar, settings and so on). |
| List Vouchers | `listVouchers` | List all vouchers of the account, including each voucher's numeric internal id (iid). |
| List Web Push Subscriptions | `listWebPushSubscriptions` | Lists the browser push subscriptions registered for this account's backend users (ID, CustomerID, UserID, UserEMail, PushEndpoint, PushP256DH, PushAuth, Description, CreationDate). | List Working Times | `listWorkingtimes` | List the weekly working times of a calendar. NOTE: eTermin's documented 'all' parameter is broken server-side (any value returns 404 'Must declare the scalar variable @calendarid') and is therefore deliberately not exposed. |

## Events

Start a workflow when one of these happens, with an [app event trigger](../../build/triggers/README.md).

| Event | Id | When it fires |
| --- | --- | --- |
| Appointment Created | `CREATED` | Fired when an appointment is booked. REGISTRATION IS UI-ONLY - eTermin has no webhook registration API (POST/PUT/DELETE on /api/webhooks all return 'The method or operation is not implemented.'). Click path in the eTermin backend: API &gt; API & Web Push &gt; enable 'Send Web Push' &gt; put the fastn webhook URL in 'Send to the following URL' &gt; choose JSON as the transfer format &gt; optionally set 'Http header name' + 'Http value' or a 'Secret key hash' &gt; Save, then reload the page. Test without booking with the 'Send Web Push (Created)' button on that page. Deliveries are listed for 14 days under API &gt; Logs. The verification salt/signature pair can be read with GET /api/webhooks?type=3. |
| Appointment Deleted | `DELETED` | Fired when an appointment is cancelled or deleted. Same UI-only registration: eTermin backend &gt; API &gt; API & Web Push &gt; enable 'Send Web Push' &gt; 'Send to the following URL' = the fastn webhook URL &gt; format JSON &gt; Save and reload. Test with the 'Send Web Push (Deleted)' button. The 'reason' field carries why the appointment was deleted. |
| Appointment Modified | `MODIFIED` | Fired when an appointment is changed. Same UI-only registration: eTermin backend &gt; API &gt; API & Web Push &gt; enable 'Send Web Push' &gt; 'Send to the following URL' = the fastn webhook URL &gt; format JSON &gt; Save and reload. Test with the 'Send Web Push (Modified)' button. Payload is the same envelope with command=MODIFIED; externalidold carries the previous external id when it changed during synchronisation. |
