# Acuity Scheduling

<img src="../../.gitbook/assets/connectors/lg/acuity-scheduling.png" alt="Acuity Scheduling logo">

Acuity Scheduling (a Squarespace company) is an online appointment scheduling platform. Manage appointments, appointment types, availability, calendars, clients, intake forms, labels, orders, products, package and coupon certificates, blocked time, and webhook subscriptions through the Acuity Scheduling API v1.

## Use it

Add Acuity Scheduling from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.acuityScheduling.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).

## Events

Start a workflow when one of these happens, with an [app event trigger](../../build/triggers/README.md).

Registered with Acuity as the appointment.canceled subscription; the delivered payload's action field is 'canceled'.</td></tr><tr><td>Appointment Changed</td><td><code>changed</code></td><td>Catch-all that fires whenever an appointment changes in any way, including when it is scheduled, rescheduled, canceled, or has its client details or intake form answers edited. Registered with Acuity as the appointment.changed subscription; the delivered payload's action field is 'changed'.</td></tr><tr><td>Appointment Rescheduled</td><td><code>rescheduled</code></td><td>Fires when an appointment is moved to a new time. Registered with Acuity as the appointment.rescheduled subscription; the delivered payload's action field is 'rescheduled'.</td></tr><tr><td>Appointment Scheduled</td><td><code>scheduled</code></td><td>Fires once when an appointment is initially booked. Registered with Acuity as the order.completed subscription; the delivered payload's action field is 'order.completed'.</td></tr></tbody></table>
