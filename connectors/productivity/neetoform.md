# NeetoForm

<img src="../../.gitbook/assets/connectors/lg/neetoform.png" alt="NeetoForm logo">

This connector wraps the NeetoForm external REST API (v2, plus the deprecated v1) so you can list and create forms, read form submissions with their answers and submitter user-agent details, and manage workspace team members. Authentication is a workspace API key sent in the X-Api-Key header against your workspace subdomain host.

## Use it

Add NeetoForm from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.neetoform.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).

## Events

Start a workflow when one of these happens, with an [app event trigger](../../build/triggers/README.md).

<table><thead><tr><th width="240">Event</th><th width="260">Id</th><th>When it fires</th></tr></thead><tbody><tr><td>Form Submitted</td><td><code>form_submitted</code></td><td>Fires the moment someone completes and submits a NeetoForm form. REGISTRATION IS MANUAL - NeetoForm exposes no webhook-registration API, so the customer pastes the fastn trigger URL into NeetoForm themselves: open the NeetoForm workspace, go to Admin Panel &gt; Webhooks &gt; Add New Webhook, paste the fastn trigger URL as the endpoint (it must accept POST), choose the form-submission event, and click Save Changes. Deliveries and their HTTP responses are inspectable under Admin Panel &gt; Webhooks by clicking the endpoint URL; a failed delivery is retried after 5 minutes and then at widening intervals for up to 6 hours. SIGNATURE: NeetoForm's Add New Webhook screen offers an optional Secret. If one is set, every delivery carries header x-neeto-webhook-signature whose value is 'sha256=' followed by the hex HMAC-SHA256 of the raw JSON body (HTML-escaped) keyed by that secret. fastn cannot currently hold a per-webhook secret for an APP-type config, so this config is set to NONE verification - LEAVE THE SECRET FIELD BLANK IN NEETOFORM, or the signature will go unchecked. EVENT ID: NeetoForm's payload carries no event-type discriminator (only webhook.source = 'NeetoForm') and the vendor publishes no machine-readable event list, so 'form_submitted' is a fastn-side identifier for the single event NeetoForm documents, not a vendor slug. PAYLOAD SCHEMA IS MODELLED from NeetoForm's published sample payload (help.neetoform.com/articles/sample-payload-for-webhook), not captured from a live delivery. The answers object is keyed by each question's field code from its advanced properties, so its keys differ from form to form.</td></tr></tbody></table>
