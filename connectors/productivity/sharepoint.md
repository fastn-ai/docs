# SharePoint

<img src="../../.gitbook/assets/connectors/lg/sharepoint.png" alt="SharePoint logo">

Microsoft SharePoint via Microsoft Graph v1.0 — sites, lists, list items, columns, content types, document libraries (drives), pages, site permissions, followed sites, and change-notification subscriptions (webhooks).

| | |
| --- | --- |
| **Category** | [Productivity](README.md) |
| **Website** | [sharepoint.com](https://sharepoint.com) |
| **Authentication** | OAuth 2.0 |
| **Slug** | `sharepoint` |

## Use it

Add SharePoint from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.sharepoint.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).

## Events

Start a workflow when one of these happens, with an [app event trigger](../../build/triggers/README.md).

<table><thead><tr><th width="240">Event</th><th width="260">Id</th><th>When it fires</th></tr></thead><tbody><tr><td>Resource Created</td><td><code>created</code></td><td>A monitored resource emitted a created change notification (for resources that support the 'created' changeType). Payload shape mirrors the updated notification.</td></tr><tr><td>Resource Deleted</td><td><code>deleted</code></td><td>A monitored resource emitted a deleted change notification (for resources that support the 'deleted' changeType). Payload shape mirrors the updated notification.</td></tr><tr><td>Resource Updated</td><td><code>updated</code></td><td>A monitored SharePoint resource (list item changed in a list, or a driveItem changed in a document library) was updated. SharePoint list/driveItem only support the 'updated' changeType; the notification signals that the list/drive changed and the app should call the items/driveItem delta to find what changed.</td></tr></tbody></table>
