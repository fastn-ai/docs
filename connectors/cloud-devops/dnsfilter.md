# DNSFilter

<img src="../../.gitbook/assets/connectors/lg/dnsfilter.png" alt="DNSFilter logo">

This connector wraps the DNSFilter public REST API (api.dnsfilter.com v1/v2): organizations, users, policies, networks, roaming clients (user agents), block pages, IP/MAC addresses, scheduled policies and reports, traffic reports and analytics, dashboards, billing and MSP/distributor management.

| | |
| --- | --- |
| **Category** | [Cloud and DevOps](README.md) |
| **Website** | [dnsfilter.com](https://dnsfilter.com) |
| **Authentication** | Bearer token |
| **Slug** | `dnsfilter` |

## Use it

Add DNSFilter from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.dnsfilter.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).
