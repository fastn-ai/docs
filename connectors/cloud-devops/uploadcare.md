# Uploadcare

<img src="../../.gitbook/assets/connectors/lg/uploadcare.png" alt="Uploadcare logo">

Manage files, groups, file metadata, webhooks, document and video conversion, and AI add-ons (AWS Rekognition, virus scanning, background removal) via the Uploadcare REST API v0.7, plus uploading via the Upload API.

| | |
| --- | --- |
| **Category** | [Cloud and DevOps](README.md) |
| **Website** | [uploadcare.com](https://uploadcare.com) |
| **Authentication** | Credentials you enter |
| **Slug** | `uploadcare` |

## Use it

Add Uploadcare from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.uploadcare.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).

## Events

Start a workflow when one of these happens, with an [app event trigger](../../build/triggers/README.md).

<table><thead><tr><th width="240">Event</th><th width="260">Id</th><th>When it fires</th></tr></thead><tbody><tr><td>File Deleted</td><td><code>file.deleted</code></td><td>A file was removed from the project.</td></tr><tr><td>File Infected</td><td><code>file.infected</code></td><td>Malware was detected during an automatic or explicit scan (Uploadcare is deprecating this in favor of file.info_updated).</td></tr><tr><td>File Info Updated</td><td><code>file.info_updated</code></td><td>metadata or appdata changed, typically after an add-on ran (object recognition, unsafe content detection, malware protection).</td></tr><tr><td>File Stored</td><td><code>file.stored</code></td><td>A file transitioned to stored status.</td></tr><tr><td>File Uploaded</td><td><code>file.uploaded</code></td><td>A new file was uploaded, a local copy created, or a file generated from a processing operation.</td></tr></tbody></table>
