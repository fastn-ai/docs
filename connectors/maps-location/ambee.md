# Ambee

Ambee provides real-time and forecast environmental intelligence. This connector covers the Ambee REST API: air quality (latest, history and forecast), weather (latest, history and forecast), pollen (latest, history and 48/120-hour forecasts), wildfires and fire risk, natural disasters (latest, history and event lookup), geocoding and reverse geocoding, elevation, and influenza-like illness forecasts.

## Use it

Add Ambee from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.ambee.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).

## Actions

| Action | Slug | What it does |
| --- | --- | --- |
| Geocode Place | `geocodePlace` | Converts a human readable place name or address into latitude and longitude coordinates with a structured address breakdown. |
| Get 120 Hour Pollen Forecast By Coordinates | `getPollenForecast120HoursByCoordinates` | Returns the hourly pollen forecast for the next 120 hours at a latitude and longitude, with predicted counts and risk bands for grass, tree and weed pollen. |
| Get 120 Hour Pollen Forecast By Place | `getPollenForecast120HoursByPlace` | Returns the hourly pollen forecast for the next 120 hours at a named place, with predicted counts and risk bands for grass, tree and weed pollen. |
| Get 48 Hour Pollen Forecast By Coordinates | `getPollenForecast48HoursByCoordinates` | Returns the hourly pollen forecast for the next 48 hours at a latitude and longitude, with predicted counts and risk bands for grass, tree and weed pollen. |
| Get 48 Hour Pollen Forecast By Place | `getPollenForecast48HoursByPlace` | Returns the hourly pollen forecast for the next 48 hours at a named place, with predicted counts and risk bands for grass, tree and weed pollen. |
| Get Air Quality Forecast By Coordinates | `getAirQualityForecastByCoordinates` | Returns the hourly air quality forecast for the next 48 hours at a latitude and longitude, including predicted AQI and pollutant concentrations. The forecast is refreshed every 12 hours. |
| Get Air Quality History By Coordinates | `getAirQualityHistoryByCoordinates` | Returns hourly historical air quality records for a latitude and longitude over a time range. The range available depends on your Ambee plan; the trial plan serves only the past two days. |
| Get Air Quality History By Postal Code | `getAirQualityHistoryByPostalCode` | Returns hourly historical air quality records for a postal code within a country over a time range. The range available depends on your Ambee plan; the trial plan serves only the past two days. |
| Get Disaster By Event ID | `getDisasterByEventId` | Returns the full record for a single natural disaster event by its Ambee event ID, including per-episode detail such as magnitude, depth and alert level, and optionally the affected-area geometry. |
| Get Disaster History By Continent | `getDisasterHistoryByContinent` | Returns natural disaster events that occurred across a continent within a past time range. Results are paginated. |
| Get Disaster History By Coordinates | `getDisasterHistoryByCoordinates` | Returns natural disaster events that occurred near a latitude and longitude within a past time range. Results are paginated. |
| Get Disaster History By Country | `getDisasterHistoryByCountry` | Returns natural disaster events that occurred within a country over a past time range. Results are paginated. |
| Get Elevation By Coordinates | `getElevationByCoordinates` | Returns the ground elevation at a latitude and longitude. Elevation coverage is limited to the regions included in your Ambee plan; locations outside coverage return an empty result set. |
| Get Elevation By Place | `getElevationByPlace` | Returns the ground elevation at a named place. Elevation coverage is limited to the regions included in your Ambee plan; places outside coverage return an empty result set. |
| Get Global Disaster History | `getGlobalDisasterHistory` | Returns natural disaster events recorded worldwide from a given start date onwards, without restricting to a location. Results are paginated. |
| Get Historical Disaster By Source Event ID | `getDisasterHistoryBySourceEventId` | Returns the archived record for a past natural disaster event identified by the id assigned by its originating data source, optionally including the affected-area geometry. |
| Get Influenza Forecast By Coordinates | `getInfluenzaForecastByCoordinates` | Returns a 28-day influenza-like illness risk forecast for a latitude and longitude, optionally with the daily pollen and weather drivers behind it. Coverage is limited to the regions included in your Ambee plan; locations outside coverage return an empty result set. |
| Get Latest Air Quality By City | `getLatestAirQualityByCity` | Returns the most recent hourly air quality readings for a named city, including the AQI, its category and driving pollutant, and pollutant concentrations. |
| Get Latest Air Quality By Coordinates | `getLatestAirQualityByCoordinates` | Returns the most recent hourly air quality reading for a latitude and longitude, including the AQI, its category and driving pollutant, and concentrations of CO, NO2, ozone, PM10, PM2.5 and SO2. |
| Get Latest Air Quality By Country | `getLatestAirQualityByCountry` | Returns the most recent hourly air quality readings for monitoring stations across a country, including the AQI, its category and driving pollutant, and pollutant concentrations. |
| Get Latest Air Quality By Postal Code | `getLatestAirQualityByPostalCode` | Returns the most recent hourly air quality reading for a postal code within a country, including the AQI, its category and driving pollutant, and pollutant concentrations. |
| Get Latest Disaster By Source Event ID | `getLatestDisasterBySourceEventId` | Returns the current record for a natural disaster event identified by the id assigned by its originating data source, such as a USGS earthquake id, optionally including the affected-area geometry. |
| Get Latest Disasters By Continent | `getLatestDisastersByContinent` | Returns the most recent natural disaster events across a continent, with the event type, name, location and identifiers for further lookup. Results are paginated. |
| Get Latest Disasters By Coordinates | `getLatestDisastersByCoordinates` | Returns the most recent natural disaster events near a latitude and longitude, with the event type, name, location, severity and identifiers for further lookup. Results are paginated. |
| Get Latest Disasters By Country | `getLatestDisastersByCountry` | Returns the most recent natural disaster events within a country, with the event type, name, location and identifiers for further lookup. Results are paginated. |
| Get Latest Pollen By Coordinates | `getLatestPollenByCoordinates` | Returns the current hourly pollen reading for a latitude and longitude, with grass, tree and weed pollen counts and risk bands, and a per-species breakdown. |
| Get Latest Pollen By Place | `getLatestPollenByPlace` | Returns the current hourly pollen reading for a named place, with grass, tree and weed pollen counts and risk bands, and a per-species breakdown. |
| Get Latest Weather By Coordinates | `getLatestWeatherByCoordinates` | Returns current weather conditions for a latitude and longitude, including temperature, apparent temperature, humidity, pressure, wind, cloud cover, visibility, UV index, precipitation and a plain language summary. |
| Get Latest Wildfires By Coordinates | `getLatestWildfiresByCoordinates` | Returns active wildfires near a latitude and longitude, each with its detection time, fire weather index, radiative power, burnt area and whether it was satellite-detected or officially reported. |
| Get Latest Wildfires By Place | `getLatestWildfiresByPlace` | Returns active wildfires within a named place, each with its detection time, fire weather index, radiative power and whether it was satellite-detected or officially reported. |
| Get Pollen History By Coordinates | `getPollenHistoryByCoordinates` | Returns hourly historical pollen readings for a latitude and longitude over a time range, with counts and risk bands for grass, tree and weed pollen. |
| Get Pollen History By Place | `getPollenHistoryByPlace` | Returns hourly historical pollen readings for a named place over a time range, with counts and risk bands for grass, tree and weed pollen. |
| Get Weather Forecast By Coordinates | `getWeatherForecastByCoordinates` | Returns the hourly weather forecast for a latitude and longitude, including predicted temperature, humidity, pressure, wind, cloud cover, UV index and precipitation. |
| Get Weather History By Coordinates | `getWeatherHistoryByCoordinates` | Returns hourly historical weather observations for a latitude and longitude over a time range, including temperature, humidity, pressure, wind, cloud cover and precipitation. |
| Get Wildfire Risk By Coordinates | `getWildfireRiskByCoordinates` | Returns a four-week weekly wildfire risk forecast for a latitude and longitude, with the predicted risk score and category alongside the fire weather and fuel moisture drivers behind it. |
| Get Wildfire Risk By Place | `getWildfireRiskByPlace` | Returns a four-week weekly wildfire risk forecast for a named place, with the predicted risk score and category alongside the fire weather and fuel moisture drivers behind it. |
| Reverse Geocode Coordinates | `reverseGeocodeCoordinates` | Converts a latitude and longitude into a human readable address, with a structured breakdown into street, city, state, postal code and country. |

## Events

Start a workflow when one of these happens, with an [app event trigger](../../build/triggers/README.md).

| Event | Id | When it fires |
| --- | --- | --- |
| Air Quality Alert | `airQuality` | Fires when an Ambee air quality alert you configured matches its trigger conditions. SETUP (required, per alert): Ambee has no webhook registration API, so you must create the alert in Ambee's own dashboard. 1) Go to www.getambee.com &gt; Products &gt; Webhooks and click 'Access Ambee Webhooks'. 2) Sign in and request platform access; wait for approval. 3) On the home screen click 'Add Integration' (top right). 4) On Alert Details: name the alert, choose 'air quality' as the data type, enter the locations (or upload a CSV), and add the parameter conditions that should trigger it. 5) On Request Information: choose POST, paste this trigger's fastn webhook URL as the service endpoint, and pick an authentication method (None, API key, Bearer token or Basic auth) plus any custom headers. 6) On Frequency: set the alert frequency (hourly at minimum) and the start and end dates, then submit. Create ONE Ambee alert per fastn trigger URL: Ambee posts each alert only to its own configured endpoint, so routing is by URL and events cannot be mixed across triggers. The payload is a bare JSON array of matching readings and carries no field naming the event type. Payload modelled from Ambee's air quality API field set, not from a captured delivery. |
