# MusicBrainz

<img src="../../.gitbook/assets/connectors/lg/musicbrainz.png" alt="MusicBrainz logo">

Keyless read access to its Web Service v2: look up, browse and search artists, releases, release groups, recordings, works, labels, areas, places, events, instruments, series, URLs and genres, plus lookups by disc ID, ISRC and ISWC. Rate limit: 1 request per second per client.

| | |
| --- | --- |
| **Category** | [Entertainment and media](README.md) |
| **Website** | [musicbrainz.org](https://musicbrainz.org) |
| **Authentication** | No authentication |
| **Slug** | `musicbrainz` |

## Use it

Add MusicBrainz from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.musicbrainz.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).
