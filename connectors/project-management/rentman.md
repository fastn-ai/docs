# Rentman

Rentman is rental and event-production management software covering projects, quotes and invoices, equipment and serial numbers, warehouse stock, crew scheduling and availability, vehicles, subrentals and purchase orders. This connector wraps the Rentman REST API v1.16 at api.rentman.net.

| | |
| --- | --- |
| **Category** | [Project management](README.md) |
| **Website** | [rentman.net](https://rentman.net) |
| **Authentication** | Credentials you enter |
| **Slug** | `rentman` |

## Use it

Add Rentman from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.rentman.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).
