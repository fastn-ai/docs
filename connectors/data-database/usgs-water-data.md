# USGS Water Data APIs

<img src="../../.gitbook/assets/connectors/lg/usgs-water-data.png" alt="USGS Water Data APIs logo">

The USGS Water Data OGC APIs (successor of the legacy NWIS Water Services) give free US water data: continuous (instantaneous) and daily values, field measurements, annual peaks and time-series metadata for streamflow, gage height, groundwater levels and water quality at thousands of monitoring locations, plus the latest values. No API key needed (a free key raises rate limits).

## Use it

Add USGS Water Data APIs from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.usgsWaterData.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).

* **Get Daily Values Collection** `getDailyCollection`: Get Daily values metadata. Daily data provide one data value to represent water conditions for the day. Throughout much of the history of the USGS, the primary water data available was daily data collected manually at the monitoring location once each day. With improved availability of computer storage and automated transmission of data, the daily data published today are generally a statistical summary or metric of the continuous data collected each day, such as the daily mean, minimum, or maximum value. Daily data are automatically calculated from the continuous data of the same parameter code and are described by parameter code and a statistic code. These data have also been referred to as “daily values” or “DV”. Docs: https://api.waterdata.usgs.gov/docs/ogcapi/ (OpenAPI https://api.waterdata.usgs.gov/ogcapi/v0/openapi) (GET /collections/daily)
