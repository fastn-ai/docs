## Setup

Office for National Statistics (ONS) API needs no sign-in, so there is nothing to set up. Add it and use its actions.

## Use it

Add Office for National Statistics (ONS) API from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.onsApi.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).

## Events

Office for National Statistics (ONS) API has no events, so it can't start a workflow by itself. Use its actions in a workflow that another [trigger](../../build/triggers/README.md) starts, such as a schedule or a webhook.
