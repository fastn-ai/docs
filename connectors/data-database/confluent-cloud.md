# Confluent Cloud

Manage Confluent Cloud infrastructure through the Confluent Cloud Control Plane REST API. Covers organizations, environments, Kafka and Schema Registry clusters, Flink compute pools, service accounts, users, API keys, role bindings, IP filtering, networking, stream sharing, notifications, encryption keys, and billing.

## Use it

Add Confluent Cloud from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.confluentCloud.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).
