# CommCare HQ

CommCare HQ by Dimagi — mobile data collection and case management for frontline programs. Read and manage cases, form submissions, mobile workers, web users, groups, applications, lookup tables, locations, device logs, user-configurable reports and OData feeds within a CommCare project space.

| | |
| --- | --- |
| **Category** | [Data and databases](README.md) |
| **Website** | [commcarehq.org](https://commcarehq.org) |
| **Authentication** | Credentials you enter, OAuth 2.0 |
| **Actions** | 94 |
| **Events** | 7 |
| **Slug** | `commcareHq` |

## Use it

Add CommCare HQ from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.commcareHq.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).

## Events

Start a workflow when one of these happens, with an [app event trigger](../../build/triggers/README.md).

| Event | Id | When it fires |
| --- | --- | --- |
| Application Structure Changed | `Application` | Fires when a new version of a CommCare application is built, so downstream systems can refresh their copy of the form and case structure. Registration is manual: CommCare HQ &gt; project space &gt; Project Settings &gt; Data Forwarding &gt; 'Forward App Structure' &gt; 'Add a service to forward to' &gt; paste the fastn webhook URL &gt; Save. |
| Case Created Or Updated | `CommCareCase` | Fires when a case is created, updated or closed in the project space. CommCare has no API for registering webhooks, so a project administrator must add the forwarder by hand: sign in to CommCare HQ, open the project space, go to Project Settings &gt; Data Forwarding, choose 'Forward Cases', click 'Add a service to forward to', paste the fastn webhook URL into URL to forward to, set Payload Format to 'JSON', leave authentication as None, then Save and use 'Test Link' to confirm delivery. |
| Form Stub Received | `XFormInstance-Stub` | Fires as soon as a form submission arrives, carrying only its identifiers rather than the full form data, which is useful for low-latency triggers. Registration is manual: CommCare HQ &gt; project space &gt; Project Settings &gt; Data Forwarding &gt; 'Forward Form Stubs' &gt; 'Add a service to forward to' &gt; paste the fastn webhook URL &gt; Save. |
| Form Submitted | `XFormInstance` | Fires when a form is submitted to the project space. Registration is manual: sign in to CommCare HQ, open the project space, go to Project Settings &gt; Data Forwarding, choose 'Forward Forms', click 'Add a service to forward to', paste the fastn webhook URL into URL to forward to, set Payload Format to 'JSON', then Save and use 'Test Link' to confirm delivery. |
| Location Changed | `Location` | Fires when an organization location is created or updated. Registration is manual: CommCare HQ &gt; project space &gt; Project Settings &gt; Data Forwarding &gt; 'Forward Location Data' &gt; 'Add a service to forward to' &gt; paste the fastn webhook URL &gt; set Payload Format to 'JSON' &gt; Save. Requires the Locations privilege on the CommCare plan. |
| Mobile Worker Changed | `CommCareUser` | Fires when a mobile worker is created or updated in the project space. Registration is manual: CommCare HQ &gt; project space &gt; Project Settings &gt; Data Forwarding &gt; 'Forward Mobile Worker Data' &gt; 'Add a service to forward to' &gt; paste the fastn webhook URL &gt; set Payload Format to 'JSON' &gt; Save. |
| Web User Changed | `WebUser` | Fires when a web user's membership of the project space is created or updated. Registration is manual: CommCare HQ &gt; project space &gt; Project Settings &gt; Data Forwarding &gt; 'Forward Web User Data' &gt; 'Add a service to forward to' &gt; paste the fastn webhook URL &gt; set Payload Format to 'JSON' &gt; Save. |
