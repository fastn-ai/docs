# Brønnøysund Register Centre (Enhetsregisteret)

<img src="../../.gitbook/assets/connectors/lg/brreg.png" alt="Brønnøysund Register Centre (Enhetsregisteret) logo">

The Brønnøysund Register Centre's open API for Norway's Central Coordinating Register for Legal Entities (Enhetsregisteret) and the Register of Non-Profit Organisations: search and get Norwegian companies and sub-units by name, org number, industry, size and address, read roles, group structures, municipalities, organisation forms and change feeds. No API key needed.

| | |
| --- | --- |
| **Category** | [Data and databases](README.md) |
| **Website** | [brreg.no](https://brreg.no) |
| **Authentication** | No authentication |
| **Slug** | `brreg` |

## Use it

Add Brønnøysund Register Centre (Enhetsregisteret) from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.brreg.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).
