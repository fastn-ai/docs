# Brandfetch

Brandfetch is the brand data layer for products and AI agents. This connector covers the Brand API (brand records by domain, email, brand ID, stock/ETF ticker, ISIN or crypto symbol), the Brand Context API, the Transaction API, the Brand Search API, the Logo API CDN and the Brandfetch GraphQL API (webhooks, request logs, organizations, API keys and Brand Police trackers).

## Use it

Add Brandfetch from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.brandfetch.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).

## Actions

| Action | Slug | What it does |
| --- | --- | --- |
| Accept Organization Invitation | `gqlAcceptInvitation` | Accept a pending Brandfetch organisation invitation on behalf of the signed-in user, joining that organisation. Requires a Brandfetch user access token; an API-key credential cannot act as a user. |
| Add Webhook Subscriptions | `gqlAddWebhookSubscriptions` | Subscribe a Brandfetch webhook to the brands it should receive events for, naming them by brand URN, by domain, or both. Subdomains resolve to the registrable domain, a brand named twice is subscribed and charged once, and one call can name at most 1000 entries across both lists. A domain Brandfetch has not indexed yet is refused and nothing in the call is subscribed. Each new subscription costs one API credit, plus one credit per month while it is held. |
| Create API Client | `gqlCreateApiClient` | Create a new Brandfetch API client for an organisation and get back its public client ID, the value used as the c query parameter by the Logo API CDN and the Brand Search API. Requires a Brandfetch user access token. |
| Create API Key | `gqlCreateApiKey` | Mint a new Brand API key for a Brandfetch organisation. SECURITY: the response contains the new key's plaintext secret, which is a live credential and is the only time it is shown in a create response; do not log or persist the result. Requires a Brandfetch user access token. |
| Create Billing Portal Link | `gqlCreateBillingPortalLink` | Create a one-time URL into the Brandfetch billing portal for an organisation, where an administrator can update the payment method, download invoices and manage the subscription. Requires a Brandfetch user access token. |
| Create Brand Police Tracker | `gqlCreateTracker` | Start a Brand Police tracker that watches the web for unauthorised uses of a brand: an IMAGE tracker matches one of the brand's stored image assets, a TEXT tracker matches a search phrase. Trackers count against the organisation's tracker quota. Requires a Brandfetch user access token. |
| Create Checkout Link | `gqlCreateCheckoutLink` | Create a Brandfetch checkout URL for an organisation so a billing administrator can start a paid plan. WARNING: this begins a real purchase flow for the priced plan you name; the returned URL leads to a payment page. Requires a Brandfetch user access token. |
| Create Organization | `gqlCreateOrganization` | Create a new Brandfetch organisation owned by the signed-in user, optionally setting the addresses that receive its notifications. Note that Brandfetch exposes no API route to delete an organisation's own credentials afterwards, so create sparingly. Requires a Brandfetch user access token. |
| Create Shared Checkout Link | `gqlCreateSharedCheckoutLink` | Create a shareable, expiring Brandfetch checkout link for a priced plan, so a colleague who holds the payment method can complete the purchase. WARNING: this begins a real purchase flow. Requires a Brandfetch user access token. |
| Create Webhook | `gqlCreateWebhook` | Register a webhook endpoint with Brandfetch so brand events are delivered to your own HTTPS URL. The response includes the webhook URN and its signing secret, which you need to verify deliveries and which can never be rotated. Requires an active paid Brandfetch subscription: on a free plan the mutation returns success false with code NO_ACTIVE_SUBSCRIPTION and creates nothing. SECURITY: the response body contains the webhook signing secret. |
| Delete API Client | `gqlDeleteApiClient` | Permanently delete a Brandfetch API client. DANGER: every Logo API image URL and Brand Search call using that client ID stops working immediately, including logos already embedded on live web pages. Requires a Brandfetch user access token. |
| Delete API Key | `gqlDeleteApiKey` | Permanently revoke a Brandfetch API key. DANGER: every integration still using that key stops working immediately and the secret cannot be recovered. Deleting the key your own connection authenticates with will break this connector. Requires a Brandfetch user access token. |
| Delete Brand Police Tracker | `gqlDeleteTracker` | Delete a Brand Police tracker and stop it watching the web. Its recorded hits go with it and the tracker quota it used is released. Requires a Brandfetch user access token. |
| Delete My Brandfetch Account | `gqlDeleteAccount` | Permanently delete the signed-in Brandfetch user account. DANGER: this is irreversible, removes the identity the credential authenticates as, and can lock the organisation out of its own data. There is no API route to undo it. Only run it with explicit, informed consent from the account owner. Requires a Brandfetch user access token. |
| Delete Organization | `gqlDeleteOrganization` | Permanently delete a Brandfetch organisation. DANGER: this is irreversible and takes its API keys, API clients, webhooks and billing subscription with it. Deleting the organisation your credential belongs to will revoke that credential. Only run it with explicit, informed consent from the organisation owner. Requires a Brandfetch user access token. |
| Delete Organization Invitation | `gqlDeleteInvitation` | Revoke a pending Brandfetch organisation invitation so it can no longer be accepted. Requires a Brandfetch user access token. |
| Delete Webhook | `gqlDeleteWebhook` | Permanently delete a registered Brandfetch webhook. This also deletes its brand subscriptions and its delivery history and drops any retries still pending, and the signing secret cannot be recovered. Deleting is the only way to replace a secret, since secrets cannot be rotated. |
| Get Authenticated Viewer | `getViewer` | Return the identity of the credential used to authenticate the request, together with the organisation it belongs to and the API credit usage and quota for the current period. Use it to verify a Brandfetch API key during setup and to read the remaining credit allowance before running a batch of lookups. Requests to this endpoint are free and never consume API credits. The response contains the key's id and name but never its secret value. |
| Get Brand | `getBrand` | Retrieve a full Brandfetch brand record using any supported identifier: a domain (nike.com), an email address (john@nike.com, resolved to its registrable domain), a Brandfetch brand ID (id_0dwKPKT), a stock or ETF ticker (NKE), an ISIN (US6541061031) or a crypto symbol (BTC). Returns logos, colours, fonts, images, links and company details. Consumes one API credit per uncached brand. |
| Get Brand By Crypto Symbol | `getBrandByCrypto` | Retrieve a full Brandfetch brand record for a cryptocurrency or token using its symbol, for example BTC or ETH. Use this instead of the auto-detecting Get Brand action when the identifier is known to be a crypto symbol. Consumes one API credit per uncached brand. |
| Get Brand By Domain | `getBrandByDomain` | Retrieve a full Brandfetch brand record for an explicit domain name, avoiding the ambiguity of the auto-detecting Get Brand action. Accepts a domain only; an email address is refused with 400. Returns logos, colours, fonts, images, links and company details. Consumes one API credit per uncached brand. |
| Get Brand By ISIN | `getBrandByIsin` | Retrieve a full Brandfetch brand record for a security using its International Securities Identification Number, for example US6541061031. Use this instead of the auto-detecting Get Brand action when the identifier is known to be an ISIN. Consumes one API credit per uncached brand. |
| Get Brand By Ticker | `getBrandByTicker` | Retrieve a full Brandfetch brand record for a publicly listed company or ETF using its stock ticker symbol, for example NKE. Use this instead of the auto-detecting Get Brand action when a ticker could collide with another identifier type. Consumes one API credit per uncached brand. |
| Get Brand Context | `getBrandContext` | Retrieve a structured, narrative-rich brand context for a domain, built for grounding LLMs and AI agents. Returns identity (tagline, mission, description), positioning, voice and visual style as JSON. Accepts a domain or an email address on that domain, which is resolved to its registrable domain and never stored. Consumes one API credit per uncached domain. |
| Get Brand Context As Markdown | `getBrandContextMarkdown` | Retrieve the same brand context as Get Brand Context but rendered as Markdown, ready to paste straight into an LLM prompt or a system message. Requests the text/markdown representation of the Brand Context API. Consumes one API credit per uncached domain. |
| Get Brand From Transaction | `getBrandFromTransaction` | Turn a raw payment transaction descriptor such as 'STARBUCKS 1523 OMAHA NE' into clean merchant identity: the matched brand record with its name, domain, logos, colours and company details. A well-formed descriptor that cannot be confidently matched returns 400 'Failed to enrich transaction', which retrying will not change; fall back to showing the raw descriptor. Consumes one API credit per uncached merchant. |
| Get Brand Logo Image | `getLogoImage` | Fetch a brand's logo image straight from the Brandfetch Logo API CDN using an auto-detected identifier (domain, brand ID, ticker, ISIN or crypto symbol). Returns the image bytes, normally as WebP. The Logo API authenticates with the public client ID rather than the API key and does not consume Brand API credits. Use Get Brand Logo Image By Type when you need an explicit identifier type or a specific size, theme or fallback. |
| Get Brand Logo Image By Type | `getLogoImageByType` | Fetch a brand's logo image from the Brandfetch Logo API CDN with an explicit identifier type and full rendering control: width, height, light or dark theme, fallback behaviour and asset type. Because every option is a URL path segment the CDN requires all of them together, so all inputs are required. Returns the image bytes, normally as WebP. Authenticates with the public client ID and does not consume Brand API credits. |
| Get Brand Police Tracker | `gqlGetTracker` | Fetch a single Brand Police tracker by id, with its kind, status, tracked asset or text, and every hit found so far, including the page and domain where the match appeared. Requires a Brandfetch user access token; an API-key credential receives 'User context is required.' |
| Get Brand Record (GraphQL) | `gqlGetBrand` | Fetch a single brand from the Brandfetch GraphQL API by brand URN or by domain, returning only the fields you need in one typed request. Note that this GraphQL field is role-gated: a plain API key receives 'Viewer is not correctly authorized. Missing the required role(s) for this resource.' Use the REST Get Brand action for API-key credentials. |
| Get GraphQL API Version | `gqlGetApiVersion` | Return the version string of the Brandfetch GraphQL API. A cheap, unauthenticated-in-effect health check for confirming the GraphQL endpoint is reachable and the credential is accepted. Takes no inputs and consumes no Brand API credits. |
| Get Taxonomy | `gqlGetTaxonomy` | Return Brandfetch's reference taxonomy in one call: the full industry tree with ids, slugs and emoji, all supported countries with their codes and coordinates, and the geographic region hierarchy. Use the industry ids it returns as filter values for the brand directory search. Takes no inputs and consumes no Brand API credits. |
| Get Viewer Account (GraphQL) | `gqlGetViewer` | Return the signed-in Brandfetch user with their profile, the organisations they belong to, billing subscriptions, overage limits, pending invitations, feature quotas and the billing plans available to them. Requires a Brandfetch user access token; an API-key credential receives 'Organization context is required.' Use the REST Get Authenticated Viewer action for API-key credentials. |
| Get Webhook | `gqlGetWebhook` | Fetch a single registered Brandfetch webhook by its URN, including its URL, enabled state, event types, brand subscriptions and its signing secret. SECURITY: the response body contains the webhook signing secret, so treat every stored result as a credential. |
| Get Webhook Deliveries | `gqlGetWebhookDeliveries` | Read the delivery history of a Brandfetch webhook: up to 100 attempts per page, newest first, each with the status, the timestamps and your endpoint's own response body, headers and HTTP status code. Delivery history is retained for 90 days. Use it to debug a failing endpoint or to recover events missed during an outage. |
| List API Request Logs | `gqlListApiRequestLogs` | List the Brand API request log for an organisation: which API key made each call, the service, method, path or GraphQL field, the status code, the user agent and the source IP. Filter by time window, by API key or by status class. Requires a Brandfetch user access token; an API-key credential receives 'User context is required.' |
| List Brand Police Trackers | `gqlListTrackers` | List every Brand Police tracker configured for a brand, with its kind, status and tracked text. Brand Police watches the web for unauthorised uses of a brand's logo or name. Requires a Brandfetch user access token; an API-key credential receives 'User context is required.' |
| List Brand Search Request Logs | `gqlListBrandSearchRequestLogs` | List the Brand Search API request log for an organisation: the search term used, the API client, the status code, bytes returned, cache result, referring page and the requester's country. Filter by time window, by API client or by status class. Requires a Brandfetch user access token; an API-key credential receives 'User context is required.' |
| List Logo CDN Request Logs | `gqlListLogoCdnRequestLogs` | List the Logo API CDN request log for an organisation: which API client served each image, the requested domain, asset type and format, the bytes served, the cache result, the referring page and the requester's country. Filter by time window, by API client or by status class. Requires a Brandfetch user access token; an API-key credential receives 'User context is required.' |
| List Organization API Clients | `gqlListOrganizationApiClients` | List the API clients (client IDs) held by each organisation the credential belongs to, with each client's kind, public key, description and last-used time. API clients are what authenticate the Logo API CDN and the Brand Search API. Requires a Brandfetch user access token; an API-key credential receives 'Organization context is required.' |
| List Organization API Keys | `gqlListOrganizationApiKeys` | List the Brand API keys held by each organisation the credential belongs to, with each key's name, quota, last-used time and credit usage. SECURITY WARNING: Brandfetch returns the plaintext secret of every API key in this response, so any consumer of this action receives live credentials; do not log or persist the result. Requires a Brandfetch user access token; an API-key credential receives 'Organization context is required.' |
| List Organization Members | `gqlListOrganizationUsers` | List the members of each organisation the credential belongs to, together with the invitations still pending on that organisation. Requires a Brandfetch user access token; an API-key credential receives 'Organization context is required.' |
| List Subscribable Events | `gqlListSubscribableEvents` | List every event type a Brandfetch webhook can subscribe to, with its namespace, description and subscription scope. Use it to populate an event-type picker before creating a webhook. Takes no inputs and consumes no Brand API credits. |
| List Webhooks | `gqlListWebhooks` | List the webhook endpoints registered on a Brandfetch organisation, with their URL, enabled state, subscribed event types and current brand subscriptions. Uses the Brandfetch GraphQL API. |
| Prefetch Brand | `prefetchBrandHead` | Check whether Brandfetch already holds a brand and, when it does not, queue a crawl so the next Get Brand call is answered from the store instead of waiting on a live crawl. HEAD /v2/brands/{identifier}: 200 when the brand is held, 202 when a crawl was queued, 404 when nothing can be fetched, and it never consumes an API credit. Available on paid Brandfetch plans only; a free plan receives 403 with the header x-bf-error: paid_plan_required. KNOWN LIMITATION: the fastn action engine cannot currently issue a HEAD request against an absolute URL, so this action cannot be executed through fastn today; the route itself is verified live with curl. |
| Prefetch Brand By Domain | `prefetchBrandByDomain` | The same availability check as Prefetch Brand, on the explicit domain route. HEAD /v2/brands/domain/{domain} accepts a domain only and refuses an email address with 400: 200 when the brand is held, 202 when a crawl was queued, 404 when nothing can be fetched. It never consumes an API credit. Available on paid Brandfetch plans only; a free plan receives 403 with the header x-bf-error: paid_plan_required. KNOWN LIMITATION: the fastn action engine cannot currently issue a HEAD request against an absolute URL, so this action cannot be executed through fastn today; the route itself is verified live with curl. |
| Record Organization Attribution | `gqlRecordOrganizationAttribution` | Attach Google Analytics client and session identifiers to a Brandfetch organisation so Brandfetch can attribute the signup to the marketing session that produced it. Requires a Brandfetch user access token. |
| Redeem Shared Checkout Link | `gqlRedeemSharedCheckoutLink` | Redeem a shared Brandfetch checkout token and get back the checkout URL it points to. WARNING: this continues a real purchase flow. Requires a Brandfetch user access token. |
| Remove User From Organization | `gqlRemoveUserFromOrganization` | Remove a member from a Brandfetch organisation. DANGER: removing the last remaining member, or the member whose credential you are using, can lock the organisation out permanently with no API route to recover it. | Remove Webhook Subscriptions | `gqlRemoveWebhookSubscriptions` | Unsubscribe a Brandfetch webhook from one or many brands by brand URN, stopping their events and their monthly subscription cost. Pausing a webhook does not stop its subscriptions renewing, so removing them here is how you stop paying for brands you no longer follow. |
| Request Brand Crawl | `gqlRequestBrand` | Ask Brandfetch to crawl and index a domain it does not yet hold, optionally calling back a URL of yours when the brand is ready. Use it to add a missing company to the dataset instead of polling Get Brand. |
| Request Brand Refresh | `gqlRequestRefresh` | Ask Brandfetch to re-crawl a brand it already holds so its logos, colours and company data are brought up to date, optionally calling back a URL of yours when the refresh completes. | Search Brand Directory (GraphQL) | `gqlSearchBrands` | Search the Brandfetch brand directory with structured filters (domain, name, query text, country, city, industry, employee count, quality score, verified, claimed, featured, NSFW) and cursor pagination, returning full brand records. | Send Organization Invitation | `gqlSendInvitation` | Invite someone to join a Brandfetch organisation by email address. NOTE: this sends a real invitation email to the address you give, so only use addresses you are authorised to contact. Requires a Brandfetch user access token. |

| Update API Client | `gqlUpdateApiClient` | Rename a Brandfetch API client or change its description. Its public client ID and kind are not affected. Requires a Brandfetch user access token. |
| Update API Key | `gqlUpdateApiKey` | Rename a Brandfetch API key or change its description. The key's secret and quota are not affected. Requires a Brandfetch user access token. |
| Update Billing Preferences | `gqlUpdateBillingPreferences` | Set an organisation's billing contact email and its soft and hard overage dollar limits, which cap how much extra Brandfetch may charge once the plan's credits are used up. | Update Webhook | `gqlUpdateWebhook` | Change a registered Brandfetch webhook: its delivery URL, its Authorization delivery header, its event types, its description, or whether it is enabled. Only the fields you supply are changed. Note that the event list replaces the stored set rather than adding to it, and that an empty list is refused. ## Events

Start a workflow when one of these happens, with an [app event trigger](../../build/triggers/README.md).

| Event | Id | When it fires |
| --- | --- | --- |
| Brand Claimed | `brand.claimed` | Triggered when a brand is claimed by its owner on Brandfetch. Payload schema modelled from Brandfetch's documented sample delivery, not captured live. |
| Brand Company Data Updated | `brand.company.updated` | Triggered any time a brand's company data (employees, industry, location, financial identifiers) is updated. Re-indexing a brand commonly emits this alongside brand.updated. Payload schema modelled from Brandfetch's documented sample delivery, not captured live. |
| Brand Deleted | `brand.deleted` | Triggered when a brand is soft-deleted, for example after an owner take-down request or when its website can no longer be retrieved. Brand API requests for that id return 404 afterwards. Payload schema modelled from Brandfetch's documented sample delivery, not captured live. |
| Brand Updated | `brand.updated` | Triggered any time a brand's data is updated. The delivery carries a snapshot of the brand; it does not say which fields changed, so compare it with your stored copy. Payload schema modelled from Brandfetch's documented sample delivery (docs.brandfetch.com/delivery-methods/webhooks/overview), not captured live: webhook creation is refused on this account with NO_ACTIVE_SUBSCRIPTION. |
| Brand Verified | `brand.verified` | Triggered when a brand's data has been human-reviewed by Brandfetch's curation team. Payload schema modelled from Brandfetch's documented sample delivery, not captured live. |
