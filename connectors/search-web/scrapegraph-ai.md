# ScrapeGraphAI

<img src="../../.gitbook/assets/connectors/lg/scrapegraph-ai.png" alt="ScrapeGraphAI logo">

This connector covers the ScrapeGraphAI v2 API: multi-format page scraping, natural-language structured extraction, web search with inline content, asynchronous crawls with status, paginated pages, stop, resume and delete, scheduled monitors with change detection and webhook delivery, request history, credits, API key validation and health, plus the agent payment, offering discovery and agent enrollment endpoints.

| **Slug** | `scrapegraphAi` |

## Use it

Add ScrapeGraphAI from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.scrapegraphAi.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).

## Events

Start a workflow when one of these happens, with an [app event trigger](../../build/triggers/README.md).

<table><thead><tr><th width="240">Event</th><th width="260">Id</th><th>When it fires</th></tr></thead><tbody><tr><td>Monitor Change Detected</td><td><code>monitor.change.detected</code></td><td>Fires when a ScrapeGraphAI monitor tick detects that the watched page changed compared with the previous run (the first tick always counts as a change). Subscribing creates a monitor through the ScrapeGraphAI API for the page in the monitorUrl input, on the cron schedule in interval (default every 30 minutes), capturing the format input (default markdown), with the fastn webhook URL as its webhookUrl; unsubscribing deletes that monitor. Each tick costs the format's credits plus 5 credits when a change is detected. The payload schema was captured from a real delivery; ScrapeGraphAI does not sign webhook requests.</td></tr></tbody></table>
