## Setup

Your customers enter their API key for NeverBounce when they connect. Nothing else needs setting up.

## Use it

Add NeverBounce from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.neverBounce.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).

## Actions

## Events

Start a workflow when one of these happens, with an [app event trigger](../../build/triggers/README.md).

NeverBounce has no webhook-registration API, so the URL is registered per job at job-creation time.</td></tr><tr><td>Job Review Completed</td><td><code>job_review_completed</code></td><td>A bulk job has been released from NeverBounce's manual review queue.
