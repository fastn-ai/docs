# Didit

<img src="../../.gitbook/assets/connectors/lg/didit.png" alt="Didit logo">

Didit identity infrastructure: KYC verification sessions, KYB business verification, AML screening and monitoring, transaction monitoring (KYT), wallet screening, Travel Rule, case management, regulatory reports, workflows, questionnaires, webhooks and billing, over the Didit REST API at verification.didit.me.

## Use it

Add Didit from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.didit.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).
