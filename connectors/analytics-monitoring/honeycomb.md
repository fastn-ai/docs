# Honeycomb

<img src="../../.gitbook/assets/connectors/honeycomb.ico" alt="Honeycomb logo" width="64">

Honeycomb is an observability platform for querying, alerting on and exploring event, trace and log data.

| | |

## Use it

Add Honeycomb from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.honeycomb.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).

## Actions

| Action | Slug | What it does |
| --- | --- | --- |
| Create API Key | `createApiKey` | Create a configuration or ingest API key in an environment. The secret is returned only in this response and cannot be retrieved later, so capture data.attributes.secret immediately. Requires the api-keys:write scope. Uses the Honeycomb v2 management API, so the connection's optional Management API Key must be set - the environment Configuration API Key cannot call this endpoint. Requests and responses use the JSON:API media type application/vnd.api+json. |
| Create Board | `createBoard` | Create a board made up of query, SLO and text panels. Query panels reference a saved query and a query annotation rather than embedding a query definition, so create those first with Create Query and Create Query Annotation. A board may carry at most 5 preset filters. |
| Create Board View | `createBoardView` | Create a saved filter view on a board, so viewers can switch the whole board to a pre-set filter combination. A board may have at most 50 views. |
| Create Burn Alert | `createBurnAlert` | Create a burn alert on an SLO. Choose Alert Type exhaustion_time and set Exhaustion Minutes to be warned before the error budget runs out, or budget_rate and set both Budget Rate Window Minutes and Budget Rate Decrease Threshold Per Million to be warned when the budget drops sharply. Honeycomb rejects fields belonging to the other alert type. Requires an API key with the Manage SLOs permission. |
| Create Calculated Field | `createCalculatedField` | Create a Calculated Field, also called a Derived Column, so that queries can group and filter on the result of an expression evaluated over each event. A Calculated Field returning a boolean is also what an SLO uses as its service level indicator. |
| Create Column | `createColumn` | Create a column in a dataset before any event has populated it, so that it can be given a type and a description up front. Requires an API key with the Manage Queries and Columns permission. |
| Create Dataset | `createDataset` | Create a dataset in the environment the API key belongs to. If a dataset with the same name or slug already exists, Honeycomb returns the existing dataset with status 200 instead of creating a duplicate. Requires an API key with the Create Datasets permission. |
| Create Environment | `createEnvironment` | Create an environment on a team. Requires the environments:write scope. Uses the Honeycomb v2 management API, so the connection's optional Management API Key must be set - the environment Configuration API Key cannot call this endpoint. Requests and responses use the JSON:API media type application/vnd.api+json. |
| Create Marker | `createMarker` | Create a marker in a dataset so that a deploy, incident or other notable moment is drawn on every query graph. Pass __all__ as the dataset slug to create an environment-wide marker. |
| Create Marker Setting | `createMarkerSetting` | Assign a display colour to a marker type so that every marker of that type is drawn in the same colour across the dataset. |

## Events

Start a workflow when one of these happens, with an [app event trigger](../../build/triggers/README.md).

| Event | Id | When it fires |
| --- | --- | --- |
| SLO Burn Alert - Budget Rate | `budget_rate` | An SLO burn alert of type budget_rate fired: the SLO's error budget dropped by at least the configured percentage within the configured window. SETUP (must be repeated for every Honeycomb environment, because Honeycomb has no event-subscription API - it only pushes when an alert fires): 1. Create the webhook destination. Either run this connector's Create Recipient action with Type set to webhook, Details &gt; Webhook URL set to this trigger's URL and Details &gt; Webhook Secret set to a shared secret; or in the Honeycomb UI go to Account menu &gt; Team settings &gt; Integrations &gt; Webhooks &gt; Add Webhook and paste the same URL and secret. 2. Add the routing field. Honeycomb sends no event-type discriminator of its own, so edit this recipient's payload template for this alert type (Honeycomb UI &gt; Team settings &gt; Integrations &gt; Webhooks &gt; your webhook &gt; Customize Payload, or the Details &gt; Webhook Payloads &gt; Payload Templates &gt; Budget Rate field on Create Recipient) and include the literal line "event_type": "budget_rate" at the top level. Without it fastn cannot route this event. 3. Attach the recipient to the alert. Open the SLO in the Honeycomb UI under Environment &gt; SLOs &gt; your SLO &gt; Burn Alerts &gt; the budget-rate alert &gt; Recipients and add this webhook, or run this connector's Create Burn Alert action with Alert Type budget_rate and the recipient's ID in the Recipients list. Delivery only happens when that alert actually fires - registering the recipient on its own receives nothing. |
