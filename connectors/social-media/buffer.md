# Buffer

<img src="../../.gitbook/assets/connectors/lg/buffer.png" alt="Buffer logo">

Buffer is a social media management platform for planning, scheduling, and publishing content across social channels. This connector uses the Buffer GraphQL API (https://api.buffer.com) to read account and organization details, list and inspect connected channels and their posting schedules, create, schedule, draft, edit, reorder and delete posts, manage the Ideas library and idea groups, manage post templates, tags, hashtag snippets and multi-channel content items (with channel-less drafts), read the per-organization configuration and Instagram audio catalog, check daily posting limits, and read per-post and aggregated post analytics.

## Use it

Add Buffer from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.buffer.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).

| Add Post To Content Item | `addPostToContentItem` | Add a post that already exists to a content item. The mutation creates no post. To add a new post, call createPost first. **Status:** ⚠️ Experimental Status: Experimental. GraphQL errors come back with HTTP 200 in errors[]; mutation errors as data.&lt;op&gt;.message. |
| Create Content Item | `createContentItem` | Create a content item together with all of its channel-specific post variants in a single operation. Validation is all-or-nothing: if any variant fails validation, no content item and no variants are created. Variants that fail while being processed after creation are reported per channel in the failure payload; the content item and its variants are still created in that case. This API is an early preview and can change without a deprecation period. **Status:** ⚠️ Experimental Status: Experimental. GraphQL errors come back with HTTP 200 in errors[]; mutation errors as data.&lt;op&gt;.message. |
| Create Content Item Draft | `createContentItemDraft` | Create a content item holding a channel-less draft, before any channels are selected. No network-specific validation applies to the draft content. The draft needs text or at least one asset. This API is an early preview and can change without a deprecation period. **Status:** ⚠️ Experimental Status: Experimental. GraphQL errors come back with HTTP 200 in errors[]; mutation errors as data.&lt;op&gt;.message. |
| Create Idea | `createIdea` | Creates an idea in a Buffer organization's Ideas library, with optional media, tags, target services, a target date and a placement on the Ideas board. |
| Create Post | `createPost` | Creates a post on a Buffer channel — queued, custom-scheduled, published immediately, or saved as a draft. Set Save As Draft to true to stage content without publishing it. Service-specific options such as Instagram post type, a Pinterest board or a YouTube category go in the matching key of the metadata object. |
| Create Post Template | `createPostTemplate` | Creates a reusable post template, visible either only to the caller (private) or to everyone in the caller's organization (internal). Public visibility is reserved for Buffer-curated templates and is rejected. |
| Create Tag | `createTag` | Create a tag for an organization. The name must be unique within the organization; a duplicate is refused with `DuplicateError`. Creation is refused with `LimitReachedError` once the organization already holds as many tags as its plan allows. This API is an early preview and can change without a deprecation period. **Status:** ⚠️ Experimental Status: Experimental. GraphQL errors come back with HTTP 200 in errors[]; mutation errors as data.&lt;op&gt;.message. |
| Delete Content Item | `deleteContentItem` | Delete a content item: the item itself and any posts created from it. Deletion is all-or-nothing. Every post must be deletable on its own, or nothing is deleted and every blocked post is reported at once. A post can only be deleted while it is a draft, awaiting approval, scheduled, or failed, so an item cannot be deleted while any of its posts is publishing or already published. An item still holding a channel-less draft has no posts, so nothing blocks it. An error can also be reported when a post could not be fully processed after the deletion already took effect; re-fetch before retrying. Deleting a content item also deletes the team notes on the item and on its posts. The notes are removed shortly after the item is deleted. This API is an early preview and can change without a deprecation period. **Status:** ⚠️ Experimental Status: Experimental. GraphQL errors come back with HTTP 200 in errors[]; mutation errors as data.&lt;op&gt;.message. |
| Delete Post | `deletePost` | Deletes a Buffer post by ID. Deleting a post that has already been sent removes it from Buffer only and does not remove the published post from the social network. |
| Delete Post Template | `deletePostTemplate` | Deletes a post template owned by the caller, or an internal template in the caller's organization when the caller is an organization admin or owner. |
