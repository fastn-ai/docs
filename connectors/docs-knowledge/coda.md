# Coda

<img src="../../.gitbook/assets/connectors/lg/coda.png" alt="Coda logo">

Coda API (v1) connector — programmatically interact with Coda docs, pages, tables, columns, rows, formulas, controls, permissions (ACL), doc analytics, and automation webhook triggers. Base: https://coda.io/apis/v1

| | |
| --- | --- |
| **Category** | [Docs and knowledge](README.md) |
| **Website** | [coda.io](https://coda.io) |
| **Authentication** | Bearer token |
| **Slug** | `coda` |

## Use it

Add Coda from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.coda.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).

## Events

Start a workflow when one of these happens, with an [app event trigger](../../build/triggers/README.md).

<table><thead><tr><th width="240">Event</th><th width="260">Id</th><th>When it fires</th></tr></thead><tbody><tr><td>Automation Webhook (Custom Payload)</td><td><code>automation.webhook</code></td><td>Generic webhook-invoked automation delivering an arbitrary JSON payload. Use this for any Coda automation whose action is 'Send a webhook' targeting the fastn URL, or as the catch-all for custom payloads pushed via the Trigger Webhook Automation action.</td></tr><tr><td>Button Pushed</td><td><code>button.pushed</code></td><td>A button in the doc was pushed, triggering an automation that posts to the fastn webhook URL.</td></tr><tr><td>Page Changed</td><td><code>page.changed</code></td><td>A page's content changed. Configured via a Coda page-change automation that posts to the fastn webhook URL.</td></tr><tr><td>Row Changed</td><td><code>row.changed</code></td><td>An existing row's values changed. Configured via a 'When a row changes' Coda automation that posts to the fastn webhook URL.</td></tr><tr><td>Row Created</td><td><code>row.created</code></td><td>A new row was added to a table. Configured in Coda via a 'When a row is added' automation that sends a webhook to the fastn URL.</td></tr><tr><td>Scheduled Time</td><td><code>time.scheduled</code></td><td>A time-based Coda automation fired on schedule and posted to the fastn webhook URL.</td></tr></tbody></table>
