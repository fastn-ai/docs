# Docupilot

<img src="../../.gitbook/assets/connectors/lg/docupilot.png" alt="Docupilot logo">

Docupilot is a document automation platform that generates PDF, DOCX, XLSX and PPTX documents from reusable templates and structured merge data. This connector covers the Docupilot v1 REST API: template folders, templates and their HTML content, document generation by merging JSON data into a template, per-template delivery configuration, and the document generation history.

## Use it

Add Docupilot from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.docupilot.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).

## Events

Start a workflow when one of these happens, with an [app event trigger](../../build/triggers/README.md).

<table><thead><tr><th width="240">Event</th><th width="260">Id</th><th>When it fires</th></tr></thead><tbody><tr><td>Document Generated</td><td><code>document.generated</code></td><td>Fires each time Docupilot finishes generating a document from the template this delivery belongs to. Repeat for every template whose documents should reach this trigger. IMPORTANT DELIVERY SHAPE: Docupilot sends the webhook as an HTTP POST with Content-Type multipart/form-data carrying the generated document as 'file' and its name as 'file_name', plus whatever fields the user configured in the delivery's Data box - it is not a JSON event envelope. The payload therefore has no vendor-defined event-type field, which is why no eventKey is set on this configuration. SIDE EFFECT: once a delivery exists on a template, Generate Document stops returning a download URL and returns a null data payload instead, because the document is routed to the configured deliveries. The payload schema below is modelled from the vendor's documentation (help.docupilot.app/deliveries/webhook), not captured from a live delivery.</td></tr></tbody></table>
