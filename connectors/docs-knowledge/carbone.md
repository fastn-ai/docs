# Carbone

<img src="../../.gitbook/assets/connectors/lg/carbone.png" alt="Carbone logo">

Upload and manage DOCX/XLSX/ODT/HTML/MD templates, merge them with JSON data to render PDF/DOCX/XLSX/CSV/images, and download generated reports. Requires an API token from account.carbone.io; every request also sends the carbone-version: 5 header.

## Use it

Add Carbone from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.carbone.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).

## Events

Start a workflow when one of these happens, with an [app event trigger](../../build/triggers/README.md).

<table><thead><tr><th width="240">Event</th><th width="260">Id</th><th>When it fires</th></tr></thead><tbody><tr><td>Report Rendered</td><td><code>report.rendered</code></td><td>Fires when Carbone finishes an asynchronous render. Carbone has NO webhook subscription API - the callback URL is supplied per render, so there is nothing for fastn to register and nothing to unsubscribe. SETUP (per render, not once): copy this trigger's fastn webhook URL, then call the 'Render Report Asynchronously To Webhook' action with carboneWebhookUrl set to that URL (Carbone sends it as the carbone-webhook-url request header). Optionally set carboneWebhookHeaderAuthorization to a shared secret, which Carbone sends back as the authorization header on the callback. Carbone then POSTs {"success":true,"data":{"renderId":"..."}} with User-Agent: Carbone, and retries once on 408/429/502/503/504/521/522/524 or a socket error (16s request timeout). Pass the renderId to 'Download Generated Report'; it is single-use and expires after one hour. The payload carries NO account identifier and NO event-type discriminator - report.rendered is the only event Carbone emits - so there is no eventKey and no mappedTo account filter; routing is inherent because the callback URL is per trigger. payloadSchema below was captured from a REAL Carbone delivery, not modelled.</td></tr></tbody></table>
