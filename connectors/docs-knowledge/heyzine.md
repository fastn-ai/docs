## Setup

Your customers enter their client id and api key for Heyzine Flipbooks when they connect. Nothing else needs setting up.

## Use it

Add Heyzine Flipbooks from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.heyzine.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).

## Events

Start a workflow when one of these happens, with an [app event trigger](../../build/triggers/README.md).

<table><thead><tr><th width="240">Event</th><th width="260">Id</th><th>When it fires</th></tr></thead><tbody><tr><td>New Leads Collected</td><td><code>leads</code></td><td>Fires when new leads are collected by any lead generation form in the Heyzine account. Heyzine has no webhook registration API, so this endpoint is registered by hand: sign in at https://heyzine.com, open https://heyzine.com/account, scroll to the 'Webhooks' heading, paste the fastn webhook URL into 'New leads webhook: Endpoint URL', choose a 'Webhook frequency' other than 'Never', and press 'Save'. The Webhooks section is only rendered for plans that include lead generation forms, so a free account will not show it. Heyzine batches leads and delivers them on the chosen frequency rather than one request per lead. NOTE: the leads payload carries no type discriminator, so a delivery is recognised by the presence of data.leads rather than by the connector's event key.</td></tr><tr><td>One-Time Access Code Issued</td><td><code>webhook_code</code></td><td>Fires when a reader requests access to a flipbook or bookshelf whose access list entry uses the 'webhook_code' access type, delivering the one-time code to your endpoint instead of emailing it. This one IS registered through the API: call the Add User Access action with access_type 'webhook_code', the reader's email as user, and the fastn webhook URL as password. Remove it with the Remove User Access action. Any non-200 response is retried up to three times. The webhook_code access type requires a Heyzine Premium plan.</td></tr></tbody></table>
