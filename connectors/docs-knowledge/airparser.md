# Airparser

<img src="../../.gitbook/assets/connectors/lg/airparser.png" alt="Airparser logo">

Airparser is an AI-powered document and email parser that extracts structured data from PDFs, emails, images and spreadsheets. This connector covers the Airparser public API: inboxes, extraction schemas, documents and parsed results, post-processing, document review, integrations (webhooks, Zapier, Make, n8n, Google Sheets), team, account settings and billing information.

## Use it

Add Airparser from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.airparser.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).

## Events

Start a workflow when one of these happens, with an [app event trigger](../../build/triggers/README.md).

<table><thead><tr><th width="240">Event</th><th width="260">Id</th><th>When it fires</th></tr></thead><tbody><tr><td>Document Failed</td><td><code>doc.fail</code></td><td>Fires when Airparser cannot process a document, for example an unsupported file or an exhausted credit balance. Set the inboxId input to the Airparser inbox this trigger should watch. The envelope shown here is the one captured from real doc.parsed and doc.received deliveries; this event's own body is modelled from it, because no failure could be provoked on the test account.</td></tr><tr><td>Document Parsed</td><td><code>doc.parsed</code></td><td>Fires when Airparser finishes extracting data from a document. Set the inboxId input to the Airparser inbox this trigger should watch. Payload schema captured from a real delivery. Airparser signs each delivery with an airparser-signature header holding base64(HMAC-SHA256(raw body, webhook secret)); the secret is unique per registration and is returned by the subscription, so the receiver must verify it.</td></tr><tr><td>Document Received</td><td><code>doc.received</code></td><td>Fires as soon as a document arrives in the inbox, before parsing starts. Payload schema captured from a real delivery: it carries only the inbox id, the document id and the event name, with no payload object, because nothing has been extracted yet. Fetch the result later with Get Document, or use Document Parsed instead. Set the inboxId input to the Airparser inbox this trigger should watch.</td></tr></tbody></table>
