## Setup

Your customers enter their API token for Placid when they connect. Nothing else needs setting up.

## Use it

Add Placid from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.placid.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).

## Events

Start a workflow when one of these happens, with an [app event trigger](../../build/triggers/README.md).

<table><thead><tr><th width="240">Event</th><th width="260">Id</th><th>When it fires</th></tr></thead><tbody><tr><td>Image Render Completed</td><td><code>image</code></td><td>Fires when Placid finishes rendering an image. Placid has no webhook-registration API - the callback is set per render: copy this trigger's URL and pass it as the Success Webhook URL input on the Create Image action (the webhook_success field). Placid then POSTs the finished image object to it. Check status in the payload: it is finished on success and error when the render failed.
