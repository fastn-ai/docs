# Digital Humani

<img src="../../.gitbook/assets/connectors/digital-humani.png" alt="Digital Humani logo" width="64">

Digital Humani RaaS (Reforestation as a Service) API. Plant trees with trusted reforestation organizations, browse reforestation projects, count trees planted by user/enterprise/month, manage the enterprise profile and its users, and drive the dashboard auth surface. Supports both the Production host (api.digitalhumani.com, $1 per tree, real money) and the free Sandbox host (api.sandbox.digitalhumani.com).

## Use it

Add Digital Humani from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.digitalHumani.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).

## Actions

| Action | Slug | What it does |
| --- | --- | --- |
| Change Dashboard Password | `changeDashboardPassword` | Change a signed-in dashboard user's password when the current password is known (as opposed to the emailed-token reset flow). POST /auth/update-password. Undocumented but live (found in the my.digitalhumani.com dashboard bundle). Requires email, currentPassword, password1 and password2; each password must be 8+ characters with at least one uppercase, one lowercase and one number, and password1 must equal password2. AUTH: dashboard SESSION COOKIE from Log In To Dashboard, not X-Api-Key - with only the API key it answers 401 Unauthorized, and fastn carries no cookie jar between actions. A nonsense-suffix control (/auth/update-passwordZZZ) 404s, so the route is real. |
| Count Enterprise Trees By Date Range | `countEnterpriseTreesByDateRange` | Count the trees an enterprise requested between two dates (both inclusive). GET /enterprise/{id}/treeCount?startDate=YYYY-MM-DD&amp;endDate=YYYY-MM-DD. Returns { count }. |
| Count Enterprise Trees By Month | `countEnterpriseTreesByMonth` | Count the trees an enterprise requested in one calendar month. GET /enterprise/{id}/treeCount/{YYYY-MM}. Returns { count }. A month that is not in YYYY-MM form returns 400 with a monthDate format error. |
| Count Enterprise Trees Total | `countEnterpriseTreesTotal` | Count the total number of trees an enterprise has ever had planted. GET /enterprise/{id}/treeCount/total. Returns { count }. Note this counter reflects confirmed plantings and can lag behind freshly created tree requests. |
| Count Trees For End User | `countTreesForEndUser` | Count how many trees one end user has had planted under an enterprise. GET /tree?enterpriseId={id}&amp;user={user}. Returns { enterpriseId, user, count }. Useful for showing a customer their personal reforestation total. |
| Create Enterprise | `createEnterprise` | Create a new enterprise on the Digital Humani platform. POST /enterprise. Undocumented admin-only route: an ordinary client API key receives 403 Forbidden. Note Digital Humani exposes no client-facing route to delete an enterprise, so only call this when you intend the enterprise to be permanent. |
| Create Reforestation Project | `createReforestationProject` | Create a new reforestation project in the Digital Humani catalogue. POST /project. Undocumented admin-only route: an ordinary client API key receives 403 Forbidden. Projects are curated by Digital Humani staff. |
| Delete Enterprise | `deleteEnterprise` | DESTRUCTIVE AND IRREVERSIBLE. Delete an enterprise and everything attached to it. DELETE /enterprise/{id}. Undocumented admin-only route: an ordinary client API key receives 403 Forbidden. Deleting the enterprise your own API key belongs to would permanently lock the account out, so never point this at your own enterpriseId. |
| Delete Reforestation Project | `deleteReforestationProject` | DESTRUCTIVE. Remove a reforestation project from the Digital Humani catalogue. DELETE /project/{id}. Undocumented admin-only route: an ordinary client API key receives 403 Forbidden. Projects are shared across every enterprise on the platform. |
| Delete Tree Planting Request | `deleteTreePlantingRequest` | Cancel and permanently remove a tree-planting request by uuid. DELETE /tree/{uuid}. Undocumented but live. Returns 200 with an empty object on success and 404 'Operation failed - item does not exist.' for an unknown uuid. Confirm with Get Tree Planting Request, which should then 404. |
