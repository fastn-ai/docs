# Spotlightr

<img src="../../.gitbook/assets/connectors/lg/spotlightr.png" alt="Spotlightr logo">

Spotlightr (formerly vooPlayer) interactive video hosting and marketing platform. Create videos from a URL or upload, organise them into projects, replace video sources, delete videos, read per-video analytics and viewer-level view records, list top-performing videos, manage whitelisted embed domains, and create course/gallery students.

## Use it

Add Spotlightr from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.spotlightr.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).

## Events

Start a workflow when one of these happens, with an [app event trigger](../../build/triggers/README.md).

<table><thead><tr><th width="240">Event</th><th width="260">Id</th><th>When it fires</th></tr></thead><tbody><tr><td>Lead Opt-In Submitted</td><td><code>optin</code></td><td>Fires when a viewer submits an opt-in / lead-capture overlay on one of your Spotlightr videos. REGISTRATION IS UI-ONLY - Spotlightr exposes no webhook registration API (GET/POST /webhooks and /api/webhooks both return the host's route-not-found page). A human must register the endpoint once: open the Spotlightr app, go to App Settings &gt; Integrations, add a custom webhook integration and paste the fastn trigger URL as the endpoint. Spotlightr then posts opt-in and watching data to it. PAYLOAD SCHEMA IS MODELLED from Spotlightr's help-centre description, NOT captured from a real delivery - no delivery could be captured because registration requires a browser login. Reconcile the schema against the first real delivery.</td></tr><tr><td>Video Watched Threshold Reached</td><td><code>watched</code></td><td>Fires when a viewer reaches the watched threshold configured on a video. REGISTRATION IS UI-ONLY AND TWO-STEP. First, a human registers the endpoint: Spotlightr app &gt; App Settings &gt; Integrations &gt; add a custom webhook integration and paste the fastn trigger URL. Second, the notification must be enabled per video: edit the video &gt; Settings tab &gt; Advanced Options &gt; Watched Email Notification &gt; enable the switch, then click the gear icon and select the webhook integration created in step one. Spotlightr exposes no API for either step. PAYLOAD SCHEMA IS MODELLED from Spotlightr's help-centre description, NOT captured from a real delivery. Reconcile it against the first real delivery.</td></tr></tbody></table>
