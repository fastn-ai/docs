# Laposta

<img src="../../.gitbook/assets/connectors/lg/laposta.png" alt="Laposta logo">

This connector covers the full Laposta v2 REST API: mailing lists and their members, custom fields, segments, campaigns and campaign content, delivery reports, member and campaign history, and webhook management.

## Use it

Add Laposta from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.laposta.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).

## Events

Start a workflow when one of these happens, with an [app event trigger](../../build/triggers/README.md).

<table><thead><tr><th width="240">Event</th><th width="260">Id</th><th>When it fires</th></tr></thead><tbody><tr><td>Subscriber Added</td><td><code>subscribed</code></td><td>Fires when someone is added to the watched Laposta list, for example through a signup form. Set the List ID input to the list you want to watch - Laposta registers webhooks per list, so one trigger watches one list. IMPORTANT: by default Laposta does NOT fire webhooks for subscribers added or changed through the API itself, on the reasoning that the caller already knows; email Laposta support to have that enabled. Deliveries are batched every 5 seconds, up to 1000 events per request, so the payload's data array can hold many events at once.</td></tr><tr><td>Subscriber Deactivated</td><td><code>deactivated</code></td><td>Fires when a subscriber on the watched Laposta list is unsubscribed, deleted, or removed after a hard bounce - the info.action field says which. Set the List ID input to the list you want to watch. IMPORTANT: by default Laposta does NOT fire webhooks for changes made through the API itself; email Laposta support to have that enabled. Deliveries are batched every 5 seconds, up to 1000 events per request.</td></tr><tr><td>Subscriber Modified</td><td><code>modified</code></td><td>Fires when a subscriber on the watched Laposta list is changed - an edited email address or custom field. Set the List ID input to the list you want to watch. IMPORTANT: by default Laposta does NOT fire webhooks for changes made through the API itself; email Laposta support to have that enabled. Deliveries are batched every 5 seconds, up to 1000 events per request.</td></tr></tbody></table>
