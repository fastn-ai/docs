# Dwolla

Dwolla's Payments API for ACH bank transfers in the United States. Create and verify Customers, attach and verify bank funding sources, initiate transfers and mass payments, allocate funds with Labels, connect external accounts via Exchanges, and subscribe to webhook events.

| | |
| --- | --- |
| **Category** | [Finance and payments](README.md) |
| **Website** | [dwolla.com](https://dwolla.com) |
| **Authentication** | OAuth 2.0 |
| **Actions** | 81 |
| **Events** | 48 |
| **Slug** | `dwolla` |

## Use it

Add Dwolla from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.dwolla.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).
