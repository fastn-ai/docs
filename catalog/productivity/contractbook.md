## Setup

Your customers enter their API key for Contractbook when they connect. Nothing else needs setting up.

## Connect in Fastn

Your customers connect Contractbook from your widget. To connect an account yourself:

1. Go to **Build → Integrations → Connectors** and search for **Contractbook**.
2. Select **Connect** on the Contractbook card.

   <figure><img src="../../.gitbook/assets/connector-guides/fastn/connect-search.png" alt="The Connectors page in Fastn with ServiceNow typed in the search box and the ServiceNow card showing a Connect button"><figcaption><p>Search for the connector, then select Connect on its card. ServiceNow is shown here.</p></figcaption></figure>

3. Fill in the fields the form asks for, using the values from [Setup](#setup) above. Then select **Connect**.

   <figure><img src="../../.gitbook/assets/connector-guides/fastn/connect-credentials.png" alt="The Connect ServiceNow dialog with an optional account name and the Instance, Username and Password fields, and Cancel and Connect buttons"><figcaption><p>A connect form that asks for credentials. Each connector asks for its own fields.</p></figcaption></figure>

4. Check that the connection appears under **Operate → Connections** with the status `Active`. Your workflows can now use Contractbook's actions.

For more detail, see [Connect an app](../../build/connectors/connect-an-app.md).

## Actions

<table><thead><tr><th width="240">Action</th><th width="260">Slug</th><th>What it does</th></tr></thead><tbody><tr><td>Create Child Space</td><td><code>createChildSpace</code></td><td>Creates a new space nested under the parent space identified by the given UUID. The document is created as a draft only - nothing is sent for signature until Send Document For Signature is called.</td></tr><tr><td>Delete Document</td><td><code>deleteDocument</code></td><td>Permanently deletes a Contractbook document (draft or contract) by its UUID. This cannot be undone - Contractbook has no restore endpoint.</td></tr><tr><td>Get Document</td><td><code>getDocument</code></td><td>Retrieves a single Contractbook document (contract or draft) by its UUID, including its parties and signees, data fields, attachments, tags, state, current version identifier and sharing visibilities.</td></tr><tr><td>Get Document PDF</td><td><code>getDocumentPdf</code></td><td>Generates a PDF copy of a Contractbook document and returns a short-lived, pre-signed download URL in the 'location' field. The link expires after a few minutes, so download it immediately.</td></tr><tr><td>Get Space Tree</td><td><code>getSpaceTree</code></td><td>Returns the space (workspace) identified by the given UUID together with its descendant spaces as a tree. Spaces organise documents and templates into a hierarchy; the id of a document's space is exposed as document.workspace.</td></tr><tr><td>Get Template</td><td><code>getTemplate</code></td><td>Retrieves a single Contractbook contract template by its UUID, including the rich-text template body, its data field definitions, party placeholders, default signing order and default message.</td></tr><tr><td>List Automations</td><td><code>listAutomations</code></td><td>Lists the Contractbook automations configured for the organisation that start from a given trigger type. Automations are authored in the Contractbook web app's Automation Builder; the API only reads and runs them. trigger_type is mandatory - Contractbook rejects the request with HTTP 422 'Missing field: trigger_type' without it.</td></tr><tr><td>List Documents</td><td><code>listDocuments</code></td><td>Returns a cursor-paginated list of Contractbook documents (drafts, contracts and stored contracts) visible to the API key. Supports filtering by context, title, state, type, tag, ownership, signed/updated date ranges and integration object id, plus sorting and page size. Returns 'documents' and 'pagination_meta.cursor' for the next page.</td></tr><tr><td>List Templates</td><td><code>listTemplates</code></td><td>Returns every contract template available to the API key, including Contractbook's standard library and the organisation's own templates. Each entry carries the template id needed by Create Document From Template.</td></tr></tbody></table>
