## Setup

Your customers enter their username and password for HTML/CSS to Image when they connect. Nothing else needs setting up.

## Use it

Add HTML/CSS to Image from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.htmlCssToImage.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).

## Events

HTML/CSS to Image has no events, so it can't start a workflow by itself. Use its actions in a workflow that another [trigger](../../build/triggers/README.md) starts, such as a schedule or a webhook.
