## Setup

Your customers sign in to Facebook through fastn's own OAuth app, so nothing needs setting up first. To show your own app on the consent screen instead, add your OAuth app on the connector's **Auth** tab under **Manage providers**.

## Use it

Add Facebook from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.facebook.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).

## Events

Start a workflow when one of these happens, with an [app event trigger](../../build/triggers/README.md).

The payload carries only leadgen_id - call Get Lead with it to retrieve the submitted answers. Setup: Meta app console &gt; Products &gt; Webhooks &gt; Page &gt; Subscribe to this object, tick the leadgen field, paste this connector's webhook URL, and use the connector's verification secret as the verify token. Then run Subscribe Page App on each customer Page with subscribed_fields including leadgen.</td></tr><tr><td>Page Feed Activity</td><td><code>feed</code></td><td>Fires on activity in the Page feed - a new post, comment, reaction, share or edit. Then run Subscribe Page App on each customer Page with subscribed_fields including feed.</td></tr><tr><td>Page Mentioned</td><td><code>mention</code></td><td>Fires when the Page is mentioned in another person's or Page's post or comment. Setup: Meta app console &gt; Products &gt; Webhooks &gt; Page &gt; Subscribe to this object, tick the mention field, paste this connector's webhook URL, and use the connector's verification secret as the verify token. Then run Subscribe Page App on each customer Page with subscribed_fields including mention.</td></tr></tbody></table>
