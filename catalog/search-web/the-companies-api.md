## Setup

Your customers enter their API token for The Companies API when they connect. Nothing else needs setting up.

## Connect in Fastn

Your customers connect The Companies API from your widget. To connect an account yourself:

1. Go to **Build → Integrations → Connectors** and search for **The Companies API**.
2. Select **Connect** on the The Companies API card.

   <figure><img src="../../.gitbook/assets/connector-guides/fastn/connect-search.png" alt="The Connectors page in Fastn with ServiceNow typed in the search box and the ServiceNow card showing a Connect button"><figcaption><p>Search for the connector, then select Connect on its card. ServiceNow is shown here.</p></figcaption></figure>

3. Fill in the fields the form asks for, using the values from [Setup](#setup) above. Then select **Connect**.

   <figure><img src="../../.gitbook/assets/connector-guides/fastn/connect-credentials.png" alt="The Connect ServiceNow dialog with an optional account name and the Instance, Username and Password fields, and Cancel and Connect buttons"><figcaption><p>A connect form that asks for credentials. Each connector asks for its own fields.</p></figcaption></figure>

4. Check that the connection appears under **Operate → Connections** with the status `Active`. Your workflows can now use The Companies API's actions.

For more detail, see [Connect an app](../../build/connectors/connect-an-app.md).
