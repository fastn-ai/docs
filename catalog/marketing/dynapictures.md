## Setup

Your customers enter their access token for DynaPictures when they connect. Nothing else needs setting up.

## Connect in Fastn

Your customers connect DynaPictures from your widget. To connect an account yourself:

1. Go to **Build → Integrations → Connectors** and search for **DynaPictures**.
2. Select **Connect** on the DynaPictures card.

   <figure><img src="../../.gitbook/assets/connector-guides/fastn/connect-search.png" alt="The Connectors page in Fastn with ServiceNow typed in the search box and the ServiceNow card showing a Connect button"><figcaption><p>Search for the connector, then select Connect on its card. ServiceNow is shown here.</p></figcaption></figure>

3. Fill in the fields the form asks for, using the values from [Setup](#setup) above. Then select **Connect**.

   <figure><img src="../../.gitbook/assets/connector-guides/fastn/connect-credentials.png" alt="The Connect ServiceNow dialog with an optional account name and the Instance, Username and Password fields, and Cancel and Connect buttons"><figcaption><p>A connect form that asks for credentials. Each connector asks for its own fields.</p></figcaption></figure>

4. Check that the connection appears under **Operate → Connections** with the status `Active`. Your workflows can now use DynaPictures's actions.

For more detail, see [Connect an app](../../build/connectors/connect-an-app.md).

## Events

Start a workflow when one of these happens, with an [app event trigger](../../build/triggers/README.md).

<table><thead><tr><th width="240">Event</th><th width="260">Id</th><th>When it fires</th></tr></thead><tbody><tr><td>New Image Generated</td><td><code>NEW_IMAGE</code></td><td>Fires when a new image is generated from the subscribed image template, through any route - the JSON generation API, a link URL, the batch API or the widget. The delivery body is identical to the generation response: image id, templateId, the public imageUrl and thumbnail URLs, the custom metadata string and the pixel dimensions. NEW_IMAGE is the only event type DynaPictures supports, and a subscription is always bound to exactly one template, so set Template ID when arming the trigger.</td></tr></tbody></table>
