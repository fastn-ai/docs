## Setup

Your customers enter their access token for PDFMonkey when they connect. Nothing else needs setting up.

## Use it

Add PDFMonkey from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.pdfmonkey.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).

## Events

Start a workflow when one of these happens, with an [app event trigger](../../build/triggers/README.md).

<table><thead><tr><th width="240">Event</th><th width="260">Id</th><th>When it fires</th></tr></thead><tbody><tr><td>Document Generated Successfully</td><td><code>success</code></td><td>Fires when PDFMonkey finishes generating a document and its download URL is available. PDFMonkey names this event documents.generation.success and delivers it through Svix, which carries the event name in the svix-event-type header rather than in the body, so fastn routes on the payload's own document.status field instead. SETUP - PDFMonkey has no webhook registration API, so the endpoint is added by hand: sign in at https://dashboard.pdfmonkey.io, click Webhooks in the main navigation, click + Add Endpoint, paste this trigger's fastn webhook URL into the Endpoint URL field, subscribe the endpoint to documents.generation.success, then save.</td></tr><tr><td>Document Generation Failed</td><td><code>failure</code></td><td>Fires when PDFMonkey fails to render a document; the failure_cause field describes what went wrong. PDFMonkey names this event documents.generation.failure and delivers it through Svix, which carries the event name in the svix-event-type header rather than in the body, so fastn routes on the payload's own document.status field instead. SETUP - PDFMonkey has no webhook registration API, so the endpoint is added by hand: sign in at https://dashboard.pdfmonkey.io, click Webhooks in the main navigation, click + Add Endpoint, paste this trigger's fastn webhook URL into the Endpoint URL field, subscribe the endpoint to documents.generation.failure, then save.</td></tr></tbody></table>
