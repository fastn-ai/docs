## Setup

Your customers sign in to Asana through Fastn's own OAuth app, so nothing needs setting up first. To show your own app on the consent screen instead, add your OAuth app on the connector's **Auth** tab under **Manage providers**.

## Use it

Add Asana from **Build → Integrations → Connectors** and connect an account, as in [Connect a system](../../build/connectors/connect-a-system.md). In workflow code, call an action as `fastn.connector.asana.<action>()`, with the action's slug from the table below. See [Workflow runtime API](../../reference/workflow-runtime.md).

## Events

Start a workflow when one of these happens, with an [app event trigger](../../build/triggers/README.md).

<table><thead><tr><th width="240">Event</th><th width="260">Id</th><th>When it fires</th></tr></thead><tbody><tr><td>Resource Added</td><td><code>added</code></td><td>A resource (task, project, story, etc.) was created/added within the watched resource. Asana sends an events[] batch; each event has action='added'.</td></tr><tr><td>Resource Changed</td><td><code>changed</code></td><td>A field on the watched resource (or a child) changed. Each event has action='changed' and a change object describing the field and old/new values.</td></tr><tr><td>Resource Deleted</td><td><code>deleted</code></td><td>A resource was deleted (moved to trash). Each event has action='deleted'.</td></tr><tr><td>Resource Removed</td><td><code>removed</code></td><td>A resource was removed from the watched resource (e.g. a task removed from a project). Each event has action='removed'.</td></tr><tr><td>Resource Undeleted</td><td><code>undeleted</code></td><td>A previously deleted resource was restored from the trash. Each event has action='undeleted'.</td></tr></tbody></table>
