## Setup

Your customers enter their API token for KoboToolbox when they connect. Nothing else needs setting up.

## Connect in Fastn

Your customers connect KoboToolbox from your widget. To connect an account yourself:

1. Go to **Build → Integrations → Connectors** and search for **KoboToolbox**.
2. Select **Connect** on the KoboToolbox card.

   <figure><img src="../../.gitbook/assets/connector-guides/fastn/connect-search.png" alt="The Connectors page in Fastn with ServiceNow typed in the search box and the ServiceNow card showing a Connect button"><figcaption><p>Search for the connector, then select Connect on its card. ServiceNow is shown here.</p></figcaption></figure>

3. Fill in the fields the form asks for, using the values from [Setup](#setup) above. Then select **Connect**.

   <figure><img src="../../.gitbook/assets/connector-guides/fastn/connect-credentials.png" alt="The Connect ServiceNow dialog with an optional account name and the Instance, Username and Password fields, and Cancel and Connect buttons"><figcaption><p>A connect form that asks for credentials. Each connector asks for its own fields.</p></figcaption></figure>

4. Check that the connection appears under **Operate → Connections** with the status `Active`. Your workflows can now use KoboToolbox's actions.

For more detail, see [Connect an app](../../build/connectors/connect-an-app.md).

## Events

Start a workflow when one of these happens, with an [app event trigger](../../build/triggers/README.md).

<table><thead><tr><th width="240">Event</th><th width="260">Id</th><th>When it fires</th></tr></thead><tbody><tr><td>New Submission</td><td><code>submission</code></td><td>Fires when a deployed KoboToolbox form receives a new submission. Registration creates a REST Service on the chosen form, and KoboToolbox then posts each submission to the Fastn trigger address. The payload is the submission record itself: the answers keyed by question name alongside the submission metadata. Note that KoboToolbox REST Services offer only this one event; submission edits and deletions are not delivered.</td></tr></tbody></table>
