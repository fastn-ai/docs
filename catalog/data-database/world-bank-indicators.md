## Setup

World Bank Indicators API needs no sign-in, so there is nothing to set up. Add it and use its actions.

## Connect in Fastn

Your customers connect World Bank Indicators API from your widget. To connect an account yourself:

1. Go to **Build → Integrations → Connectors** and search for **World Bank Indicators API**.
2. Select **Connect** on the World Bank Indicators API card.

   <figure><img src="../../.gitbook/assets/connector-guides/fastn/connect-search.png" alt="The Connectors page in Fastn with ServiceNow typed in the search box and the ServiceNow card showing a Connect button"><figcaption><p>Search for the connector, then select Connect on its card. ServiceNow is shown here.</p></figcaption></figure>

3. World Bank Indicators API needs no credentials. Select **Connect** in the dialog that opens.

4. Check that the connection appears under **Operate → Connections** with the status `Active`. Your workflows can now use World Bank Indicators API's actions.

For more detail, see [Connect an app](../../build/connectors/connect-an-app.md).
